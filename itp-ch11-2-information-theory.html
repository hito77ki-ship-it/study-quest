何通りを表せるかと、何バイト使うかを区別する

1ビットには0と1の2通り、nビットには2のn乗通りのビット列があります。1バイト＝8ビットなので2バイトなら16ビット、2の16乗＝65,536通りです。これは固定の16ビットで表せる組合せの数です。文字コードが実際にどの組合せを使うかは規格で決まります。

k、M、G、Tなどは10の累乗の接頭語です。1 kBは1,000 B、1 KiBは1,024 B。通信のbpsは1秒当たりのビット数です。8,000 bitの送信を4,000 bit/sで行う理想条件なら2秒です。接頭語・単位と、通信の追加情報を含むかを確認します。

音声のデジタル化は、時刻・段階・ビット列の順

館内の放送を録音します。音の波形は連続的に変化します。デジタル化では、どの時刻で値を取るか、測った値をどの段階に寄せるか、その段階をどのビット列で記録するかを順に決めます。

例えば非圧縮PCMで、8,000回/秒、1回8ビット、1チャンネルを3秒記録すると、8,000×8×1×3＝192,000ビット、24,000バイトです。ヘッダなどは含めません。測定回数を増やすと時間方向の変化をより細かく拾え、段階数を増やすと振幅方向の丸めの幅を小さくできます。

画像では、画素ごとに明るさや色を数値にします。例えば白黒の写真を256段階の明るさで表せば、1画素は8ビットです。横100×縦60画素なら、非圧縮でヘッダを除いたデータは100×60×8＝48,000ビット（6,000バイト）。画素数と一つの画素に使うビット数を分けて計算します。

文字コード・検索記号・論理的な推論

文字コードは文字を数値と対応づける仕組みです。Unicodeは文字にコードポイントを割り当て、UTF-8はそれをバイト列で表します。英字 A はUTF-8で1バイト、ひらがなの「あ」は3バイトです。JISコードやシフトJISのデータを受け取る場合は、読み書きの方式が合っているかを確かめます。

述語論理では「すべての予約は利用者と結びつく」のように、対象と条件を明示します。一般的な規則と個別の事実から結論を出すのが演繹推論、複数の観察例から傾向を推測するのが帰納推論です。ワイルドカードでは「貸出*.csv」の * が任意の文字列を表すことがあります。正規表現では * が直前の要素の0回以上の繰返しを表すため、検索機能の方式を確かめます。

例題8問と解説

Study Quest編集部の自作問題です。先に答えを考えてから、各問の「解答と解説」を開いてください。

第1問　識別子の組合せ

固定長12ビットですべてのビット列を使えるとします。最大何種類のIDを作れますか。

  1. 1,024
  2. 2,048
  3. 4,096
  4. 12,000
第1問の解答と解説

ウ　4,096

2の12乗＝4,096です。値0も一つの組合せです。

第2問　バイトとビット

非圧縮PCMで毎秒6,000回、量子化8ビット、1チャンネルの2秒分を記録します。ヘッダなしで何バイトですか。

  1. 12,000
  2. 6,000
  3. 24,000
  4. 96,000
第2問の解答と解説

ア　12,000

6,000×8×2＝96,000 bit。8で割って12,000 Bです。

第3問　測定の間隔

音の大きさの段階数は同じまま、より短い間隔で波形を測ります。変わるものはどれですか。

  1. 符号化の文字種
  2. 量子化段階数
  3. チャンネル数
  4. 標本化周波数
第3問の解答と解説

エ　標本化周波数

1秒当たりに測る回数が増えるので、標本化周波数が上がります。

第4問　文字の長さ

UTF-8で「Aあ」を保存します。BOM・改行なしなら何バイトですか。

  1. 2
  2. 4
  3. 3
  4. 6
第4問の解答と解説

イ　4

Aは1バイト、あは3バイトなので4です。文字数とバイト数は一致しないことがあります。

第5問　ルールを適用する

「すべての学習室の鍵は返却が必要」「この鍵は学習室のもの」から「この鍵は返却が必要」と結論づけます。どの推論ですか。

  1. 帰納推論
  2. 確率的な標本抽出
  3. 演繹推論
  4. 強化学習
第5問の解答と解説

ウ　演繹推論

一般的な規則を個別の事実に当てはめています。観察を集めて一般化するのは帰納推論です。

第6問　ラベルがある写真

分類名を付けた本の写真から、新しい写真の分類を学びます。方式はどれですか。

  1. 教師あり学習
  2. 教師なし学習
  3. 強化学習
  4. 量子化
第6問の解答と解説

ア　教師あり学習

写真と正解の分類名の組を使っているので、教師あり学習です。

第7問　活性化関数を使う

活性化関数がReLUで、重み付き和にバイアスを加えた値が−3です。出力はどれですか。

  1. −3
  2. −1
  3. 3
  4. 0
第7問の解答と解説

エ　0

ReLUは入力が負なら0、0以上なら入力をそのまま返します。

第8問　どのデータで評価するか

図書館が本の画像を分類するモデルを作りました。未知の写真にも通用するか確かめる方法はどれですか。

  1. 学習に使った写真だけを再分類
  2. 学習に使わなかった別の写真で評価
  3. 正答ラベルをモデルに入力してから評価
  4. 写真を使わず、保存容量だけを比べる
第8問の解答と解説

イ　学習に使わなかった別の写真で評価

学習に含めなかったデータで評価すると、既知の例を覚えただけかどうかを確かめやすくなります。
