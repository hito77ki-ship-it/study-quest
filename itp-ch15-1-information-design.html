ITパスポート 15-1 情報デザイン

図書館のイベント予約を題材に、情報の並べ方、GUI、Webのアクセシビリティ、人間中心設計を図と例題で学びます。

見つけたい情報に合わせて並べる

架空の市立図書館が、工作や読み聞かせのイベントを開きます。告知を見た親子が「何時に、どこで、まだ予約できるか」をすぐ見つけられるように、情報を選び、組み立て、表現するのが情報デザインです。

同じイベント一覧でも探し方によって順序は変わる
LATCHの軸図書館での使い方
Location｜場所会場マップに催しを置く。
Alphabet｜文字順題名から五十音順で探す。
Time｜時間開始時刻の順に並べる。
Category｜分類工作、読み聞かせに分ける。
Hierarchy｜階層・順位定員が多い順に並べる。

扉の「押す」や、予約ボタンの輪郭と「予約へ」という文言は、できる行動を知らせるシグニファイアです。ピクトグラムは会場や設備を伝える絵記号です。空き枠の推移を軸と棒で見せる図はインフォグラフィックスの例です。

受付フォームの部品を役割で選ぶ

ヒューマンインタフェースは人とシステムの接点です。画面上の部品をタップして操作するGUI、声で質問したり答えを聞いたりするVUI、手の動きを使うジェスチャーインタフェースがあります。タップで選択、スワイプで移動、ピンチで拡大縮小、長押しで追加操作というように、一つのタッチ画面でも動作はさまざまです。

ウィンドウは作業の表示領域、アイコンは機能などを示す絵、サムネイルは内容を見分ける縮小表示です。リストボックスは候補を一覧表示し、設定によって複数選択にも使えます。メニューバーは操作の分類を並べ、プルダウンやポップアップは選択肢を必要に応じて開きます。ホバー時に出るツールチップだけに頼ると、タッチ操作では説明を見つけづらいことがあります。

画面設計では、日時を選ぶ→必要事項を入力→確認の順に進め、入力エラーの場所と直し方を近くに出します。帳票設計では、受付番号・日時・会場など係員が使う項目をそろえ、参加者向けの控えと受付用一覧にはそれぞれ必要な項目を載せます。

スマホの表示と、色を見分けにくい場面を考える

CSSは色や余白、文字サイズ、レイアウトなどを指定します。共通のスタイルを使うとページ間で書式をそろえやすくなります。画面幅に応じたCSSを使うと同じページの配置を調整できます。旧予約ページから新しいURLへ転送するリダイレクトは、アクセス先を変える仕組みです。

ユニバーサルデザインは、できるだけ多くの人が利用できるようにする考え方です。アクセシビリティでは、キーボードだけで予約できるか、読み上げで入力欄や図の意味が分かるか、色を区別しにくい状況でも満席を判断できるかを確かめます。例えば意味のある会場図には要点を説明する代替テキストや本文を添え、装飾だけの画像は読み上げを省けるようにします。

使う人と場面を調べ、試して直す

ユーザビリティは、ある人が目的を達成するときの使いやすさです。UXは予約前の期待、操作中の安心感、当日の受付までを含む体験です。構造化シナリオ法では、例えば「安心して参加できる」という価値から、「家族の空き時間に合わせて選ぶ」活動と、「満席を除いて時間枠を選択する」操作へ具体化します。

例題8問と解説

Study Quest編集部の自作問題です。先に答えを考えてから、各問の「解答と解説」を開いてください。

第1問　近くに置く

イベント名の直下に会場と時刻を並べ、次のイベントとは間を空けました。まとまりを作る原則はどれですか。

  1. 反復
  2. 近接
  3. 対比
  4. 整列
第1問の解答と解説

イ　近接

関連項目を近づけ、別のイベントとの間を空ける近接です。

第2問　時刻の順に探す

開始の早い順にイベントを見られる一覧にします。LATCHのどの軸ですか。

  1. Location
  2. Category
  3. Alphabet
  4. Time
第2問の解答と解説

エ　Time

判断に使う並びは開始時刻なのでTimeです。

第3問　押せる手掛かり

押す場所が分からない扉に「押す」と表示しました。表示の役割はどれですか。

  1. シグニファイア
  2. スタイルシート
  3. リダイレクト
  4. 帳票
第3問の解答と解説

ア　シグニファイア

表示が「ここで何をすればよいか」を伝えています。

第4問　同時に二つを選ぶ

字幕と大きな文字をそれぞれ独立に選ぶ部品はどれですか。

  1. 一組のラジオボタン
  2. 実行ボタン
  3. チェックボックス
  4. ツールチップ
第4問の解答と解説

ウ　チェックボックス

両方を必要とする人も片方だけの人も選べるよう、各項目を独立してオンにします。

第5問　満席を伝える

赤い枠だけで満席を示していました。改善する案はどれですか。

  1. 赤の彩度を上げるだけ
  2. 枠の横に「満席」と書く
  3. ホバーでだけ説明する
  4. 赤い背景画像に置き換える
第5問の解答と解説

イ　枠の横に「満席」と書く

満席という意味を文字でも伝えると、色を見分けづらい場面にも対応できます。

第6問　画面幅に合わせる

同じページを狭い幅では1列、広い幅では2列で表示します。どの設計ですか。

  1. 音声インタフェース
  2. リダイレクト
  3. レスポンシブWebデザイン
  4. インフォグラフィックス
第6問の解答と解説

ウ　レスポンシブWebデザイン

画面の幅に応じてレイアウトが変わります。URLの転送はこの変更に必要ありません。

第7問　控えを設計する

受付係が予約を照合する一覧に、必要な情報を配置します。適切なのはどれですか。

  1. 照合に使う予約番号・氏名・時間を近づける
  2. 予約番号を毎行違う位置にする
  3. 広告画像を優先する
  4. 全項目を色だけで区別する
第7問の解答と解説

ア　照合に使う予約番号・氏名・時間を近づける

照合に使う情報を揃った位置にまとめると、行を追って確かめやすくなります。

第8問　試作から改善する

試作で利用者が満席の枠を何度も選びました。人間中心設計に沿う対応はどれですか。

  1. 利用者には説明せず正式版を公開する
  2. 担当者だけで好きな色を決めて終了する
  3. 評価した画面をそのまま採用する
  4. 迷った理由を調べ、表示を直して再評価する
第8問の解答と解説

エ　迷った理由を調べ、表示を直して再評価する

利用者の行動を見て要求と設計に反映し、修正した案を再評価します。
