アローダイアグラムで「何の完了を待つか」を読む

学習室予約を公開するまでの作業を五つに分けます。各作業の期間は架空の数値です。実装担当と案内担当は別で、同時に作業できるとします。土日や担当者の休み、準備時間はこの計算に含めません。

予約機能を公開する作業と前提
作業所要日数先に終える作業
A 要件確認2日なし
B 予約機能の実装4日A
C 職員向け案内2日A
D 受入れ確認2日BとC
E 本番公開1日D

アローダイアグラム（PERT図と呼ばれることもあります）は、作業を矢印で表し、どの作業が終われば次へ進めるかを示します。BとCは同時に始められますが、Dは両方が終わるまで始められません。そのため日数は全部を足すのでなく、A→B→D→Eが2＋4＋2＋1＝9日、A→C→D→Eが2＋2＋2＋1＝7日と、経路ごとに比べます。後者の点線も経由しますが、所要日数は0日なので合計には影響しません。

クリティカルパスと余裕日数を計算する

この例のクリティカルパスは、最短で終えようとしたときに全体の完了時点を決める9日の経路です。Bが1日長くなると、他の作業を変えない限り全体も1日延びます。一方、Cが2日長くなっても両経路が9日で並ぶため、全体の日数は変わりません。このときクリティカルパスは二つになります。Cが3日長くなると、Cを通る経路が10日となり、公開も1日延びます。

結合点の最早開始日は、開始側から日数を足して求めます。結合点4ではBの終わりが2＋4＝6、Cの終わりが2＋2＝4なので、大きい方の6を選びます。最遅開始日は終了側から、完了期限を守れるように逆算します。経過9日からEの1日とDの2日を引くと、結合点4は経過6日までに到達する必要があります。結合点3から4へは0日なので、結合点3も経過6日までに到達すれば間に合います。分岐する結合点を逆算するときは、全ての後続作業に間に合うよう、候補のうち早い時点を選びます。

結合点3は最早4日、最遅6日なので、差の2日がこの分岐の余裕です。実際の計画で同じ担当者にBとCを割り当てれば、同時に作業できるという前提が崩れます。日程表を作るときは、依存関係と担当者の空きの両方を確認します。

ガントチャートで計画と実績を比べる

ガントチャートは、横軸に日付や期間を取り、作業の開始から終了までを横棒で表します。同じ計画でも、アローダイアグラムは前後関係、ガントチャートは「何日目にどの作業が動くか」を読み取りやすくします。実務のガントチャートには依存関係の矢印を併記することもあります。

マイルストーンは、例えば「受入れ承認」や「公開完了」のような重要な節目です。「本番への反映を1日かけて行う」のは作業で、「反映を確認して完了した時点」が節目です。全体の主要な成果物や節目をまとめた日程をマスタスケジュールといいます。

進捗報告では「6日目終了時点で実装が1日分残っている」「7日目に終わる見込み」「そのままだと公開は10日目になる」「担当者の追加や公開範囲の見直しを判断してほしい」のように、基準日、残作業、影響、次の判断を分けます。この例の計画は実装が6日目まで、受入れが7〜8日目、公開が9日目です。

プレシデンスダイアグラムで開始と終了を区別する

プレシデンスダイアグラム法では、作業を四角で表し、作業同士の依存関係を矢印でつなぎます。記号の最初の文字は先行作業、二つ目は後続作業の条件です。Fは終了、Sは開始です。

例の「実装完了を待って受入れ開始」はFSです。一方、試行期間中に問い合わせの集計も始められるならSSです。終了が条件か開始が条件かで、重ねて進められる作業が変わります。

例題6問と解説

Study Quest編集部の自作問題です。先に答えを考えてから、各問の「解答と解説」を開いてください。

第1問　二つの経路から全体の日数を出す

上の作業表で、作業を最短で進めた場合の完了までの日数はどれですか。

  1. 7日
  2. 8日
  3. 9日
  4. 11日
第1問の解答と解説

ウ　9日

Aの後、BとCは同時に始められます。Dが待つのは時間が長いBの完了なので、2＋最大(4, 2)＋2＋1＝9日です。11日は並行作業を直列として足した値です。

第2問　案内の遅れが公開日に響くか

上の計画からCだけが3日長くなり、所要日数が5日になりました。公開日は何日ずれますか。

  1. 1日遅れる
  2. ずれない
  3. 2日遅れる
  4. 3日遅れる
第2問の解答と解説

ア　1日遅れる

元のCには2日の余裕があります。延びたC経路は2＋5＋2＋1＝10日となり、B経路の9日を1日超えます。

第3問　逆算して最遅開始日を求める

開始を経過0日とします。元の計画で結合点3を経過何日までに通れば9日で公開できますか。

  1. 経過2日
  2. 経過4日
  3. 経過5日
  4. 経過6日
第3問の解答と解説

エ　経過6日

終点からEの1日、Dの2日、ダミーの0日を引いて、9−1−2−0＝6日です。経過4日はAとCが最も早く終わる時点です。

第4問　棒と節目を選ぶ

実装の予定期間と、公開完了の時点を同じ日程表に載せたいとき、適切な組合せはどれですか。

  1. WBSの枝と日数だけ
  2. ガントチャートの横棒とマイルストーン
  3. リスク一覧と憲章
  4. 担当者一覧と費用の円グラフ
第4問の解答と解説

イ　ガントチャートの横棒とマイルストーン

ガントチャートの横棒が期間を示し、マイルストーンが時点を示します。WBSは作業を階層的に分ける図です。

第5問　計画と実績から公開を予測する

6日目が終わった時点で、Bの実装は7日目の終了までかかると見込みました。Cは完了済みで、DとEの順番と期間はそのままです。公開はいつですか。

  1. 8日目
  2. 9日目
  3. 10日目
  4. 11日目
第5問の解答と解説

ウ　10日目

B完了は7日目の終了です。Dの受入れに8・9日目を使い、その後のEを10日目に行います。

第6問　新受付と旧受付の切替を表す

新しい受付が始まる前に、旧受付を止めてはいけません。新受付を先行作業、旧受付を後続作業とすると、関係はどれですか。

  1. SF
  2. SS
  3. FF
  4. FS
第6問の解答と解説

ア　SF

条件は新受付の開始（S）と旧受付の終了（F）なのでSFです。SSなら旧受付の開始が条件になるので、この切替の説明と合いません。

短縮しても、別の経路が公開日を決める

図書館の別の計画で、公開に必要な経路は二つあり、元の経路Aは12日、経路Bは10日です。Aだけ4日短縮できても、Bが待ち合わせの時点を決めます。

用語を場面と結び付ける
用語意味と使う場面
クリティカルパスの切替Aを8日に縮めると、残るBの10日が全体を決める。全体の短縮は12−10＝2日。変更のたびに全経路を比較する。
マイルストーンチャート計画上の重要な時点を一覧にする図。教科書では、ガントチャート上にマイルストーンを記したものもこう呼ぶ。
進捗管理計画日と実績・見込みを比べ、差が後続作業や節目にどう波及するかを確認する。

補足の自作例題

別の計画では二つの独立した経路が14日と11日です。14日の経路だけを5日短縮できました。全体は何日短縮できますか。

解答と考え方を開く

経路は9日と11日になり、両方の終了を待つため全体は11日。14−11＝3日短縮できます。

もう一歩の復習
用語意味と使う場面
EVM・PV・EV・ACEVMは計画、完了した仕事、実際の費用を比較する。PVは基準日までの計画分の予算、EVは実際に完了した分に割り当てた予算、ACは実際に掛かった費用。
日程差異 SV・コスト差異 CVSV＝EV−PV、CV＝EV−AC。SVは金額換算された進捗差であり、何日遅れたかは工程の依存関係を別に確かめる。

EVMと完了時の費用を考える自作例題

1台3万円で設定する計画で、基準日には5台の予定でした。実際は4台が完了し、14万円を使いました。日程差異とコスト差異はいくらですか。全体で12台を設定し、今後も同じ平均費用が続くと仮定すると、当初予算に対し完了時の費用はどれだけ増えますか。

EVMの解答と計算を開く

PVは15万円、EVは12万円、ACは14万円。SVは12−15＝−3万円、CVは12−14＝−2万円です。実績の平均は14÷4＝3.5万円なので、12台の完了時は42万円と見積もれます。当初予算は3×12＝36万円。差は6万円の増加です。今後の条件が変われば、残りの作業費を見直します。
