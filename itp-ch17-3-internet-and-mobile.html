ITパスポート 17-3 ネットワーク応用

URLを開くと、名前から通信先を探す

たとえば https://school.example/guide/?day=2 では、httpsがスキーム、school.exampleがホスト名、/guide/がパス、day=2がクエリです。URLは情報の場所などを表し、ドメイン名は名前空間の中の名前です。ドメイン名は右から階層をたどり、例えばwww.example.jpではjpがトップレベルです。ルートまで含めて完全に指定した名前をFQDNと呼びます。

DNSは名前を手掛かりにIPアドレスなどの情報を調べる分散型の仕組みです。同じ名前に複数のIPが返ることもあり、単純な1対1の名簿とは限りません。IPv4は32ビット、IPv6は128ビットでアドレスを表します。IPv4のプライベートアドレスは家庭や学校などの内部に使い、インターネットではそのままの宛先として使いません。グローバルIPアドレスは公開インターネットで使えるアドレスです。

同じLANかどうかは、IPv4アドレスのネットワーク部分を比較して判断します。たとえば /24 は先頭24ビットがネットワーク部分という意味で、サブネットマスクは255.255.255.0です。192.168.20.10/24と192.168.20.25/24のネットワークはともに192.168.20.0/24です。192.168.21.25/24は別のネットワークです。

Webやメールで、どこに何が残るかを考える

Webでは、ブラウザがURLを指定して要求し、WebサーバがHTMLなどを返します。ハイパーリンクは別の情報へ移動する参照です。CGIはWebサーバが外部プログラムを呼び出す仕組みの一つで、案内フォームの入力に応じて内容を変えるといった使い方があります。SNSは情報を共有したり交流したりするサービスです。

同報メールは同じ内容を複数の人に送る方法です。受信したメールはサーバのメールボックスなどに置かれます。テキストメールは主に文字、HTMLメールは書式や画像を含められます。Bccは宛先の扱いを変えるもので、本文の機密性を保つ機能とは別です。実際に一斉送信するときは、送信アプリで少人数のテストを行い、宛先表示を確認します。

固定回線と携帯回線の、どちらを使う？

回線がどこまで届くかで見分ける
方式・役割仕組みと例
FTTH・ONU建物まで光ファイバーを引く。ONUは光回線と宅内側の機器をつなぐ。
CATVインターネットケーブルテレビの設備を活用して接続する。
ADSL・ISDN電話回線を用いる方式の例。ADSLは上り・下りが非対称、ISDNはデジタル通信網。
回線事業者・ISP回線事業者は通信回線を提供し、ISPはインターネットへの接続を提供する。同じ会社が両方を扱う場合もある。
IP電話・VoIP音声をデータ化し、IPネットワーク上で運ぶ。

料金の設問では、何に対して支払うかを見ます。従量制は利用量などに応じて費用が変わり、定額制は条件内で一定です。例えば固定費を無視し、従量制を0.5円/MB、定額制を1,000円と仮定すれば、2,000 MBで同額です。これは仕組みを比べる架空の条件です。

移動するスマホの通信を、基地局と契約で分けて考える

SIMカードは契約者の識別などに必要な情報を持つICカードです。eSIMは対応端末へ契約情報のプロファイルを遠隔で設定でき、物理カードの差替えを減らせます。MNOは自らの移動通信網でサービスを提供する事業者、MVNOは他事業者の移動通信網を借りてサービスを提供する事業者です。

電波を使う仕組みと、サービスの使い道
用語身近な場面
LTE・5G携帯回線で通信する規格。5Gでは高速大容量・低遅延・多数接続が用途ごとの特徴になる。
プラチナバンド携帯で使う比較的低い周波数帯の通称。障害物の回り込みや屋内への届きやすさに関わる。
MIMO複数の送受信アンテナを使い、通信品質や速度の改善を図る。
キャリアアグリゲーション複数の周波数ブロックを束ね、通信容量を広げる。
テレマティクス車両などの情報を通信で集め、位置案内や運行管理に活用する。

無線LANのAPはWi-Fi端末をネットワークにつなぎ、携帯の基地局は携帯回線につなぎます。WiMAXは無線で広域アクセスを提供する方式の一つです。利用者が多いときの体感速度は、規格名だけでなく、電波の状態や回線の混雑などにも左右されます。

例題11問と解説

Study Quest編集部の自作問題です。先に答えを考えてから、各問の「解答と解説」を開いてください。

第1問　つながる準備と名前の検索

Wi-Fi接続後にIP設定は受け取れましたが、案内サイトのホスト名に対応するIPを確認できません。どの仕組みを調べますか。

  1. DHCP
  2. DNS
  3. SMTP
  4. MNP
第1問の解答と解説

イ　DNS

名前からIPアドレスなどの情報を調べるのはDNSです。DHCPは端末の接続設定を配布します。

第2問　同じサブネットを選ぶ

受付PCが192.168.20.10/24です。下の候補も全て/24とした場合、同じサブネットなのはどれですか。

  1. 192.168.21.10
  2. 192.169.20.10
  3. 192.168.20.25
  4. 192.168.2.10
第2問の解答と解説

ウ　192.168.20.25

/24では最初の24ビットがネットワーク部です。先頭3組が192.168.20で一致する192.168.20.25が該当します。

第3問　一つの外側IPを共用

2台の受付端末が、外側では同じIPv4アドレスを使い、ポート番号の違いで通信を区別します。何の例ですか。

  1. MIME
  2. NTP
  3. FTTH
  4. NAPT
第3問の解答と解説

エ　NAPT

NAPTは、内部と外部のIPアドレスに加えてポート番号も対応付けて変換します。

第4問　URLのどの部分が名前？

https://school.example/guide/?day=2 で、DNSの検索に使うホスト名はどれですか。

  1. school.example
  2. https
  3. /guide/
  4. day=2
第4問の解答と解説

ア　school.example

スキームはhttps、ホスト名はschool.example、パスは/guide/、クエリはday=2です。

第5問　参加者のアドレスを守る

参加者同士にはメールアドレスを見せず、同じ案内を送る用途に使う欄はどれですか。

  1. Cc
  2. Bcc
  3. 件名
  4. Reply-To
第5問の解答と解説

イ　Bcc

Bccは受信者同士に宛先アドレスを見せない一斉送信に使えます。Ccでは他の受信者に宛先が見えるのが一般的です。

第6問　前に読んだ画像を再利用

同じ案内画像を取得し直さず、以前受け取ったデータを条件に応じて再利用します。何を使う例ですか。

  1. RSS
  2. SIM
  3. キャッシュ
  4. Cookie
第6問の解答と解説

ウ　キャッシュ

キャッシュは画像などの取得結果を再利用するための仕組みです。Cookieは利用状態の識別などに使います。

第7問　回線を分け合う

各来場者の写真データを小さな単位に分け、同じ回線を複数の通信で使います。どの説明に当たりますか。

  1. 回線交換だけ
  2. MNP
  3. ハンドオーバー
  4. パケット交換
第7問の解答と解説

エ　パケット交換

各通信を小さな単位に分けて回線を共有する考え方です。

第8問　移動中に基地局を切り替える

通話しながら校門から駅へ移動し、接続先の基地局が切り替わります。どれですか。

  1. ハンドオーバー
  2. MNP
  3. MIMO
  4. テザリング
第8問の解答と解説

ア　ハンドオーバー

移動中の接続先の基地局の切替えがハンドオーバーです。電話番号を持ち運ぶMNPとは別の場面です。

第9問　スマホでPCをつなぐ

外でノートPCを使うとき、スマホの携帯回線をPCと共有します。何を使いますか。

  1. PoE
  2. テザリング
  3. NATを無効化
  4. RSS
第9問の解答と解説

イ　テザリング

スマホなどを中継役にして、PCなどを携帯回線につなぐのがテザリングです。

第10問　複数の周波数を束ねる

一つの周波数ブロックだけでなく、複数を束ねて通信容量を増やす技術はどれですか。

  1. MNP
  2. MIMO
  3. キャリアアグリゲーション
  4. ローミング
第10問の解答と解説

ウ　キャリアアグリゲーション

キャリアアグリゲーションは複数の周波数ブロックを束ねます。MIMOは複数のアンテナに着目する仕組みです。

第11問　料金を比べる

架空のプランで従量制が0.5円/MB、定額制が1,000円とします。2,400 MB使ったとき、差はいくらですか。

  1. 従量制のほうが200円安い
  2. 同額
  3. 定額制のほうが1,400円安い
  4. 定額制のほうが200円安い
第11問の解答と解説

エ　定額制のほうが200円安い

従量制は2,400×0.5＝1,200円。定額制は1,000円なので差は200円です。
