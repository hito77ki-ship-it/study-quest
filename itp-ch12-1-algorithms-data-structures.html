流れ図は矢印をたどり、分岐では通った道だけを読む

大学図書館が、予約した人と当日来た人を案内します。アルゴリズムは、何を受け取り、どの順で処理し、どんな結果を出すかを定めた手順です。同じ手順を流れ図や擬似言語などで表せます。

端子は開始・終了、処理の箱は値の計算や更新、ひし形は条件による分岐を表します。番号を読んでから確認するのが順次、条件で案内を変えるのが選択、受付データが残る間だけ繰り返すのが反復です。反復では「いつ条件を調べるか」と「何が変わると終わるか」を先に確かめます。

変数には処理中の値が入り、代入で値が更新されます。例えば count ← count + 1 は更新前の値に1を足して戻します。予約の件数は整数、平均の待ち時間は実数、名前は文字列、予約の有無は論理型で表せます。

取り出し方を先に決めると、データ構造を選べる

同じ図書館でも、管理したい関係が違う
構造使う場面
配列部屋ごとの残席を位置で扱う。行を階、列を部屋とすれば2次元配列で表せる。
キュー（FIFO）受付番号を到着順に処理する。先に入れたものから出す。
スタック（LIFO）履歴のうち最新の操作を取り消す。後から入れたものを先に出す。
連結リスト各要素が次の要素への参照を持つ。途中に案内を差し込むとき、前後のつながりを変更する。
木構造「図書館 → 2階 → 閲覧室」のような階層。起点は根、下に子を持たない点は葉。

予約番号・部屋・人数をまとめた1件分はレコード、各項目はフィールドと呼べます。複数の記録をファイルにまとめて保存する場合もあります。木構造のうち、各点の子が最大二つのものは二分木です。

連結リストで「一般 → 予約」を「一般 → 優先 → 予約」にするなら、一般の次を優先に、優先の次を予約にします。配列と連結リストを見分けるときは、位置を指定するか、参照をたどるかを考えましょう。操作が混ざる問題は基本情報のスタックとキューでも練習できます。

探し方は「整列済みか」を見て選ぶ

返却された本を順不同で置いた棚では、先頭から一つずつ確かめる線形探索が使えます。番号の昇順に並ぶ一覧で中央の値を確認できるなら、中央と比較して候補を減らす二分探索（2分探索）が使えます。降順の場合は左右の判断が逆になります。

候補が7件の場合、線形探索で末尾まで調べると7回比較します。この図と同じ中央を取る二分探索では、最初に7件、次に最大3件、その次に最大1件となるので最大3回です。二分探索の前に整列が必要な場合は、並べ替えの手間も考えます。重複がある一覧で最初の一致を探す場合は、見つかった時点で終えるかも仕様で決めます。

整列は、何を比較してどこが確定するかを追う

整列の手掛かり
手法確かめる操作
バブルソート隣り合う値を比較して交換する。この例の最初の1周では最大値が右端に移る。
選択ソート未整列部分の最小値を選び、未整列部分の先頭へ置く。この入力で最初の交換後は[2, 3, 6, 8]。
クイックソート基準値（ピボット）で分け、部分ごとに同じ考え方を適用する。例では基準6を除いて小さい側は3と2、大きい側は8。実装によって等しい値の扱いが異なる。
マージソート小さい単位に分割し、整列済みの部分を併合して戻す。先に整列した小さな列同士をつなぎ直す。

併合では、左右の先頭のうち小さい方を一つ出す

後ろの値はその列の先頭以上なので、全体の残りで最小の値は左右どちらかの先頭にあります。同じ値を残す設問なら、同値でも片方ずつ取り出します。マージソートではこの併合を繰り返して大きい列を作ります。

例題8問と解説

Study Quest編集部の自作問題です。先に答えを考えてから、各問の「解答と解説」を開いてください。

第1問　流れ図の分岐

図の受付に、予約していない利用者が来ました。番号を確認した後の処理はどれですか。

  1. 入室を記録する
  2. 入室を記録し、空き枠も案内する
  3. 空き枠を案内して終了する
  4. 予約ありになるまで番号を読む
第1問の解答と解説

ウ　空き枠を案内して終了する

「予約あり？」の答えがいいえなので、右側の経路を選びます。入室の記録は左の経路です。

第2問　代入の順番

x ← 4、y ← x、x ← x + 3 を順に実行します。最後のxとyはどれですか。

  1. x＝7、y＝4
  2. x＝7、y＝7
  3. x＝4、y＝7
  4. x＝4、y＝4
第2問の解答と解説

ア　x＝7、y＝4

yへ代入する時点のxは4です。その後の加算はxだけを更新するので、yは4のままです。

第3問　受付と取り消し

受付番号21、22を入れ、1件取り出し、続けて23を入れました。次にキューとスタックから1件ずつ取り出すと、それぞれ何番ですか。

  1. キュー21、スタック22
  2. キュー22、スタック22
  3. キュー23、スタック21
  4. キュー22、スタック23
第3問の解答と解説

エ　キュー22、スタック23

キューからは最初に21が出るので、次は22です。スタックからは最初に22が出ます。その後23が積まれるので、次は23です。

第4問　データ構造の見分け

分類の下に小分類があり、その下に本がある関係を表したい。最も自然なのはどれですか。

  1. キュー
  2. 木構造
  3. スタック
  4. 受付番号の変数
第4問の解答と解説

イ　木構造

分類から枝を分ける階層なので木構造が合います。キューとスタックは主に取り出す順番を表します。

第5問　二分探索の次の比較

図の昇順の7件から42を探します。初回に25と比較した次に、候補の中央としてどの値を確認しますか。

  1. 19
  2. 25
  3. 42
  4. 56
第5問の解答と解説

ウ　42

42は25より大きいので、残る候補は31・42・56。中央は42です。

第6問　未整列の探索

値が順不同の5件から目的の番号を、並べ替えずに探します。説明が適切なのはどれですか。

  1. 線形探索で先頭から確認できる
  2. 二分探索では中央を一度見れば必ず見つかる
  3. 二分探索では順不同でも常に片側を除外できる
  4. 線形探索には事前の昇順整列が必要
第6問の解答と解説

ア　線形探索で先頭から確認できる

線形探索は一つずつ照合するので順不同でも使えます。二分探索で片側を捨てられる根拠は、値が順に並んでいることです。

第7問　選択ソートの1回目

{8, 3, 6, 2} を昇順に選択ソートします。未整列部分の最小値と先頭を交換した直後はどれですか。

  1. {3, 6, 2, 8}
  2. {2, 3, 6, 8}
  3. {3, 8, 6, 2}
  4. {8, 3, 2, 6}
第7問の解答と解説

イ　{2, 3, 6, 8}

全体の最小値2と先頭8を交換します。アは同じ入力を左からバブルソートで1周した結果です。この例で交換後に全体が昇順なのは元の中央2要素も昇順だったためです。

第8問　整列済みの列を併合

左 {3, 7, 12} と右 {3, 5, 10} を昇順で併合します。同じ値も残すなら、最初の3件はどれですか。

  1. 3、5、7
  2. 3、7、12
  3. 3、5、3
  4. 3、3、5
第8問の解答と解説

エ　3、3、5

同値の3を片方から出しても、もう片方の先頭に3が残ります。次にその3を出すと、残る左右の先頭7と5の小さい方は5です。
