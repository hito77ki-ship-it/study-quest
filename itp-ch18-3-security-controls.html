人・場所・機器に対策を分けて置く

人的対策には教育や確認手順、物理的対策には施錠、監視カメラ、セキュリティケーブルなどがあります。入退室管理ではICカードなどを使い、アンチパスバックでは退室記録のないカードで再入室できないようにするなど、カードの使い回しを防ぎます。インターロックは二つの扉が同時に開かないようにする仕組みです。クリアデスクは紙の資料を机に残さず、クリアスクリーンは離席時に画面をロックするなどの対策です。

アクセス制御では、受付係は名簿を読めるが、設定を変更できるのは管理者だけ、というように権限を分けます。業務に必要な最小限に絞るのが最小権限です。貸与端末をMDMで管理し、画面ロックや更新のルールを適用できます。遠隔消去などが可能かは製品と設定によります。

WAFWebアプリへのHTTP要求などを検査し、不正な入力を遮断する。アプリ自体の修正も必要。
IDS・IPSIDSは侵入の兆候を検知し通知。IPSは不正と判断した通信を遮断できる。

SIEM複数の機器やサービスのログを集め、関連付けて分析する。
検疫ネットワーク接続する端末の状態を確認し、基準を満たさない端末の接続を制限する。

VPNは共有の回線などの上に仮想的な専用網を作ります。インターネットVPNは公衆インターネットを利用し、暗号化などで通信を保護する構成が一般的です。IP-VPNは通信事業者の閉域IP網を使うサービスの例です。閉域網でも暗号化の有無は別に確認します。Webの通信保護に使うTLSは旧来のSSLを置き換えた技術です。

URLフィルタリングはURLなどを基準に閲覧を制限し、コンテンツフィルタリングは内容などから制限します。ペアレンタルコントロールは子どもの利用時間や閲覧などを保護者が管理する仕組みです。Wi-Fiでは対応機器に応じてWPA2やWPA3を設定し、家庭用などでは事前共有鍵（PSK）を使う方式があります。SSIDの非表示やMACアドレスによる許可設定だけでは、暗号化や認証の代わりになりません。

感染を広げず、戻せることを確かめる

バックアップを一定期間書き換えられなくするのがイミュータブルバックアップです。WORMは一度書いたデータを繰り返し読める仕組みです。バックアップ先を本番と同じ権限で常に操作できる設計では、同時に被害を受ける場合があります。

端末の更新とマルウェア対策ソフトは被害を抑えるために使います。感染が疑われるときは、組織の手順に沿って端末をネットワークから隔離し、担当者へ連絡します。状況の調査前にログやファイルを消去しないことも大切です。デジタルフォレンジックスは証拠を保全して調べること、ペネトレーションテストは許可された範囲で攻撃を模擬して弱点を確かめることです。

設計段階から攻撃への備えを組み込むのがセキュリティバイデザイン、プライバシーを組み込むのがプライバシーバイデザインです。受付フォームなら、公開前に入力と権限をテストし、集める項目を必要最小限にします。IoT機器も、更新方法や初期設定、接続先を設計時から確認します。

ほかの用語も、守る対象から区別する

セキュアイレースストレージが備える消去機能などで残存データを読めない状態にする。媒体や機器に合う手順を選ぶ。
耐タンパ性ICカードなどへの物理的・論理的な解析や改変を難しくする。
電子透かし画像などに識別情報を埋め込み、出所の確認などに使う。
ブロックチェーンブロックをハッシュなどで連結して、記録の改ざんを困難にする。
コールバック登録済みの連絡先へかけ直し、接続や連絡の相手を確認する方式の例。

例題9問と解説

Study Quest編集部の自作問題です。先に答えを考えてから、各問の「解答と解説」を開いてください。

第1問　事前に人が確かめる

名簿の添付送信前に別の担当者と送信先を確認します。どの種類の対策ですか。

  1. 物理的
  2. 人的
  3. 暗号鍵交換
  4. 伝送制御
第1問の解答と解説

イ　人的

確認手順や教育に関する取組なので人的対策です。

第2問　カードの使い回し

退室の記録がないカードでは再入室できないようにします。何ですか。

  1. WAF
  2. SIEM
  3. アンチパスバック
  4. 暗号化
第2問の解答と解説

ウ　アンチパスバック

入退室の順番を管理し、同じカードの使い回しを抑える対策です。

第3問　公開サーバを分ける

外部から見せるWebサーバと、名簿を扱う内部を分けます。公開サーバを置く領域の例はどれですか。

  1. DMZ
  2. TPM
  3. DNSキャッシュ
  4. プロキシのパスワード
第3問の解答と解説

ア　DMZ

DMZは外部公開サーバを内部ネットワークと分けて配置するための領域です。

第4問　Webアプリの入力を調べる

受付サイトへ送られた不正なHTTP要求をWebアプリ向けのルールで検査します。何を使いますか。

  1. MDM
  2. EDR
  3. 遠隔バックアップ
  4. WAF
第4問の解答と解説

エ　WAF

WAFはWebアプリへの要求などを調べます。アプリ側で原因となる脆弱性を修正することも必要です。

第5問　検知した通信を止める

不正と判断した通信を検知し、その場で遮断することが目的です。どれですか。

  1. IDSの通知のみ
  2. IPS
  3. WORM
  4. ICカード
第5問の解答と解説

イ　IPS

IPSは不正な通信の検知に加え、遮断できる仕組みです。

第6問　ログを関連付ける

受付サーバ、端末、ファイアウォールの記録を一か所で関連付けて異常を調べます。何ですか。

  1. PSK
  2. TPM
  3. SIEM
  4. VPN
第6問の解答と解説

ウ　SIEM

複数のログを集めて分析するのがSIEMです。

第7問　バックアップの数

本番の1つと、別媒体にある控え1つだけです。3-2-1のうち、まず足りていないと分かるのはどれですか。

  1. 3つのコピー
  2. 2種類の媒体
  3. 複製を全て本番へ移すこと
  4. バックアップを作らないこと
第7問の解答と解説

ア　3つのコピー

元データを含めて2つです。3つにするためにバックアップをもう一つ作り、別の場所にも置く必要があります。

第8問　調査に使える記録を残す

受付PCのログを保全し、事故の経緯を調べます。何の例ですか。

  1. 電子透かし
  2. ペアレンタルコントロール
  3. IP-VPN
  4. デジタルフォレンジックス
第8問の解答と解説

エ　デジタルフォレンジックス

事故の調査に使える証拠を保全し、分析する取組です。

第9問　端末の設定をまとめる

貸与スマホの画面ロックや利用設定をまとめて管理します。何ですか。

  1. VPN
  2. MDM
  3. IDS
  4. WORM
第9問の解答と解説

イ　MDM

組織のモバイル端末を管理する仕組みがMDMです。
