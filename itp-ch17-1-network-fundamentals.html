校内のLANから、校外のネットワークへ

文化祭の受付では、パソコンとプリンターが校内で通信し、案内サイトには来場者の自宅からもアクセスします。同じ校舎や敷地などの限られた範囲を結ぶのがLAN、離れた拠点のネットワークなどを広い範囲で結ぶのがWANです。インターネットは、世界中のネットワークが相互につながったものです。

校内だけに公開する連絡ページはイントラネットの例です。ネットワークを外部の協力会社などにも限定して開く仕組みはエクストラネットと呼びます。一般の来場者向けWebとは、利用できる範囲が異なります。

接続装置は、どの宛先を見て何をする？

有線LANではイーサネットを使うのが一般的です。端末のNIC（ネットワークインタフェースカードなど）やLANポートに、より対線（ツイストペア）のLANケーブルなどを接続します。光ファイバーでは光で信号を伝えます。PoEに対応した機器なら、LANケーブルを通じてアクセスポイントなどに電力も送れます。

ネットワーク機器の役割を見分ける
装置仕事文化祭での例
リピータ・リピータハブ信号を再生し、ハブでは他ポートへも送る宛先で振り分けずに伝える
ブリッジ・L2スイッチ宛先MACアドレスを使ってフレームを転送受付PCから同じLANのプリンターへ
ルーター・L3スイッチ宛先IPアドレスを使い別ネットワークへ転送校内の端末から外部サイトへ
無線アクセスポイント（AP）無線端末をLANに接続する来場者のスマホをWi-Fiにつなぐ

MACアドレスは同じリンク上でデータを運ぶ際に使う識別子で、端末がランダム化して使う場合もあります。IPアドレスはネットワークをまたぐ配送にも使います。同じLANにない宛先への経路が別に設定されていなければ、端末はデフォルトゲートウェイへ渡します。プロキシは端末に代わってWebなどに接続する中継役です。SDNでは通信の制御をソフトウェアで行い、構成や転送方針を変更しやすくします。

無線LANの主な規格はIEEE 802.11系列です。2.4 GHz帯はほかの機器と干渉することがあり、5 GHz帯や6 GHz帯も機器や利用条件に応じて使い分けます。Wi-Fi 4・5・6は世代を表し、Wi-Fi 6EはWi-Fi 6の利用を6 GHz帯にも広げたものです。アドホックモードは無線APを介さず端末間で通信する形態です。

校門の混雑を、少ない電力で知らせる

距離・データ量・電池で選ぶ
条件候補判断の理由
受付のすぐ近くへ短い識別信号BLEビーコン近距離で小さな情報を発信する。
離れた設備から少量の観測値LPWA広い範囲を低消費電力で結ぶ用途に向く。
届きにくいセンサーを順に中継マルチホップ複数の機器を経由して届ける。
校内の機器をまとめて接続IoTエリアネットワーク設置場所の近くでデータを受ける。

BLE（Bluetooth Low Energy）は低消費電力の近距離通信に、LPWA（Low Power Wide Area）は遠距離・少量のデータに使われます。ビーコンは識別用などの信号を発信する機器です。環境の光や振動などから電力を得るエネルギーハーベスティングは、通信方式とは別に電源を工夫する方法です。

写真を送る時間を、ビットにそろえて求める

小文字のbはビット、大文字のBはバイト、bpsは1秒当たりのビット数です。来場者が一斉に写真を送ると、処理や回線の待ちが増える輻輳が起きる場合があります。Wi-Fiの表示速度だけで、インターネット越しの転送が同じ速度になるとは判断できません。

例題9問と解説

Study Quest編集部の自作問題です。先に答えを考えてから、各問の「解答と解説」を開いてください。

第1問　校舎と離れた会場を結ぶ

二つの校舎にそれぞれLANがあり、数km離れた屋外会場にもLANがあります。これらを広域回線で結ぶネットワークはどれですか。

  1. NIC
  2. WAN
  3. SSID
  4. PoE
第1問の解答と解説

イ　WAN

限られた範囲の各LANを、離れた拠点まで結ぶのでWANです。

第2問　同じ箱でネットワークを分ける

配線を付け替えず、同じスイッチ上で受付用と来場者用を別の論理LANにします。何を使いますか。

  1. PoE
  2. リピータ
  3. VLAN
  4. BLE
第2問の解答と解説

ウ　VLAN

物理配線と独立して論理的なLANを分ける機能がVLANです。

第3問　宛先MACを見て転送

受付PCが同じLANのプリンターへ送ったフレームを、宛先MACアドレスを見て転送する装置はどれですか。

  1. L2スイッチ
  2. リピータハブ
  3. 無線端末のSSID
  4. 電源タップ
第3問の解答と解説

ア　L2スイッチ

L2スイッチはMACアドレスを使って転送します。リピータハブは宛先MACで振り分けません。

第4問　校外への出口

校内LANの端末から別ネットワークへ送るとき、個別の経路が設定されていません。最初にどこへ渡しますか。

  1. 校内のプリンター
  2. 同じSSIDの端末
  3. 最寄りのビーコン
  4. デフォルトゲートウェイ
第4問の解答と解説

エ　デフォルトゲートウェイ

行き先に対応する個別経路がなければ、通常は既定経路のデフォルトゲートウェイへ渡します。

第5問　天井のAPに給電

電源の差込口がない天井に、対応するLANケーブルと給電機器でAPを設置します。利用する技術はどれですか。

  1. WPS
  2. PoE
  3. NAPT
  4. LPWA
第5問の解答と解説

イ　PoE

PoEならLANケーブルで通信と給電ができます。

第6問　直接印刷する

既設の無線APがない教室で、対応するスマホからプリンターにWi-Fiで直接送ります。どれが適切ですか。

  1. メッシュWi-Fi
  2. FTTH
  3. Wi-Fi Direct
  4. VLAN
第6問の解答と解説

ウ　Wi-Fi Direct

Wi-Fi Directは対応機器同士を既設の無線APなしで接続します。

第7問　電池で遠方から送る

屋外設備の温度を、離れた受信地点へ毎時数バイト送ります。電池交換を減らしたい場合の候補はどれですか。

  1. LPWA
  2. HDMI
  3. 近接用のビーコンだけ
  4. PoEでの無線送信
第7問の解答と解説

ア　LPWA

距離が長く、少量の通信で低消費電力が必要という条件からLPWAが候補です。実際の利用には通信範囲なども確認します。

第8問　現場で混雑を判定

中央サーバに全ての観測値を送る前に、校門の近くで混雑の有無を判断します。何の例ですか。

  1. メーリングリスト
  2. 回線交換
  3. 名前解決
  4. エッジコンピューティング
第8問の解答と解説

エ　エッジコンピューティング

センサーや利用現場に近い機器でデータを処理します。

第9問　画像の送信時間

24 MBを伝送速度40 Mbps、効率60%の回線で送ります。その他の時間は無視し、1 B＝8 bitです。何秒ですか。

  1. 0.6秒
  2. 8秒
  3. 4.8秒
  4. 32秒
第9問の解答と解説

イ　8秒

24×8＝192 Mb、実効速度は40×0.6＝24 Mbpsなので、192÷24＝8秒です。
