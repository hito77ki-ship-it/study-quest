案内を音・画像・動画で届ける

図書館のイベント案内には、時間と会場の文字、部屋の写真、音声ガイド、工作の動画を載せられます。種類の異なる情報をデジタルで組み合わせて扱うのがマルチメディアです。リンクで会場図や動画へ移動できる構成はハイパーメディアの例です。印刷用の案内は、ページの構成を保って渡しやすいPDFも使えます。

動画の一枚をフレーム、毎秒の枚数をフレームレート（fps）と呼びます。30fpsで10秒なら、一定フレームレートの仮定で300枚です。H.265も映像の符号化方式で、AVIもコンテナの例です。MPEGは映像や音声などの国際規格の策定に関わるグループの名前で、その規格群も指します。DRMはコンテンツの利用や複製を制御する技術の総称で、CPRMは記録媒体に関する複製制御の例です。

音を測る頻度と、一回の値に使うビット数を分ける

PCMでは、一定の時間間隔で波形を測る標本化、測った値を段階値にする量子化、段階値をビット列にする符号化を行います。標本化周波数は1秒に測る回数、量子化ビット数は一回の値を表すビット数です。例えば16bitなら2¹⁶＝65,536段階を表せます。

無圧縮PCMのデータ量は、標本化周波数×量子化ビット数×チャンネル数×秒数です。16,000Hz・16bit・モノラルで5秒なら、16,000×16×1×5÷8＝160,000バイトです。ファイルのヘッダーなどはこの計算に含めません。

WAVはPCMを格納する用途でよく使うファイル形式です。MP3やAACは非可逆圧縮で使われる音声の符号化方式です。MIDIは演奏の音程・長さ・強さなどを扱う仕組みで、マイクで録った波形とは中身が違います。

写真と図を、何を保持したいかで選ぶ

図書館の素材から形式を選ぶ
目的形式と選ぶ理由
会場の写真一般的なJPEGは非可逆圧縮で容量を抑えやすい。再編集が必要なら元データも保管する。
文字入り画面や透過素材PNGは可逆圧縮で、透過にも対応する。
線や文字が中心の地図SVGなら座標と形で表現でき、拡大したときも輪郭を描き直せる。
色数を抑えた短いアニメGIFは1フレームの色表に最大256色。動きを持たせることもできる。

BMPやTIFFはラスター画像を扱う形式の例です。圧縮方法は形式や保存設定によります。EPSは印刷などに使われる形式で、ベクターに加えラスター画像も含められます。写真を画素で加工するペイント系と、地図の矢印や線を形として配置するドロー系の違いも押さえます。

元と同じデータに戻せるかで圧縮方式を見分ける

ランレングス法は同じ記号の連続を「記号と回数」で表します。例えば AAABB は A×3、B×2 と表せます。この表記は考え方を示す例で、短いデータが常に小さくなるとは限りません。ハフマン法では出現頻度を基に、よく現れる記号に短いビット列を割り当てるよう符号を作ります。

元のファイルが800KB、圧縮後が200KBなら、圧縮後÷元の大きさは25%、減少した割合は75%です。「圧縮率」とだけ書かれているときは、問題文がどちらの式を指定しているかを確かめます。

色、画素数、階調を混同しない

RGBは光を足す加法混色、CMYは反射する光を減らす減法混色として捉えられます。色相は赤や青など色の種類、明度は明るさ、彩度は鮮やかさです。画素は画像を構成する点で、階調は明暗や各色成分を何段階で表せるかです。各色8bitのRGBでは、成分ごとに256段階、組合せは256³＝16,777,216通りです。

1200×800ピクセルの画像を横4インチで配置すると、横は1200÷4＝300ppiです。ppiは1インチ当たりの画素数で、dpiは主にプリンターなどの1インチ当たりのドット数を表します。ピクセル数が同じ画像でも、配置する大きさを変えるとppiが変わります。

会場で体験してもらう方法を選ぶ

メタバースは利用者がアバターなどを通じて活動・交流できる仮想空間の例です。4Kや8Kは映像の画素数の規模を指します。放送の例では4Kは3840×2160、8Kは7680×4320です。画素数が増えると伝えられる細部は増えますが、配信のデータ量は符号化の条件にも左右されます。

例題10問と解説

Study Quest編集部の自作問題です。先に答えを考えてから、各問の「解答と解説」を開いてください。

第1問　音の大きさを測る回数

波形を一定の時間間隔で測る工程はどれですか。

  1. 伸長
  2. 標本化
  3. 量子化
  4. デコード
第1問の解答と解説

イ　標本化

標本化は測る時点を決める工程です。測った値を一定の段階に丸めるのは量子化です。

第2問　無圧縮音声の容量

16,000Hz、16bit、モノラルで5秒のPCMは、ヘッダーなしで何バイトですか。

  1. 16,000
  2. 80,000
  3. 160,000
  4. 1,280,000
第2問の解答と解説

ウ　160,000

16,000×16×1×5＝1,280,000ビットです。8で割って160,000バイトです。

第3問　地図の線を編集する

拡大した後も矢印の端点を個別に動かしたいとき、適した表現はどれですか。

  1. 線を図形として保持するベクター
  2. 画素を一列ずつ保存するラスター
  3. 演奏のMIDI
  4. 音声のPCM
第3問の解答と解説

ア　線を図形として保持するベクター

ベクターなら端点などの指定を変更して線を描画できます。

第4問　透明な案内アイコン

画素の値を元に戻せて、透過も使える画像形式はどれですか。

  1. 一般的なJPEG
  2. MP3
  3. MP4
  4. PNG
第4問の解答と解説

エ　PNG

PNGは可逆圧縮で透過にも対応します。

第5問　動画の入れ物と中身

工作動画の映像をH.264で符号化し、音声と一緒にMP4に入れました。適切な説明はどれですか。

  1. 両方とも動画のフレーム数
  2. H.264は符号化方式、MP4はコンテナ
  3. H.264はコンテナ、MP4は映像の符号化方式
  4. MP4には映像を格納できない
第5問の解答と解説

イ　H.264は符号化方式、MP4はコンテナ

符号化方式は映像をどう記録するか、コンテナは映像や音声をどう格納するかを定めます。

第6問　減った分を計算する

800KBの写真を200KBにしました。元から何%減りましたか。

  1. 20%
  2. 25%
  3. 75%
  4. 80%
第6問の解答と解説

ウ　75%

600KB減っています。600÷800＝0.75なので75%減です。

第7問　配布原稿を保管する

参加者用の文書をまとめ、開いたときに元のデータへ戻したい場合の選択はどれですか。

  1. 可逆圧縮を使う
  2. 画素を減らす
  3. 音声をAACで符号化する
  4. 非可逆圧縮で一部を省く
第7問の解答と解説

ア　可逆圧縮を使う

可逆圧縮なら伸長後に圧縮前と同じデータに戻せます。

第8問　画素の密度を求める

横1200ピクセルの画像を横4インチで配置します。画素の密度はいくつですか。

  1. 1200ppi
  2. 4800ppi
  3. 400ppi
  4. 300ppi
第8問の解答と解説

エ　300ppi

横幅1インチに入る画素数は1200÷4＝300です。

第9問　画面の色を作る

RGBの赤・緑・青の光をすべて最大で重ねると、基本モデルでは何色ですか。

  1. 黒
  2. 白
  3. 黄
  4. マゼンタ
第9問の解答と解説

イ　白

光の加法混色では、赤・緑・青の光を最大で重ねると白になります。

第10問　床に矢印を出す

スマホのカメラで実際の通路を映し、その映像に矢印を重ねます。該当するのはどれですか。

  1. MIDI
  2. VR
  3. AR
  4. ランレングス法
第10問の解答と解説

ウ　AR

現実に見えている場面に案内情報を重ねる拡張現実です。
