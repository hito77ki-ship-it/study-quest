処理する場所と、処理を始めるタイミングを分ける

リアルタイム処理では、事象が起きてから決められた時間内に処理することが重要です。対話型でも処理の期限が厳しいとは限りません。並列処理は複数の計算を同時に進める方式です。分散処理では、同じ役割を複数台に分けて負荷を分担する例と、画面・業務処理・データ管理のように機能で分担する例があります。

端末・サーバ・仮想環境の役割を見分ける

クライアントサーバでは利用する側と提供する側に役割が分かれます。ピアツーピアでは端末同士が対等に通信し、提供と利用の両方を担う場合があります。シンクライアントでは端末側の処理やデータ保存を少なくします。VDIはサーバ上などに仮想デスクトップを用意し、端末から利用する仕組みです。NASはネットワーク経由でファイルを共有するためのストレージです。

スケールアップは1台の性能を上げること、スケールアウトは台数を増やすことです。例えば受付サーバのメモリを増やすのは前者、同じ役割の受付サーバを追加するのは後者です。クラスタは複数の機器を連携させる構成で、性能向上や障害対応に使われます。

仮想マシンを実行する土台には、物理機器に直接載るハイパーバイザー型と、ホストOS上で仮想化ソフトを動かすホスト型があります。コンテナはOSカーネルを共有する方式で、ライブラリなどをアプリごとにまとめられます。

予備を置くなら、何を引き継げるかを確認する

機器を複数使う理由を比べる
構成運転中と障害時の違い
シンプレックス1系統で動かす。機器故障に対する代替系がない。
デュアル2系統で同じ処理を行い、結果を照合する。
デュプレックス普段は主系で処理し、異常が起きると待機系へ切り替える。
ホット／コールドスタンバイ待機系を運転して切替に備える方式と、停止状態などから起動・準備して引き継ぐ方式。

同じ容量のドライブを使うと仮定すると、2台のRAID 0は合計容量を利用でき、1台故障への冗長性はありません。2台のRAID 1は同じデータを複製するので1台分の容量です。RAID 5はパリティを分散し、1台分相当を復元用に使うため、4台で構成すると実効容量は3台分です。管理領域などは計算から除きます。

レプリケーションはデータを別の装置などに複製します。誤って削除した内容も複製先へ伝わる構成があるので、以前の状態を取り戻すためには別の世代のバックアップも確保します。

止まったとき、サービスと利用者のどちらをどう守るか

貸出機で考える信頼性設計
考え方身近な例
フォールトアボイダンス点検や耐久性の高い部品で故障を起きにくくする。
フォールトトレラント一部が故障しても代替系でサービスを続ける。
フェールソフト印刷が故障しても、画面で貸出結果を案内し基本機能は続ける。
フェールセーフ扉の異常を検知したらモーターを停止し、安全側にする。
フールプルーフ向きが逆では取り付けられないようにして、誤操作を防ぐ。

フェールソフトで続けるのは一部の機能です。安全を優先して停止する例と、故障の影響を受けにくい構成で処理を続ける例を見分けます。

応答の始まりと完了、稼働率と費用をそれぞれ測る

スループットは単位時間当たりの処理量です。5分で100件なら20件/分。1件の応答時間と、一定時間に何件処理できるかは別です。ベンチマークでは機種間で処理内容や設定などの条件をそろえます。

MTBFは故障と故障の間に動作していた時間の平均、MTTRは修復にかかった時間の平均です。稼働と停止を繰り返す単純なモデルでは、稼働率＝MTBF÷（MTBF＋MTTR）。例えば98時間動作して2時間止まる周期なら98%です。共通の電源や回線が止まる場合は、図の独立の仮定で計算できません。

バスタブ曲線は、初期故障期、故障率が比較的安定する期間、摩耗故障期を表すモデルです。TCOは導入から廃棄までの総費用で、同じ利用期間を決め、機器・電気・保守・教育などの費用を含めて比較します。

例題8問と解説

Study Quest編集部の自作問題です。先に答えを考えてから、各問の「解答と解説」を開いてください。

第1問　利用形態

閉館後に当日の貸出データをまとめて集計するのはどれですか。

  1. リアルタイム処理
  2. ピアツーピア
  3. バッチ処理
  4. ライブマイグレーション
第1問の解答と解説

ウ　バッチ処理

ためたデータを決まった時刻に一括処理しています。

第2問　負荷を分ける

同じ仕事をするサーバを2台から3台へ増やして処理量を増やしたい。どの方法ですか。

  1. スケールアップ
  2. スケールアウト
  3. コールドスタンバイ
  4. シンプレックス
第2問の解答と解説

イ　スケールアウト

1台の性能を上げるのではなく、台数を増やすのがスケールアウトです。

第3問　待機系に切り替える

通常は1系統で処理し、故障時に別の待機系が引き継ぐ構成はどれですか。

  1. デュプレックス
  2. デュアル
  3. シンプレックス
  4. ピアツーピア
第3問の解答と解説

ア　デュプレックス

デュプレックスは主系と待機系です。デュアルでは2系統が同じ処理を行い結果を照合します。

第4問　RAIDの使える容量

同じ2TBのドライブ4台でRAID 5を作ります。管理領域を除いた理論上の容量はどれですか。

  1. 2TB
  2. 4TB
  3. 6TB
  4. 8TB
第4問の解答と解説

ウ　6TB

パリティに1台分相当を使うため、（4−1）×2TB＝6TBです。

第5問　安全を優先する設計

挟み込みの可能性を検知し、異常時に投入口のモーターを止める考え方はどれですか。

  1. ベンチマーク
  2. スケールアウト
  3. フォールトアボイダンス
  4. フェールセーフ
第5問の解答と解説

エ　フェールセーフ

異常が起きたときに、安全な状態へ移す考え方です。

第6問　時間と処理量

要求の入力完了は0秒、出力開始は3秒、全結果が返るのは9秒です。別の測定で2分間に90件を処理しました。応答時間とスループットはどれですか。

  1. 3秒・45件/分
  2. 9秒・45件/分
  3. 3秒・90件/分
  4. 9秒・90件/分
第6問の解答と解説

ア　3秒・45件/分

応答時間は出力開始までの3秒。スループットは90÷2＝45件/分です。

第7問　修復時間と稼働率

MTBFが190時間、MTTRが10時間とします。この単純なモデルでの稼働率はどれですか。

  1. 90%
  2. 95%
  3. 98%
  4. 99%
第7問の解答と解説

イ　95%

190÷（190＋10）＝0.95です。分母は動作時間と修復時間の合計です。

第8問　並列で止まる確率

稼働率80%と90%の2台は、どちらか1台が動けば使えます。各装置の稼働・停止は独立で、切替による停止は無視します。全体の稼働率はどれですか。

  1. 72%
  2. 85%
  3. 90%
  4. 98%
第8問の解答と解説

エ　98%

両方が止まる確率は（1−0.8）×（1−0.9）＝0.02。稼働率は1−0.02＝0.98です。72%は両方が動く確率です。
