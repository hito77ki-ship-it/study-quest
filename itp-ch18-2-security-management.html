ITパスポート 18-2 情報セキュリティ管理

事故の候補を洗い出し、優先順位を決める

文化祭の受付で、氏名と連絡先を扱う担当者が対策を考えます。守るべき資産、弱点、事故の起こり方を整理するのがリスク特定です。発生可能性と影響の大きさを見積もるのがリスク分析、判断基準と照らして優先度や対応の要否を決めるのがリスク評価です。ここまでをリスクアセスメントと呼び、その結果を対策の選択に使います。

リスク共有には、損失の負担を契約で移す方法や、集中を避けて分散する方法があります。担当者間で前提や判断結果を共有することをリスクコミュニケーションと呼びます。

方針を、現場で守れるルールにする

ISMSは、情報セキュリティを組織で計画し、実行し、見直し続けるための仕組みです。機密性・完全性・可用性に加え、必要に応じて真正性（確かに本人・本物か）、責任追跡性（誰の操作か追えるか）、否認防止（実施した事実を後で否定しにくくする）、信頼性（期待した動作を安定して行う）も考えます。

個人情報の安全管理措置には、役割の明確化などの組織的措置、教育などの人的措置、書類の保管などの物理的措置、アクセス制御などの技術的措置があります。プライバシーポリシーは個人情報の取扱いに関する方針です。プライバシーマーク制度は個人情報を適切に取り扱う体制などを評価する制度です。サイバー保険は契約で定めた損失や対応費用に備えます。

用語を制度の目的で比べます。SECURITY ACTIONは中小企業などがセキュリティ対策への取組を自己宣言する制度です。システム管理基準は情報システムを適切に管理するための基準で、システム監査基準は監査人が監査を行うときの基準です。PCI DSSはカード会員データを保護するための業界基準です。

ウイルスや不正アクセスに関する届出と、製品などの脆弱性情報に関する届出では対象が異なります。自社で不審な動作を見つけたときの報告先と、製品の脆弱性を見つけたときの連絡先を、手順書では分けておきます。

SOCが見つけ、CSIRTが対応を調整するのは分担の一例です。小さな組織では同じ担当が担うこともあります。外部への届出や連絡は、発生した事象と適用される要件を担当者が確認して進めます。

例題9問と解説

Study Quest編集部の自作問題です。先に答えを考えてから、各問の「解答と解説」を開いてください。

第1問　何が起こり得るか列挙する

受付の名簿について、誤共有・紛失・不正な変更という事故の候補を書き出しました。どの段階ですか。

  1. リスク保有
  2. リスク特定
  3. リスク移転
  4. リスク評価
第1問の解答と解説

イ　リスク特定

特定では対象と事故の候補を洗い出します。分析で大きさを見積もり、評価で基準と照合します。

第2問　優先対応の基準と比べる

可能性3、影響4で積を計算します。9以上を優先する架空の基準に従うとどれですか。

  1. 7なので対象外
  2. 7なので優先
  3. 12なので優先
  4. 12なので対象外
第2問の解答と解説

ウ　12なので優先

分析結果は3×4＝12。評価では優先の基準9以上を満たします。

第3問　連絡先を集めない

連絡先なしで受け付ける運用に切り替え、連絡先の漏えいリスクの原因をなくしました。何ですか。

  1. 回避
  2. 移転
  3. 保有
  4. 低減
第3問の解答と解説

ア　回避

対象リスクを生む活動をやめたので回避です。

第4問　保険に加入

事故時の一部費用を、契約条件内で保険会社に負担してもらいます。何の例ですか。

  1. 保有
  2. 回避
  3. 検知
  4. 共有・移転
第4問の解答と解説

エ　共有・移転

損失の負担を他者と分ける例です。事故の防止策とは役割が異なります。

第5問　具体的なクリック手順

共有画面を開き、担当者を選び、閲覧権限を付けると文書に書きました。どの文書に相当しますか。

  1. 基本方針
  2. 実施手順
  3. プライバシーマーク
  4. サイバー保険証券
第5問の解答と解説

イ　実施手順

画面での具体的な操作を定めているので実施手順です。

第6問　第三者が使えないことを確かめる

PDCAで共有設定を変更した後、許可のないテスト用アカウントで読めないことを確かめます。どれですか。

  1. Plan
  2. Do
  3. Check
  4. Act
第6問の解答と解説

ウ　Check

決めた対策が働くかの確認なのでCheckです。発見事項に対応し次の運用を改善するのはActです。

第7問　誰が変更したか追える

受付表の変更者と時刻を確認できるようにします。着目する要素はどれですか。

  1. 責任追跡性
  2. 可用性
  3. 機密性
  4. 分離レベル
第7問の解答と解説

ア　責任追跡性

操作の主体や経緯を追えることが責任追跡性です。

第8問　事故対応を調整

監視で異常を見つけた後、関係者への連絡と復旧の分担を調整します。担当の例はどれですか。

  1. JVN
  2. ISMAP
  3. 認証局
  4. CSIRT
第8問の解答と解説

エ　CSIRT

CSIRTは事故対応の調整を担います。SOCの代表的な役割は監視と異常の検知です。

第9問　制度の対象を見分ける

政府向けの調達候補となるクラウドサービスを評価・登録する制度はどれですか。

  1. プライバシーマーク
  2. ISMAP
  3. J-CSIP
  4. JVN
第9問の解答と解説

イ　ISMAP

ISMAPは政府のクラウド調達でのセキュリティ水準確保を目的とする制度です。
