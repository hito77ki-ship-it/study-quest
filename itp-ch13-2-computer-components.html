CPUの役割と、速さを見る条件

CPUは命令を実行し、演算や機器の制御を担います。クロック周波数は1秒当たりのクロックの回数で、2GHzなら1秒に20億周期です。1周期当たりの仕事量、コア数、メモリ待ちやアプリの作りも関係するので、周波数だけで機種の速さは決まりません。

マルチコアCPUは複数のコアを備え、同時に進められる処理を分担できます。GPUは描画など、多数の似た計算を並行して行う処理に向きます。描画以外の計算にGPUを使うことをGPGPUと呼びます。CPUの32ビット・64ビットは扱うデータ幅などに関わる区分で、処理が必ず2倍になるという意味ではありません。

編集中の内容と、保存済みファイルを区別する

主記憶によく使うDRAMは電荷を保持するためにリフレッシュが必要です。キャッシュなどに使うSRAMは通電中のリフレッシュが不要で、一般に高速です。どちらも通常、電源を切ると内容を失う揮発性メモリです。ROMは電源を切っても内容が残り、起動時のプログラムなどに使われます。フラッシュメモリは電源を切っても記憶を保ち、消去・書換えができます。

SDRAMはクロックと同期して動くDRAMです。DDRはクロックの立上がりと立下がりを使う方式で、DDR4・DDR5などの世代があります。DIMMとSO-DIMMはメモリモジュールの形の区分で、SO-DIMMは小型です。交換するなら、形状と世代の両方を確認します。

長く保存する媒体を、記録の仕組みと用途から選ぶ

HDDでは一つのファイルが離れた場所に分かれると、読み取り位置の移動が増える場合があります。これが断片化です。光ディスクではCD-ROMなどの読出し専用、CD-RやDVD-Rなどの追記型、CD-RWやBD-REなどの書換え型を見分けます。

差し込める形と、使える機能を別々に確認する

DisplayPortも映像・音声に使われます。アナログRGBは映像をアナログ信号で伝える例です。DVIにはデジタルやアナログに対応する種類があり、IEEE 1394は映像機器などに使われた有線規格です。IrDAは赤外線、Bluetoothは電波を使います。RFIDは無線でタグの情報を読む技術の総称で、通信距離は方式や機器によって異なります。

シリアル伝送では同じ伝送路でビットを順に送り、パラレル伝送では複数の伝送路で並べて送ります。この区分だけで実際の速度の優劣は決まりません。デバイスドライバはOSが機器を制御するためのソフトウェアで、プラグアンドプレイでは接続した機器の検出や設定を自動化します。対応ドライバが必要な場合もあります。

センサーで測り、アクチュエータで現実を動かす

光学センサーは光、加速度センサーは加速度、ジャイロセンサーは回転の速さ、圧力センサーは圧力を測ります。磁気センサーで磁界を捉えたり、超音波が戻る時間から距離を求めたりする例もあります。モーターや電磁弁は、制御信号を受けて物理的な動きを起こす部品です。

例題8問と解説

Study Quest編集部の自作問題です。先に答えを考えてから、各問の「解答と解説」を開いてください。

第1問　仕事を分ける

CPUを変えずGPUを使う計算に向いている例はどれですか。

  1. 画像の多数の画素に同じ種類の演算をする
  2. 紙をスキャンする
  3. SSDに印刷する
  4. タッチパネルの位置を読み取る
第1問の解答と解説

ア　画像の多数の画素に同じ種類の演算をする

画素ごとに行う似た演算は並行処理に向きます。

第2問　クロックの読み方

同じ3GHzの二つのCPUについて、仕様から言えることはどれですか。

  1. 同じ時間で必ず同じ仕事を終える
  2. 同じ周波数で動作する条件なら1秒当たりの周期数は同じ
  3. コア数が同じ
  4. キャッシュ容量が同じ
第2問の解答と解説

イ　同じ周波数で動作する条件なら1秒当たりの周期数は同じ

GHzが示すのは周期数です。性能を比べるときは処理や構成も見ます。

第3問　停電前の保存

自動保存がなく、変更がRAMだけにある状態で電源が落ちました。SSDに保存済みの旧版は壊れていないとします。どれが残りますか。

  1. RAMの変更だけ
  2. 旧版とRAMの変更
  3. SSDに保存済みの旧版
  4. どちらも必ず消える
第3問の解答と解説

ウ　SSDに保存済みの旧版

通常のRAMは揮発性です。SSDに書き込まれていた旧版が残ります。

第4問　記憶階層の順番

CPUに近い側から並べたものはどれですか。

  1. SSD→主記憶→キャッシュ
  2. 主記憶→SSD→キャッシュ
  3. キャッシュ→SSD→主記憶
  4. キャッシュ→主記憶→SSD
第4問の解答と解説

エ　キャッシュ→主記憶→SSD

キャッシュにはよく使う内容の一部、主記憶には実行中のデータ、SSDには保存したファイルがあります。

第5問　書換えできる光ディスク

教材を何度も書き換えて使う場合の候補はどれですか。

  1. CD-RW
  2. CD-ROM
  3. CD-R
  4. DVD-R
第5問の解答と解説

ア　CD-RW

RWは書換え型です。Rは追記型、ROMは読出し専用です。

第6問　同じ形の端子

USB Type-C端子で外部画面を使えるか確かめるには何を見ますか。

  1. 端子の形だけ
  2. PC・画面・ケーブルの映像対応
  3. SSDの空き容量
  4. Bluetoothの設定だけ
第6問の解答と解説

イ　PC・画面・ケーブルの映像対応

同じ端子の形でも対応機能は異なります。必要な映像方式を、機器とケーブルそれぞれで確認します。

第7問　機器とOSの橋渡し

新しいスキャナーの操作をOSから行うためのソフトウェアはどれですか。

  1. キャッシュ
  2. センサー
  3. デバイスドライバ
  4. HDMIケーブル
第7問の解答と解説

ウ　デバイスドライバ

デバイスドライバがOSと機器の間で制御を仲立ちします。

第8問　測る部品と動かす部品

人の接近を検知して扉を開ける場合、モーターの役割はどれですか。

  1. 光の計測
  2. 通信速度の計測
  3. 条件式の判定
  4. 制御信号に応じて扉を動かす
第8問の解答と解説

エ　制御信号に応じて扉を動かす

モーターはアクチュエータです。接近を検知する入力側がセンサーです。
