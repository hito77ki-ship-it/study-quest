作りたいものからソフトを選ぶ

検索条件の考え方では、ANDは両方を含め、ORはいずれかを含め、NOTは指定した条件を除きます。検索サービスによって入力記法が異なるので、サービスのヘルプで指定方法を確かめます。

表の位置を読み、コピー後の参照を追う

読書会の資料費。F1には共通単価50円を入力
行A列 資料B列 枚数C列 資料費
2案内4200円
3ワークシート6300円
4アンケート2100円

列と行の交点がセルです。B3はB列の3行目、B2:B4は縦に並んだ3セルを表します。別のシートを参照するときはシート名も指定できます。例えば 料金!F1 は「料金」シートのF1を指します。

C2に =B2*$F$1 と入力し、C4までコピーすると、4×50＝200円、6×50＝300円、2×50＝100円です。ここで B2 は相対参照、$F$1 は列と行を固定した参照です。$B2 は列だけ、B$2 は行だけを固定します。実際の表計算ソフトでは、片方だけ固定する指定を複合参照と呼ぶこともあります。

式は括弧を先に計算し、その後に乗除、加減の順で計算します。例えば 4+2*50 は104、(4+2)*50 は300です。数量の合計を求めてから単価を掛ける場合は括弧を付けます。

集計と判定を分け、式の答えを小さな表で確かめる

よく使う集計と判定
目的試験で使う名前とこの表での例
合計と平均合計(B2:B4)は12、平均(B2:B4)は4。
最大と最小最大(B2:B4)は6、最小(B2:B4)は2。
個数と条件付個数試験の「個数」は空白以外を数える。「条件付個数」で5以上を数えると1。
整数部と剰余整数部は値以下で最大の整数。剰余は割った余り。例えば剰余(14,4)は2。

表計算ソフトで試すときは関数名や条件の書き方が異なります。例えばExcelで空白以外を数える関数は COUNTA、数値を数える関数は COUNT です。試験問題は問題文やIPAの表記に従います。

条件が三つなら、例えば =IF(B3>=8,"特大",IF(B3>=5,"多め","通常")) のようにIFを入れ子にできます。上から境界を見て、8、5、4を一つずつ当てはめると、等号の漏れに気づけます。

表示する行と、分類して集計する表を分ける

土曜の午前3人・午後5人、日曜の午前2人・午後6人なら、曜日別の合計はどちらも8人です。会場や時間帯も並べれば、合計が同じでも内訳が違うことを確認できます。

ソースを読めることと、配布の条件を確かめる

オープンソースの定義では、ソースコードを入手でき、改変や再配布が許されることなどが求められます。販売も可能で、著作権は保持されます。無保証の条項がある場合、別契約でサポートを受けられるかとは区別します。

GPLはコピーレフト型の例です。GPLの対象となる改変版を配布する場合は、GPLに沿った配布や、受領者が対応するソースコードを入手できるようにする条件などを確認します。GPLのプログラムを組織内だけで改変して使う場合、改変したソースを一般公開する義務はGPLからは生じません。

例題10問と解説

Study Quest編集部の自作問題です。先に答えを考えてから、各問の「解答と解説」を開いてください。

第1問　仕事に合う道具

読書会の参加人数を会場別に集計したい。最も直接使えるのはどれですか。

  1. 文書作成ソフト
  2. 表計算ソフト
  3. 画像閲覧ソフト
  4. 印刷ドライバ
第1問の解答と解説

イ　表計算ソフト

表計算ソフトで元の記録を表にし、会場別に数えたり合計したりできます。

第2問　数式を二行下にコピー

C2の =B2*$F$1 をC4へコピーしたときの式はどれですか。

  1. =B2*$F$3
  2. =B4*$F$3
  3. =B4*$F$1
  4. =B2*$F$1
第2問の解答と解説

ウ　=B4*$F$1

数量の相対参照B2はB4へ移り、列と行を固定した$F$1は動きません。

第3問　行だけを固定

式の中の B$2 を1列右・1行下へコピーすると、参照はどれになりますか。

  1. C$2
  2. B$3
  3. $C3
  4. B$2
第3問の解答と解説

ア　C$2

列のBに$がないのでCへ移ります。行の2は$で固定されています。

第4問　境界を含める

枚数が5以上なら「多め」、そうでなければ「通常」です。ちょうど5枚の場合はどれですか。

  1. 通常
  2. 空白
  3. エラー
  4. 多め
第4問の解答と解説

エ　多め

「以上」は同じ値を含むので、条件が真のときの「多め」です。

第5問　関数の名前を読む

IPAの表計算の記法で、値が4、文字列「欠席」、空白の3セルを「個数」で数えるといくつですか。

  1. 1
  2. 2
  3. 3
  4. 4
第5問の解答と解説

イ　2

試験の「個数」は空白以外を数えます。4と「欠席」の2セルです。

第6問　曜日で集計する

同じ曜日に複数の申込があり、曜日と会場の組合せごとの人数合計を表にしたい。どの機能が適していますか。

  1. 拡張子の変更
  2. クリップボードの消去
  3. ピボットテーブル
  4. プリンターの設定
第6問の解答と解説

ウ　ピボットテーブル

曜日と会場を分類の項目、人数を合計する値に指定します。

第7問　OSSを見分ける

コードが閲覧でき、配布条件で改変と再配布が認められるソフトを利用します。まず確かめるのはどれですか。

  1. 配布元が示すライセンス
  2. アイコンの色
  3. ファイルの拡張子だけ
  4. インストール先の文字数
第7問の解答と解説

ア　配布元が示すライセンス

ソースの閲覧だけで条件は分かりません。使う版や部品のライセンスを確認します。

第8問　GPLの改変版を配布する

GPLの対象となる改変版を外部の参加者へ渡します。適切な確認はどれですか。

  1. 常にライセンス表示を取り除く
  2. 配布先を一人に絞れば確認は不要
  3. 無償なので表示やソース提供の条件はない
  4. GPLに沿ってソースの提供方法や表示の条件を確認する
第8問の解答と解説

エ　GPLに沿ってソースの提供方法や表示の条件を確認する

配布時の条件をライセンス本文で確認します。代金を取らない配布でも、条件の確認が必要です。

第9問　整数部の向き

IPAの記法で整数部(−2.4)の結果はどれですか。

  1. −2
  2. −3
  3. 2
  4. 3
第9問の解答と解説

イ　−3

元の値以下で最大の整数を求めます。−2は−2.4より大きく、−3が条件に合います。

第10問　表示だけを絞る

名簿の元データは保持し、土曜の申込行だけを一時的に表示したい。どの操作ですか。

  1. 土曜以外を削除する
  2. 列をすべて隠す
  3. 曜日でフィルターを掛ける
  4. セルの参照を固定する
第10問の解答と解説

ウ　曜日でフィルターを掛ける

フィルターは条件に合う行を表示します。対象外の行も元の表に残ります。
