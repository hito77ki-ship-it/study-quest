ITパスポート 14-1 OSの役割と種類

図書館の読書会を例に、OS、ミドルウェア、マルチタスク、スプーリング、代表的なOSを学びます。

アプリの操作は、OSを通じて機器に届く

図書館で読書会を開きます。スタッフは文書作成ソフトで案内を書き、プリンターで配布用の紙を出します。文書の編集や印刷の指定を行うのがアプリケーションで、CPUやメモリ、ファイル、周辺機器などの資源を管理してアプリから利用できるようにするのがOSです。

ミドルウェアは複数のアプリが使う機能を提供するソフトウェアです。例えば、受付アプリと集計アプリが共通して利用するデータベース管理システムが該当します。OS、ミドルウェア、アプリの役割を、どの仕事を引き受けているかで区別します。

複数の仕事にCPUやメモリを割り当てる

マルチタスクでは複数のタスクを並行して進めます。コアが1個でもOSがCPU時間を短く配分すれば、編集と表計算を交互に進められます。複数のコアがあれば、実行できる仕事を同時に進められる場合があります。マルチスレッドでは一つのプロセスの中でも複数の実行の流れを持てます。

OSは利用者ごとの設定やプロファイル、アクセス権も管理します。仮想記憶ではアプリに仮想的なアドレス空間を与え、必要に応じて補助記憶も利用します。補助記憶への退避が増えると、読み書きの待ちが発生する場合があります。

印刷の順番待ちを引き受けるスプーリング

デバイスドライバはOSと周辺機器の制御を仲介します。プラグアンドプレイでは機器の検出と設定が自動化され、対応ドライバが必要になる場合もあります。スプールの待ち行列と、CPUをどのタスクに割り当てるかは別の処理です。

OSの種類と、ファイルを渡すときに見ること

主なOSを、使う場所で思い出す
名称身近な例や特徴
Windows・macOS・ChromeOSパソコンで使う例。macOSはMac、ChromeOSはChromebookなどで使われる。
UNIX・LinuxUNIX系のOSはサーバなどで使われる。Linuxは公開されたカーネルで、他のソフトウェアと組み合わせてディストリビューションとして使う。

例題6問と解説

Study Quest編集部の自作問題です。先に答えを考えてから、各問の「解答と解説」を開いてください。

第1問　印刷を仲介する

プリンターを利用するため、アプリからの要求を受けて機器の利用を管理するソフトウェアはどれですか。

  1. 案内文のテンプレート
  2. OS
  3. 印刷済みのPDF
  4. SSDの空き容量
第1問の解答と解説

イ　OS

OSは機器の利用を管理し、対応するドライバなどを通じてアプリから印刷できるようにします。

第2問　二つの仕事を進める

1コアのCPUで文章編集と表計算の処理時間を小刻みに割り当てます。どの機能ですか。

  1. 世代管理
  2. 文字コード変換
  3. マルチタスク
  4. ファイル圧縮
第2問の解答と解説

ウ　マルチタスク

各タスクに実行時間を配り、処理を交互に進めるマルチタスクです。

第3問　印刷の待ち行列

印刷要求を一時保管し、プリンターが空いてから送る仕組みはどれですか。

  1. スプーリング
  2. 仮想記憶
  3. アクセス権の継承
  4. バックアップ
第3問の解答と解説

ア　スプーリング

印刷データを一時的に保持して、プリンターの準備に合わせて出力します。

第4問　利用者の設定を分ける

利用者ごとにアカウントとフォルダの利用権限を設定するのは、OSのどの機能に当たりますか。

  1. 画像の描画
  2. 印刷順の調整
  3. 文章校正
  4. ユーザー管理
第4問の解答と解説

エ　ユーザー管理

利用者やグループを識別し、それぞれのアクセス権や設定を管理します。

第5問　共通の機能を使う

受付アプリと集計アプリが同じデータベース管理システムを利用します。この共通ソフトの位置付けはどれですか。

  1. 周辺機器
  2. ミドルウェア
  3. 印刷スプール
  4. 利用者のプロファイル
第5問の解答と解説

イ　ミドルウェア

アプリが共通して利用する機能を提供するので、ミドルウェアの例です。

第6問　文字化けを調べる

別の端末にCSVを渡すと、日本語だけ正しく表示されません。まず確かめるものはどれですか。

  1. ディスプレイの大きさ
  2. キーボードの接続方式
  3. 保存時と読込み時の文字コード
  4. プリンターの用紙サイズ
第6問の解答と解説

ウ　保存時と読込み時の文字コード

CSVに使われた文字コードと、アプリが読込みに使う文字コードが違うと文字化けします。
