ネットワークの仕事を7層と4層で整理する

文化祭の案内サイトを開くスマホと、ページを返すサーバは別の機器です。それでも通信できるのは、データの形式や送る順序などを共通の通信プロトコルで決めているからです。通信の仕事を層に分けると、今困っているのが接続、宛先、届き方、サービスのどこかを考えられます。

下から上へ、どんな仕事をするか
OSIの層イメージ
1 物理層電気・光・電波でビットを運ぶ。
2 データリンク層同じリンクでフレームを渡す。例はイーサネット。
3 ネットワーク層異なるネットワークを越えて宛先へ届ける。例はIP。
4 トランスポート層端末上の通信先を区別し、方式に応じて届き方を制御。例はTCP・UDP。
5 セション層やり取りを始めたり、終えたりするための対話を管理する。
6 プレゼンテーション層データの表現形式を扱う。文字や値を双方で解釈できる形にする。
7 アプリケーション層Webなどアプリケーションに必要な通信機能を提供する。

TCP/IP階層モデルでは、ネットワークインタフェース層・インターネット層・トランスポート層・アプリケーション層の4層に整理します。イーサネットは近くの区間、IPは宛先までの配送、TCPやUDPは機器上の通信先、HTTPなどはサービス固有のやり取りを担います。

IP・TCP・UDP・ポート番号を区別する

TCPはデータを順序どおりに渡す仕組みを備え、届かなかった部分を再送できます。UDP自体には再送や順序保証がありません。少し欠けても早く次の音声を再生したいアプリなどが利用します。必要に応じ、アプリや上位のプロトコルが信頼性を補うこともあります。HTTP/3ではQUICを使うので、Web通信が全てTCPというわけではありません。

IPは宛先のネットワークへパケットを届けるための仕組みです。各ルーターが次の転送先を判断します。TCPの再送のような処理をIP単独に期待するのは適切ではありません。

Web、メール、端末設定のプロトコルを選ぶ

したいことから名前を選ぶ
したいことプロトコル役割
案内ページを取得HTTP・HTTPS要求と応答。HTTPSはTLSで通信を保護する。
メールを送る・サーバ間で運ぶSMTP送信や配送。
メールを端末で取得POP3メールサーバから端末側に取得。設定によってサーバに残すこともある。
複数端末からメールを管理IMAPサーバ上のメールやフォルダーの状態を参照・操作。
ファイルを送受信FTPファイル転送。通常のFTPは暗号化を前提としない。
離れた端末を操作Telnet・SSH遠隔操作。SSHは通信を暗号化できる。
端末にIPなどを配るDHCPIPアドレスなど接続設定を自動配布。
時計をそろえるNTPネットワーク越しに時刻を合わせる。

IoTでは、必要なデータ量や電力に合わせてプロトコルを選びます。例えばセンサーが値を発行し、必要な端末だけが受け取る構成では、仲介役が配信するMQTTの発行・購読モデルが候補になります。

例題9問と解説

Study Quest編集部の自作問題です。先に答えを考えてから、各問の「解答と解説」を開いてください。

第1問　同じ形式でやり取り

異なる製品の受付PCとサーバが、同じ形式・手順でデータをやり取りします。その約束は何ですか。

  1. プロトコル
  2. MACアドレス
  3. 通信距離
  4. 帯域
第1問の解答と解説

ア　プロトコル

通信プロトコルは送受信側が共有する取り決めです。

第2問　OSIで経路を選ぶ

別のネットワークへの配送を担当するOSIの層はどれですか。

  1. データリンク層
  2. ネットワーク層
  3. セション層
  4. プレゼンテーション層
第2問の解答と解説

イ　ネットワーク層

異なるネットワークを越えて届けるのがネットワーク層です。同じリンクでフレームを渡すのはデータリンク層です。

第3問　サービスの入口を区別

同じIPアドレスのサーバで、別々のサービスの通信先を区別したいときに用いる番号はどれですか。

  1. SSID
  2. 伝送効率
  3. ポート番号
  4. SIM番号
第3問の解答と解説

ウ　ポート番号

ポート番号は一つの機器の中で通信先を区別するのに使います。IPアドレスは宛先機器側の識別に使います。

第4問　順番に届ける

案内データを順序どおりに届け、欠けた部分をプロトコルが再送する方式はどれですか。

  1. UDP単独
  2. IP単独
  3. イーサネット単独
  4. TCP
第4問の解答と解説

エ　TCP

TCPは順序を扱い、損失を検知して再送します。UDP単独はその処理を備えていません。

第5問　端末がIPを受け取る

来場者の端末にIPアドレスなどの接続設定を自動配布したいときに使うのはどれですか。

  1. DHCP
  2. SMTP
  3. IMAP
  4. NTP
第5問の解答と解説

ア　DHCP

DHCPは接続設定の配布を行います。DNSは接続先の名前に対応する情報を探す仕組みです。

第6問　既読を別端末でも見る

PCで付けた既読状態を、同じメールボックスを開くスマホでも利用したい。用途に合うのはどれですか。

  1. FTP
  2. IMAP
  3. SMTP
  4. Telnet
第6問の解答と解説

イ　IMAP

IMAPはサーバ上のメールや状態を扱えます。SMTPは配送側のプロトコルです。

第7問　時計の時刻を合わせる

受付端末の時計をネットワーク経由で時刻サーバに合わせます。使うのはどれですか。

  1. HTTP
  2. POP3
  3. NTP
  4. DHCP
第7問の解答と解説

ウ　NTP

NTPは時刻の同期に使います。DHCPで時刻サーバの情報を配る構成があっても、時刻の同期そのものとは別の仕事です。

第8問　通信を暗号化する

Webで受付情報を送るとき、TLSで通信を保護する方式はどれですか。

  1. 平文のFTP
  2. HTTPのみ
  3. POP3のみ
  4. HTTPS
第8問の解答と解説

エ　HTTPS

HTTPSではTLSを使って通信を保護します。

第9問　HTTPがTCPを使う例の下の層

図のHTTP/1.1の例で、TCPの下にあり、IPアドレスを使うTCP/IPの層はどれですか。

  1. インターネット層
  2. アプリケーション層
  3. トランスポート層
  4. プレゼンテーション層
第9問の解答と解説

ア　インターネット層

TCPはトランスポート層、IPはその下のインターネット層にあります。
