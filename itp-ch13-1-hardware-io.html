ITパスポート 13-1 ハードウェアと入出力装置

図書館の貸出機を例に、コンピュータの種類、スキャナーとOCR、プリンターなどの入出力装置を学びます。

機器の名前から、任せる仕事を見分ける

図書館では、職員がPCで貸出を受け付け、利用者はスマートフォンで蔵書を検索します。館内の自動返却機は制御用のコンピュータで動きます。ハードウェアは、こうした機器本体や内部部品、周辺装置など、システムを物理的に構成するものです。

コンピュータの分類に出てくる例
分類用途や構成の手掛かり
PC・ワークステーションPCは個人のさまざまな作業、ワークステーションは設計や画像処理など専門用途の例。
メインフレーム組織の基幹業務で大量の取引などを処理する例。
スーパーコンピュータ気象のシミュレーションなど、大規模な科学技術計算を行う例。
マイクロコンピュータマイクロプロセッサを使う小型のコンピュータ。機器の内部で制御に使う例がある。
ブレード型サーバ板状のサーバを共通の筐体に収め、電源などを共有する形。
スマート・ウェアラブル端末スマートフォンやタブレットは携帯してアプリを使う端末。腕時計型など身体に装着する機器はウェアラブル端末。

紙の資料は、画像・文字・マークを分けて考える

キーボードは文字など、マウスやペンタブレットは位置や動き、カメラは画像や動画を入力します。バーコードリーダーは本に付いたコードから識別番号を読み取ります。タッチパネル付きの画面は、指が触れた位置を入力し、表示で情報を出力します。

印刷の細かさ、速さ、方式を区別する

ドットインパクト方式はピンでインクリボンを打つので、複写用紙に使われる例があります。感熱方式は熱で発色する専用紙を使い、レシートなどで見かけます。画面では液晶や有機ELがあり、縦横の画素数と画面の物理的な大きさは別の指標です。

例題6問と解説

Study Quest編集部の自作問題です。先に答えを考えてから、各問の「解答と解説」を開いてください。

第1問　天気を予測する計算

多数の観測値を使って大規模な気象シミュレーションを行う機器の例はどれですか。

  1. スマートウォッチ
  2. スーパーコンピュータ
  3. バーコードリーダー
  4. 複写用プリンター
第1問の解答と解説

イ　スーパーコンピュータ

大規模な科学技術計算が手掛かりです。

第2問　筐体を共有する

板状のサーバを共通の筐体に差し込み、電源などを共有する形はどれですか。

  1. ワークステーション
  2. メインフレーム
  3. ブレード型サーバ
  4. ウェアラブル端末
第2問の解答と解説

ウ　ブレード型サーバ

板状のサーバを複数まとめて収める構成が、ブレード型サーバの特徴です。

第3問　申込書を検索したい

読み取った紙を、氏名の文字列で検索できるようにしたい。画像にした後に何を使いますか。

  1. OCR
  2. OMR
  3. プロジェクター
  4. インクジェット
第3問の解答と解説

ア　OCR

OCRで画像中の文字を文字データにします。OMRは塗りつぶしなどのマークを読みます。

第4問　複写用紙に印刷する

1回の印刷で下の紙にも文字を転写したい。打撃を利用する方式はどれですか。

  1. レーザー
  2. インクジェット
  3. 感熱
  4. ドットインパクト
第4問の解答と解説

エ　ドットインパクト

ピンでリボンと用紙を打つため、複写用紙に向きます。

第5問　連続印刷にかかる時間

30ppmの速度が一定で、準備時間を除く場合、75ページを印刷するには何分かかりますか。

  1. 2分
  2. 2分30秒
  3. 3分
  4. 4分
第5問の解答と解説

イ　2分30秒

75ページ÷30ページ/分＝2.5分です。0.5分は30秒です。

第6問　画面の二つの役割

タッチ画面で本を選び、貸出結果を読む場合、それぞれの役割はどれですか。

  1. どちらも入力
  2. どちらも出力
  3. 選択は入力、表示は出力
  4. 選択は出力、表示は入力
第6問の解答と解説

ウ　選択は入力、表示は出力

利用者の指示が機器に入る操作と、機器から利用者に結果が出る操作を分けます。
