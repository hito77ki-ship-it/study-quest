ITパスポート 9-2 ファシリティマネジメント

図書館の機器室と停電を例に、UPS、自家発電装置、サージ防護、配線や空調の管理を図解と例題で学びます。

予約を支える電気・部屋・配線を管理する

ファシリティマネジメント（FM）は、組織が使う施設と環境を総合的に計画・管理・活用する活動です。例えば図書館では、予約サーバの置き場、電力、空調、配線、機器の盗難防止、災害時の運用を一緒に考えます。サーバ本体が動作していても、機器室が高温になったりネットワーク機器が停止したりすれば、利用者は予約できません。

消火・漏水検知・耐震対策、温度と湿度の監視も、機器を置く場所を整える取組です。グリーンITでは、省電力機器や冷却の見直しでIT自体の環境負荷を減らすことや、ITを使って施設のエネルギーを管理することを考えます。

UPS・発電機・サージ防護を見分ける

無停電電源装置（UPS）は、停電や電圧低下などの際に、接続した機器へ一定時間給電します。設置条件に応じて、保存して安全に停止する時間を確保したり、発電機に切り替わるまで支えたりします。自家発電装置は発電で給電しますが、始動して安定した電力を使えるまで時間がかかることがあります。サージ防護は、落雷などによる瞬間的な過電圧から機器を守る対策です。

何が起きるかで設備を選ぶ
状況選ぶ設備と確認点
停電の直後にサーバが落ちそうUPS。機器の消費電力、必要な運転時間、対象コンセントを確かめる。
停電が長引き、給電を続けたい発電機と切替設備。燃料、負荷、切替までの給電を確かめる。
落雷などで瞬間的な過電圧が心配サージ防護。保護対象の回路と機器を確かめる。
配線が通路に出てしまうフリーアクセスフロアなど。経路、点検のしやすさ、漏水時の対応を確かめる。

例題6問と解説

Study Quest編集部の自作問題です。先に答えを考えてから、各問の「解答と解説」を開いてください。

第1問　急な停電で保存時間を確保

受付サーバの電力が突然止まりました。短時間給電して保存と停止を行うための機器はどれですか。

  1. サージ防護のみの電源タップ
  2. セキュリティワイヤー
  3. UPS
  4. フリーアクセスフロア
第1問の解答と解説

ウ　UPS

UPSは蓄えた電力などで給電を維持します。サージ防護だけの電源タップには停電時の給電機能がありません。

第2問　切替に必要な時間を見積もる

発電機が安定するまで2分、切替に1分と仮定します。この間の給電を担うUPSは何分以上の運転が最低限必要ですか。

  1. 1分
  2. 2分
  3. 3分
  4. 4分
第2問の解答と解説

ウ　3分

安定後に切り替えるので2＋1＝3分です。実際には負荷や電池の劣化、作業余裕も考えます。

第3問　一瞬の過電圧を抑える

落雷に伴う瞬間的な過電圧から機器を守る対策はどれですか。

  1. サージ防護
  2. 電源の稼働率集計
  3. 入退室記録
  4. 機器棚の増設
第3問の解答と解説

ア　サージ防護

短時間に大きく上がる電圧を抑える設備です。電力を継続して供給する目的とは分けます。

第4問　サーバは動くのに窓口が使えない

停電時にサーバはUPSで動きますが、窓口へのネットワーク機器は給電を失いました。最初に点検すべきことはどれですか。

  1. 予約画面の色
  2. 職員の連絡先だけ
  3. SQLの書き方
  4. 接続経路全体と給電対象
第4問の解答と解説

エ　接続経路全体と給電対象

利用には端末からサーバまでの通信が必要です。サーバだけでなくスイッチなど経路上の機器への給電を確認します。

第5問　配線を点検できるようにする

受付机を移動するときに、床の下の配線を開けて引き直せるようにしたい。どの設備ですか。

  1. 自家発電装置
  2. フリーアクセスフロア
  3. 消火設備
  4. サービスデスク
第5問の解答と解説

イ　フリーアクセスフロア

外せる床板の下に配線空間を設ける構造です。

第6問　日常の空調も計画する

高温になる機器室の空調、電気代、設置場所をまとめて見直します。中心になる活動はどれですか。

  1. 問題管理だけ
  2. 展開管理
  3. ファシリティマネジメント
  4. サービス要求管理
第6問の解答と解説

ウ　ファシリティマネジメント

施設と環境を計画して管理します。個別の障害対応と合わせ、設置環境を改善して安定運用につなげます。
