# 収益目標と達成プロセス（2026年7月30日策定）

**取締役の設定した大目標：** 一人暮らしできるくらいのお金を稼ぐ
**取締役の設定した中間目標：** Googleアドセンス合格

本書は、この2つを会社の目標として正式に登録し、達成プロセスをCEOとして設計したものである。

---

## 1. まず、中間目標の位置づけを訂正させてほしい

**「AdSense合格」を一人暮らし費用の達成手段として置くのは、数字が合わない。** 目標そのものは維持するが、役割を変える必要がある。

### AdSense単独で一人暮らし費用に届くのに必要なPV

日本語の資格・学習系コンテンツのRPM（1,000PVあたり収益）は、おおむね200〜500円のレンジとされる。月10〜15万円を狙う場合の必要PVは以下になる。

| RPM | 月10万円に必要 | 月15万円に必要 |
|---|---|---|
| 200円 | 500,000 PV | 750,000 PV |
| 300円 | 333,000 PV | 500,000 PV |
| 500円 | 200,000 PV | 300,000 PV |

### 現状（GSC 2026-07-29エクスポート・28日間の実数）

```
検索クリック : 21 回
検索表示     : 408 回
CTR          : 5.1%
月間PV       : 直接流入を含めてもおおむね100PV未満
```

**RPM300円で月12万円を狙うなら400,000PV。現状からの必要倍率は約4,000倍である。**

月40万PVは、資格ジャンルでは記事1,000本規模・運営数年のサイトが到達する水準である。205本・ドメイン開設4ヶ月の当サイトが数ヶ月で届く数字ではない。**「AdSenseに合格すれば一人暮らしできる」という筋道は、残念ながら成立しない。**

### では、AdSense合格の価値は何か

3つある。これは本物の価値なので、目標として残す。

1. **サイトが品質基準を満たしたという外部認定** — 独立した第三者が「広告を載せてよいサイト」と判断した証明になる
2. **収益メーターが動き出す** — 0円と1円の差は大きい。数字が動き始めると改善の手応えが取れる
3. **アフィリエイトとの併用が前提** — AdSenseは「下限を支える収入」として機能する

**つまりAdSenseは通過点であって、到達点ではない。**

## 2. 資格ジャンルでは、アフィリエイトの方が桁で有利

同じ月12万円を、成約課金型で狙うと必要数はこうなる。

| 成約単価 | 月12万円に必要な成約数 |
|---|---|
| 3,000円 | 40件/月 |
| 5,000円 | **24件/月** |
| 10,000円 | **12件/月** |

**予備校・通信講座は、資料請求や申込で数千円〜1万円クラスの単価が成立するジャンルである。** 月12件の成約なら、必要な流入は月40万PVではなく数千〜数万PVで足りる可能性がある。

**桁が2つ違う。** 資格ブログでAdSenseを主収入に置くのは、そもそも筋が悪い。

> **注記：** 上記の単価・RPMは一般的なレンジであり、当社が実際に得られる金額を保証するものではない。実測して修正していく前提の数字である。

## 3. 最大の未回収を発見した

現在の収益導線を実測した結果がこれである。

| 項目 | 実数 |
|---|---|
| 予備校名（CPA会計学院・TAC・ユーキャン・スタディング・クレアール・フォーサイト・アガルート）を本文で挙げている記事 | **29本** |
| そのうちアフィリエイトリンクになっている記事 | **1本** |
| A8ネットのバナーが置かれている場所 | `app.html`（13箇所）と `index.html`（8箇所）**のみ** |
| Amazonアソシエイトを含む記事 | 7本 |

**バナーは、買う気のないページにだけ貼られている。**

`index.html` はサイトの入口で、`app.html` は学習記録アプリである。どちらも「予備校に申し込むか迷っている瞬間」ではない。一方、`cpa-yobikou.html`（会計士は予備校か独学か）や `boki1-yobikou.html`（簿記1級は予備校か独学か）といった記事は、**まさに読者が申し込みを検討している場所**である。そこに導線がない。

**これは今すぐ着手できる最大のレバーだと考える。** 新しい記事を書く必要も、PVを増やす必要もない。すでにある29本に導線を通すだけである。

## 4. 目標の階層

```
【大目標】一人暮らしできる収入（月10〜15万円）
    │
    ├─【収益源①】アフィリエイト（主軸）
    │     └ 予備校・講座の成約。月12〜24件で大目標に届く可能性がある
    │
    ├─【収益源②】AdSense（下限を支える）
    │     └ ★中間目標：合格。品質の外部認定＋収益メーター始動
    │
    └─【収益源③】受注（ランサーズ・ココナラ）
          └ 唯一「今月」動かせる収入。Study Quest自体が営業資料になる
```

**3本立てにする理由：** ①と②は流入が増えるまで時間がかかる。③だけが自分の営業努力で今月動く。**収入がゼロのまま数ヶ月耐えるのは、精神的にも継続性の観点からも危険である。**

## 5. 達成プロセス

順序に意味がある。上から順に着手する。

### Phase 0（今すぐ〜1ヶ月）：現金が入る経路を作る

| やること | 理由 |
|---|---|
| 予備校名を出している**29記事のうち28本**にアフィリエイト導線を通す | 最大の未回収。PVを増やさずに収益化率が上がる |
| ココナラに出品する（SEOリライト・表示速度改善・図解制作） | 唯一コントロール可能な収入。手数料22%だが即金性がある |

**Phase 0は流入増加を待たない。** 今ある資産（29記事・419枚のSVG図解・実サイト運営実績）を現金化する段階である。

### Phase 1（1〜3ヶ月）：見つけてもらえる状態にする

| やること | 現状 → 目標 |
|---|---|
| インデックス登録を全ページへ | 135 / 207ページ → 200以上 |
| 検索表示回数 | 408回/28日 → **4,000回/28日（10倍）** |
| 「検出 - インデックス未登録」54ページの解消 | 内部リンクとサイト評価の改善で |
| AdSense審査結果の確認と、否認なら是正 | 申請済み・結果待ち |

**この段階の指標はPVではなく「表示回数」にする。** クリックはCTR改善で後から伸ばせるが、表示されていないものはどうにもならない。

### Phase 2（3〜6ヶ月）：成約に変える

| やること |
|---|
| 成約単価の高いジャンル（会計士・簿記1級・司法書士）の記事を厚くする |
| 「比較記事 → 申込」の導線設計。資料請求という低いハードルを最初に置く |
| A/Bで導線位置を検証（記事冒頭 vs 本文中 vs 末尾） |
| AdSense広告配置の最適化（合格後） |

### Phase 3（6〜12ヶ月）：規模と権威性

| やること |
|---|
| 記事数 205 → 400本規模へ |
| 若葉の簿記1級合格（合格すれば著者の権威性が跳ね上がる） |
| 被リンク獲得（note・X・他サイトからの言及） |

## 6. 判断基準の更新（CEOジョブズの新しいフィルター）

これまでの判断基準は「検索上位表示とAdSense合格に近づくか」だった。**これを更新する。**

提案は以下の順で評価する。

1. **収益に直結するか**（アフィリエイト導線・受注に繋がるか）
2. **見つけてもらえる状態に近づくか**（インデックス・表示回数）
3. **ユーザーの人生を本当に変えるか**（従来の基準。1と2が同点なら、これで決める）

**変更の理由を正直に書く。** 今日1日を振り返ると、私はCLSを0.207から0.032に下げるために長時間を使い、その過程で診断を5回外した。CLSの改善はサイトの品質に寄与するが、**収益には1円も寄与していない。** 一方、予備校名を出している29記事に導線がないことには気づいていなかった。

**判断基準に「収益」が入っていなかったから、収益の穴が見えなかった。** これはCEOとしての設計ミスである。

## 7. 正直に書いておくこと

- 上記のRPM・成約単価は一般的なレンジであり、**当社の実額を保証するものではない。** 実測して修正する
- 月10〜15万円という金額は、家賃を含む一人暮らし費用の一般的な想定として置いた。実際に必要な額は取締役の生活条件によるので、**具体的な金額は取締役に確定していただきたい**
- Phase 1の「表示回数10倍」は、今日までの施策（表示速度・内部リンク・sitemap整合）の効果が出る前提の目標である。**達成できるかは分からない。** 未達なら原因を分析して計画を組み直す
- AdSenseの審査結果は当社から確認できない（別アカウントに紐づいているため）。**取締役ご自身での確認をお願いしたい**
- **一人暮らしのタイミングを、この収入だけに賭けるのは危険である。** ③受注を含めても、月10万円が安定するまでの期間は読めない。他の収入源（アルバイト等）と併走させる前提で計画されることを強く勧める
