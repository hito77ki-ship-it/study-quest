# AdSense合格に向けた記事群整理計画

**作成日：** 2026年8月10日
**目的：** Google AdSense合格とSEO強化のため、213本のHTMLを「合格するサイトの構造」に整理する
**担当：** CEO ジョブズ

---

## 1. 結論

今やるべきことは、記事をさらに増やすことではない。

**213本を、Googleにも読者にも「専門性のある整理されたサイト」として伝わる構造に変える。**

AdSense審査では、ページ単体の文章量だけでなく、サイト全体の完成度、ナビゲーション、独自性、薄いページや未整理ページの混入が見られる。Study Questは記事量は十分にある。弱点は、記事数に対して整理の線がまだ細いことだ。

今回の第一歩として、当初 `article-widgets.js` の記事台帳から漏れていた38本を棚卸しし、扱いを決める。

## 5. 次の実行順

### Phase 1：記事一覧の再編

`index.html` の記事一覧を以下の大分類へ再編する。

| 大分類 | 役割 |
|---|---|
| 簿記 | サイトの主戦場。3級・2級・1級をハブ化 |
| FP | 簿記の次に取りやすい資格として接続 |
| 会計士・税理士 | 高単価導線の中核 |
| 法律資格 | 宅建・行政書士・司法書士・社労士 |
| IT資格 | ITパスポート・基本情報・応用情報 |
| 英語資格 | TOEIC・英検・TOEFL・IELTS |
| 大学生・社会人 | 資格選び、税金、就活、働きながら勉強 |
| 学習継続・アプリ活用 | Study Quest本体への回遊 |

### Phase 2：1記事カテゴリを減らす

現在は1記事だけのラベルが多く、専門性が分散して見える。カテゴリラベルを大分類に寄せる。

例：

- `登録販売者`、`衛生管理者`、`秘書検定` → `資格ガイド`
- `会計士の進路`、`会計士→簿記1級` → `公認会計士`
- `AIライフハック`、`AI活用・時短術` → `AI活用`

### Phase 3：ハブへの内部リンクを強化

各記事末尾に、以下の3導線を置く。

1. 同カテゴリの次に読む記事
2. カテゴリハブ
3. Study Questアプリ起動

## 6. CEO判断

AdSense合格に必要なのは、記事数の多さではない。

**「このサイトは何の専門サイトで、読者は次にどこへ行けばいいのか」が一瞬で分かることだ。**

Study Questはすでに素材を持っている。次は、素材を束ねる。余計なページを見せず、価値ある記事をハブに接続する。

それはユーザーの人生を本当に変えるか？

変える。迷っている学習者に、次の一歩を渡せるからだ。
