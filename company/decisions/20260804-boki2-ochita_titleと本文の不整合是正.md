# 稟議書：boki2-ochita.html の title と本文の不整合是正

**起案日：** 2026-08-04
**起案者：** CEO ジョブズ
**種別：** 記事コンテンツに関わる変更（CLAUDE.md 稟議フロー対象）
**ステータス：** 取締役の承認待ち

---

## 1. 提案の背景

技術SEO監査（2026-08-04）で、`boki2-ochita.html` の title が約束している内容が本文に存在しないことを発見した。

| 要素 | 内容 |
|---|---|
| title | 簿記2級に落ちた…次はいつ受ける？**再受験までの期間**と立て直し4ステップ｜スタディクエスト |
| og:title | 簿記2級に落ちた…次はいつ受ける？再受験までの期間と立て直し4ステップ |
| h1 | 簿記2級に落ちた…次どうする？**不合格後の立て直し方【2026年版】** |
| description | 簿記2級に不合格だった人へ。落ちた原因を4パターンに整理したうえで、ネット試験を使った再受験のタイミング、次の合格に向けた立て直し4ステップを具体的に解説します。 |

**本文での言及回数：** 「再受験」1回／「いつ受ける」2回／「期間」2回。
**該当する h2：** 無し。

現在の h2 構成：

1. まず「なぜ落ちたか」を冷静に分析する
2. 簿記2級が難しい本当の理由
3. 不合格後の学習 4ステップ
4. ネット試験を活用して早期リベンジ
5. 合格のための得点戦略を持つ
6. 2回目以降で合格する人の共通点
7. まとめ
8. よくある質問

「再受験までの期間」に答えている記述は、**FAQ アコーディオン内の1問だけ**である。

> Q. 簿記2級に落ちたら次いつ受けるべき？
> A. 弱点補強に1〜2ヶ月かけてから次の試験を目指すのが理想です。ネット試験なら随時受験できるため、準備ができたタイミングで申し込めます。焦って再受験しても同じ結果になりやすいので、十分な補強期間を取ってください。

アコーディオンは初期状態で折りたたまれている。**title の主語を読みに来た読者が、開くまで答えに辿り着けない。**

## 2. ファクトチェック

**同型の失敗が実際にインデックス未登録を招いた前例がある。**

`boki2-net-test.html` は title が「ネット試験（CBT）とは？統一試験との違い・合格率・**受験方法**を完全解説」でありながら、本文に申込・予約・受験料の記述が0回だった。このページは Google Search Console で「クロール済み — インデックス未登録」だった（2026-07-29 発見・是正済み）。この一件を受けて CLAUDE.md に「タイトル変更時のチェックリスト」を追加している。

**本件はそのチェックリストの項目2・項目3に抵触する。**

- 項目2：title に入れたキーワードが本文に実在するか → 「再受験」1回のみ。実在はするが、キーワード出現としては極めて希薄
- 項目3：title が「〜受験方法」等を名乗るなら対応する h2 があるか → **無い**
- 項目1：title / h1 / og:title / description が同じ記事を指しているか → **h1 だけが別の約束をしている**

**「簿記2級 落ちた」の検索意図について。** 不合格直後の読者が最初に知りたいのは「原因分析」ではなく「次いつ受けられるのか」である。統一試験は年3回（6月・11月・2月）で次回まで最短でも3〜4ヶ月、ネット試験は施行休止期間を除き随時受験可能で、同一試験の再受験に回数制限は無い（日商公式）。**この「統一試験を待つと最長4ヶ月、ネット試験なら1〜2ヶ月後に受け直せる」という比較こそが、この記事で最も価値のある情報であり、いま h2 になっていない。**

なお、日程・施行休止期間は日商公式サイトで確認したうえで書くこと（CLAUDE.md「金額を記事に書くときのルール」と同じ姿勢を、日付にも適用する）。

## 3. 対応案

### 案A：本文に h2 を新設し、title の約束を果たす（推奨）

現在の h2-4「ネット試験を活用して早期リベンジ」を、**h2「次はいつ受ける？再受験までの期間」に改題・拡充する。** 内容：

- 統一試験の次回日程と、そこまでの待ち時間（公式確認のうえ具体日で書く）
- ネット試験の再受験可能タイミング（施行休止期間に触れる）
- 「1〜2ヶ月の弱点補強を挟む」という推奨と、その根拠
- 焦って2週間後に受け直した場合に何が起きるか

あわせて **h1 を title と揃える**。

### 案B：title を本文の実態に合わせる

title から「再受験までの期間」を落とし、h1 の「不合格後の立て直し方」に寄せる。

## 4. CEO ジョブズの所見

**案Aを推す。理由は SEO ではない。**

簿記2級に落ちた直後の人間が検索窓に打ち込むのは「簿記2級 落ちた 次」である。その瞬間、彼が本当に欲しいのは慰めでも原因分析でもない。**「あと何ヶ月待てばいいのか」という、たった一つの数字である。** それが分かって初めて、原因分析を読む気力が湧く。

いまの記事は、その数字をアコーディオンの中に畳んで隠している。**答えを持っているのに、開かないと見せない。これは設計として不誠実である。**

案Bは title を削るだけなので5分で終わるが、それは**読者が求めている情報が記事に無いことを追認する**選択である。この記事は情報を持っている。持っているものを、見える位置に出せばいいだけだ。削るべきものと、出すべきものを取り違えてはいけない。

一方で、**辛口に言えばこれは本来チェックリストを作った7/29に潰しておくべき問題だった。** ルールを CLAUDE.md に書いて満足し、既存ページへの遡及適用をしていなかった。今回 boki2-* 42本を見ただけで2件出ている。**残り170本にも同種の不整合が眠っていると考えるべきで、本件の是正だけで「対応した」と言うつもりは無い。** 次回監査で約束表現の自動スクリーニングを試す。

**評価順との照合：**

1. 収益に直結するか → **間接的。** この記事に予備校導線は無い。ただし「独学で落ちた人」は予備校検討層と最も重なる読者層であり、将来的に導線を置く価値が最も高いページの一つである
2. 見つけてもらえる状態に近づくか → **する。** title と本文の不整合はインデックス見送りの既知の原因であり、前例が社内にある
3. ユーザーの人生を本当に変えるか → **変える。** 落ちた直後に「1〜2ヶ月後にもう一度戦える」と分かることは、そこで諦めるか続けるかの分岐そのものである

## 5. 実行時の注意

- 本文を追記したら `dateModified`（JSON-LD）と本文表示の「更新日」を**2箇所セットで**更新する（CLAUDE.md ルール）
- h1 を変更するので、変更後に title / h1 / og:title / description の4点整合を再チェックする
- 試験日程は日商公式で確認した実数のみを書く。「だいたい3ヶ月後」のような相場観で書かない
- `.tip-box` 等の共通クラスを新たに使う場合、ローカル `<style>` に定義があるか確認する
