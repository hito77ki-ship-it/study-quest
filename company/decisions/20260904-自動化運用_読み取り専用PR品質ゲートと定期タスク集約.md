# 稟議書：読み取り専用のPR品質ゲートと定期タスク集約

> **本稟議の決裁事項は2件である。** 対象は自動化の安全境界と公開前の機械検査であり、記事本文・UI・広告・外部投稿は変更しない。

**起案日：** 2026年9月4日

**起案者：** CEO ジョブズ
**ステータス：** 実行済み（取締役による「全部やってみましょう」の明示指示）

## 背景

ルート作業ツリーには未コミット変更と `.git/index.lock` が存在する。一方、既存の定期タスクにはレポート・稟議の自動書き込みや、日次の commit / push を許すものがあった。この状態では、監査のための自動化が他者の変更と混ざる。

また、公開前に機械的に確定できる崩れ（空白エラー、構造化データ、内部リンク、ローカル画像参照、更新日3面、広告保護面）がPR単位で止まる仕組みがなかった。

## 決裁事項1｜定期タスクを読み取り専用へ集約

- `Study Quest 承認済み変更の安全commit・push` を停止する。
- 重複する夜間記事監査、重点AdSense監査、日次SEO確認などを停止し、残る監査は目的別に集約する。
- 稼働を継続する監査は、`company/reports`、`company/decisions`、進捗台帳を含めて自動書き込みを行わず、タスクの最終報告だけを出す。
- 参考書照合と公式情報差分監視は、極高推論を試行する。リンク・note導線など定型的な確認は低〜中推論を維持する。
- 月1回、定期タスク自体の重複・書き込み・モデル／推論設定を点検する監査を新設する。

これはCodexアプリの自動化設定に反映する。Git操作、公開、外部送信は含まない。

## 決裁事項2｜PR専用の機械検査を追加

`.github/workflows/media-audits.yml` にPRトリガーの読み取り専用ジョブを追加する。チェック内容は次のとおり。

1. `git diff --check` による差分の空白エラー
2. title、h1、description、canonical、JSON-LD、記事更新日の3面、内部リンク、ローカル画像参照の静的検査
3. AdSense是正で保護した非収益化面・信頼ページ・短い広告面の再混入検査
4. 内部リンクグラフの検査

すべて `--no-write` で実行し、リポジトリのファイル、広告設定、本番サイトを自動変更しない。本文の意味、一次情報の正しさ、デザインの見た目は機械判定で断定しない。

## 検証条件

- 既存の main で各検査が成功すること
- `git diff --check` が成功すること
- ワークフローのYAMLが解析できること
- PRトリガーの権限は既存どおり `contents: read` に限定すること

## CEO所見

自動化の価値は、変更を勝手に増やすことではなく、誤った変更を公開前に止めることにある。まず書き込み権限をなくし、確定的な検査だけをPRに置く。一次情報の読解と記事改善は人間の判断を残す。
