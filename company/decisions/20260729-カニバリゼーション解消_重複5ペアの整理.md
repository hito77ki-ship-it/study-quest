## 1. 調査で判明した最大の事実：net-test はカニバリではなく「title詐欺」だった

前回のレポートで私は `boki2-net-test.html` と `boki2-cbt-vs-paper.html` を「ほぼ同一テーマ」と診断し、統合を選択肢に挙げた。**これは誤診だった。**

実際に本文を計測した結果はこうである。

| 検索語 | net-test 本文 | cbt-vs-paper 本文 |
|---|---|---|
| 統一試験 | 6回 | 34回 |
| 合格率 | 2回 | 1回 |
| 申込 | **0回** | 0回 |
| 予約 | **0回** | 1回 |
| 受験料 | **0回** | 1回 |

net-test の title はこうなっていた。

```
【日商簿記2級】ネット試験（CBT）とは？統一試験との違い・合格率・受験方法を完全解説
```

ところが h2 は「問題構成の目安／時間配分／解く順番／ネット試験で注意すること」。**本文は最初から最後まで「当日の90分の使い方」の記事で、title が約束している「統一試験との違い」「受験方法」を一切扱っていない。**

決定的だったのは og:title である。

```
og:title: 簿記2級ネット試験の問題構成・時間配分を解説   ← 中身と一致している
title:    ネット試験（CBT）とは？統一試験との違い…      ← 中身と一致していない
```

**og側は正しく、title だけが取り残されていた。** 過去に記事をリライトしたとき title の更新を忘れたものと見られる。

Googleから見れば、title が約束した内容が本文にない状態である。これは重複というより**title と content の不一致**であり、インデックス見送りの説明としてはカニバリゼーションよりずっと自然だ。前回「ほぼ同一テーマ」と書いたのは、私が title だけを並べて比較し、本文を読まなかったからである。**本日7件目の「一次情報を確認せずに結論を書いた」ミスになる。**

## 2. 5ペアの再診断

本文を実測したうえで診断し直した。**統合が必要なペアは1つもなかった。**

| ペア | 前回の診断 | 実測後の診断 | 対応 |
|---|---|---|---|
| net-test / cbt-vs-paper | 極めて高い。ほぼ同一 | **重複ではない。titleが中身と不一致** | title・description を中身に合わせる |
| zeikouka / kurinobe | 高い。両方未登録 | 中身は分業済み。**titleが両方「繰延税金資産」を主張** | zeikouka から「繰延税金資産」を外す |
| yukashoken / arai | 中 | **低い。**分類の全体像 vs 洗替/切放の処理。相互リンク各2本あり | 対応不要 |
| kotei-betsu / sogo | 中 | **低い。**sogo 本文の「工程別」出現は1回のみ | 対応不要 |
| cpa-dokugaku / cpa | 高 | 中身は別。**title が両方「独学」を主張**。相互リンクも片側のみ | cpa から「独学」を外し、リンクを補完 |

**共通する真因は本文ではなく title だった。** 5ペア中3ペアで、同じキーワードを2つのページの title が奪い合っていた。本文の中身はどれも十分に分業できている。**記事を削除・統合する必要は一切なかった。**

## 3. 実行した変更

### ① `boki2-net-test.html` — title を中身に合わせる

```
旧 title: 【日商簿記2級】ネット試験（CBT）とは？統一試験との違い・合格率・受験方法を完全解説
新 title: 簿記2級ネット試験の時間配分と解く順番｜90分で合格する問題構成ガイド
```

description も「統一試験との違い・難易度・合格率、電卓使用ルール…」という本文に無い内容だったため、実際の中身（第1問〜第5問の時間配分・解く順番・切り上げ判断）に書き換えた。

さらに冒頭に、どちらの記事を読むべきかの案内を追加した。

> **この記事は「ネット試験を受けると決めた人」向けです。** 「そもそもどっちで受けるべき？」を迷っている段階の方は、先に *ネット試験（CBT）vs 統一試験（紙）徹底比較* をご覧ください。

cbt-vs-paper → net-test のリンクは4本あったのに、**逆方向は0本だった。** これも補完した。

### ② `boki2-zeikouka.html` — 「繰延税金資産」を kurinobe に譲る

```
旧: 簿記2級の税効果会計とは？繰延税金資産・法人税等調整額を解説
新: 簿記2級の税効果会計とは？一時差異と法人税等調整額を図解で解説
```

title・h1・og:title・description を統一して変更。zeikouka は「なぜ利益と所得がズレるのか」という全体像、kurinobe は「資産か負債かの判別」に特化する、という役割分担を検索面にも反映させた。**このペアは両方とも未登録だったので、現状維持が最も避けるべき選択だった。**

### ③ `cpa.html` — 「独学」を cpa-dokugaku に譲る

```
旧 title: 公認会計士試験の勉強法・独学ロードマップ【2026年版】
新 title: 公認会計士試験の勉強法・合格ロードマップ【2026年版】｜科目別攻略と学習スケジュール
```

h1 はもともと「合格ロードマップ」だったので、**title を h1 に合わせた形**でもある。「独学」の語は cpa-dokugaku 側に一本化した。cpa-dokugaku → cpa のリンクが0本だったため、関連記事の先頭に追加した。

### ④⑤ 有価証券ペア・原価計算ペア — 変更なし

実測の結果、重複と呼べる水準になかった。title も本文も既に分業できており、相互リンクも張られている。**手を入れないという判断も判断である。** 触れば触るほど良くなるものではない。

## 4. CEO所見

**シンプルさは究極の洗練である。** 前回の私は「統合するか、切り分けるか」という重い選択肢を並べていた。記事を1本消す判断だ。しかし本文を実際に測ったら、答えは**「titleを直すだけ」**だった。5ペアのうち2ペアは何もしなくてよかった。

危なかったのは net-test である。前回の診断のまま「ほぼ同一テーマだから統合」を実行していたら、**時間配分という独立した価値を持つ記事を、比較記事に吸収して消していた。** 実際にはこの記事は「解く順番」という、cbt-vs-paper には全く無いテーマを扱っている。title だけを見て統合を判断するのが、いかに危険かという実例になった。

一方で、辛口に書く。**5記事の title が中身とズレたまま放置されていたのは、記事を出した後に誰も見返していないということだ。** og:title と title が食い違っていた net-test は、リライト時に片方だけ直して終わっていた。これは仕組みの問題であり、新規記事チェックリストに「リライト時は title / h1 / og:title / description の4点をすべて突き合わせる」を足す必要がある。

**効果測定の注意：** 本日は別途、CTR改善目的で5ページの title を変更している（`20260729-上位表示狙いのリライト方針`）。今回の3ページはそれとは別の目的（重複解消）だが、**同時期に変更したため、GSCの数字を見るときは両者を混同しないこと。** 対象ページは重複しない（今回：net-test / zeikouka / cpa、CTR改善：boki1 / boki2 / itp / fe / boki2-ochita）ため、分けて評価できる。
