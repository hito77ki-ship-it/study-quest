## 指摘1｜🔴 `ap.html` — 2026年度CBT移行の「名称」だけ書き、「日程」と「別期間実施」を書いていない

### 事実確認（IPA一次情報・2026年7月6日最終更新）

出典：[令和8年度（2026年度）応用情報技術者試験、高度試験及び情報処理安全確保支援士試験の実施予定について](https://www.ipa.go.jp/shiken/2026/ap_koudo_sc_yotei.html)

**記事が正しく書いていること：**

| 記事 | 公式 |
|---|---|
| 従来の「午前・午後」は科目A・科目Bに名称変更 | 「午前試験」→「科目A試験」、「午後試験」→「科目B試験」に名称変更予定 |
| 2026年度はCBT方式 | CBT方式に移行する予定 |
| 前期・後期に実施 | 前期試験・後期試験 |
| 科目A 80問・150分／科目B 11問中5問・150分 | 出題形式・出題数・試験時間に変更なし |

**記事に書かれていないこと：**

```
grep 結果（ap.html）
  11月 = 0    2月 = 0    2027 = 0
  別期間 = 0  実施期間 = 0  同日 = 0  申込 = 0
```

公式が明示している次の4点が、記事に1つも入っていない。

1. **前期試験 ＝ 2026年11月頃**（従来の春期に相当）
2. **後期試験 ＝ 2027年2月頃**（従来の秋期に相当）
3. **科目A群と科目B群は実施期間を分けて実施する**（同日受験ではなくなる）
4. 申込みは前期・後期それぞれ**1回のみ**。科目A群と科目B群は申込時に**同時予約**

### なぜこれが実害になるか

記事は h2「**独学6ヶ月合格スケジュール（FE合格者向け）**」で受験計画を指示している。月別テーブルの最終行は：

> 直前1ヶ月｜**科目A・科目Bを交互に総仕上げ**。弱点分野を集中強化

**これは同日に両科目を受ける前提の助言である。** 実施期間が分かれるなら、学習の山を2つに割り、科目A群の日程で仕上げてから科目B群に移る組み立てになる。

さらに**本日は2026年8月18日**。前期試験（11月頃）まで約3か月で、6か月計画は物理的に間に合わない。後期（2027年2月頃）なら約6か月だが、記事はどちらを指すか示していない。

### この型は7資格目である

制度改正の追随漏れは、税理士・英検・電気工事士・情報処理／介護福祉士・社会福祉士・登録販売者に続いて**7資格目**。

**ただし今回は前6件と1点違う。記事は制度変更そのものには触れている。** 名称変更だけ拾って、日程と受験方式の変更を落とした。

**定型チェック項目23の判定基準は「制度改正に言及があるか」の二値であり、これでは今回も過去も検出できない。** 08-11に `eiken3.html`（Eメール問題には触れているが試験時間が旧値）でまったく同じ判定ミスを認めたはずだった。**1つの制度改正は複数項目を同時に動かす、という結論を書いた後で、同じ形が別資格で出た。**

## 指摘3｜🟡 公認会計士の勉強時間がサイト内で2通り／税理士の時間が文脈と合っていない

### 3-1. 公認会計士の勉強時間（全記事スキャン結果）

| 記述 | ファイル |
|---|---|
| **3,000〜5,000時間** | `cpa.html`（4箇所以上）／`cpa-yobikou.html`／`cpa-dokugaku.html`／`cpa-daigakusei-kakugo.html`（3箇所） |
| **3,000〜4,000時間** | `zeirishi-vs-cpa.html`／`dokugaku-shikaku.html`／`shikaku-20dai.html` |

`zeirishi-vs-cpa.html` の比較表は次の形をしている。

| | 税理士 | 公認会計士 |
|---|---|---|
| 必要勉強時間 | 3,000〜5,000時間（全科目） | **3,000〜4,000時間** |

**これは「会計士の方が短い」と読める。** この記事は「どっちを目指すべきか」を決めさせる記事であり、勉強時間は判断の主要根拠である。

**「サイト内の別記事が違うことを書いている」型は8週連続。** 08-05（簿記3級配点）・08-06（税理士受験資格）・08-11×2（FE合格率／ITパスポート勉強時間）・08-12・08-13・08-14（宅建業法配点・勉強時間5資格）に続く。

### 3-2. 税理士の「3,000〜5,000時間（全科目）」が置かれている場所

`zeirishi.html` の科目別表を**全11科目**合算すると：

```
下限 450+400+600+600+300+400+250+250+200+150+200 = 3,800時間
上限 600+500+800+800+400+500+350+350+300+250+300 = 5,150時間
```

**「全科目」という語義では 3,000〜5,000 と整合する。** しかし税理士試験は**5科目合格で取得**であり、`zeirishi.html` 自身が「1科目ずつでいい」を記事の中心主張に据えている。5科目の最短構成を足すと：

```
簿記論450 + 財務諸表論400 + 選択必須(所得 or 法人)600 + 国税徴収法200 + 酒税法150 = 約1,800時間
```

比較表の行名は「**必要勉強時間**」であり、読者は「取得までに要る時間」として読む。**数字そのものが誤りなのではなく、置かれた場所と行名が数字の意味を変えている。**

### 判断が要る点

- **⚠️ 揃え先を多数決で決めてはいけない。** 08-14に勉強時間5資格の不整合で同じことを書いた。今回も、5本が「3,000〜5,000」・3本が「3,000〜4,000」だが、**どちらが正しいかは記事の中では決まらない。** 一般に公認会計士は3,000〜5,000時間とされることが多いが、**本稟議では一次情報で確認していない。** 揃えるなら先に出典を確定させるべきである。
- **⚠️ 一括置換は危険である。** `zeirishi-vs-cpa.html` の「3,000〜4,000時間」を「3,000〜5,000時間」に置換すると、**税理士と会計士が同じ数字になり、比較表としての情報量が消える。** 比較記事で両者が同値になることが妥当かは別途判断が要る。
- **⚠️ 3-2は「行名を変える」「注記を足す」「5科目基準の数字に差し替える」のどれを選ぶかで、記事の主張が変わる。** `zeirishi.html` が「1科目ずつでいい」を主張している以上、5科目基準に寄せる方が一貫するが、**それは「税理士は会計士より短時間で取れる」という新しい主張を生む。** 慎重な判断が要る。

## CEOジョブズの所見

指摘1と2は、**書き手が知らなかったのではなく、知ったうえで途中で止まっている**という点で同じ形をしている。

`ap.html` は2026年度のCBT移行に気づいて名称変更を書いた。そこで止まった。`zeirishi.html` は2023年改正に気づいてFAQを直した。そこで止まった。**どちらも「対応した」という記録が残り、残りの箇所は誰も見に行かない。**

これは注意力の問題ではない。**「制度改正に触れているか」という二値の確認しかしていないから、途中で止まった記事が『済』の側に分類される**という、監査側の設計の問題である。08-11に一度この結論を書いた。書いた後で2件再発した。**結論を書くことと、検査条件を変えることは別の作業である。**

指摘3は8週連続で出ている型で、正直に言えば、これを毎週報告し続けることに私は意味を感じなくなっている。**1本ずつ読む監査では原理的に見つからないと4週間前に結論が出ていて、横断grepをローテーションの外に出す提案は着手されていない。** 今回も指摘3が見つかったのは、`zeirishi.html` と `zeirishi-vs-cpa.html` がたまたま同じ週の15本に入っていたからである。

そして最も重いのは、**8週間前に指摘した `cpa-akirameta-zeirishi-boki1.html` の税理士受験資格が、本日時点で1文字も変わっていない**ことである。あの記事は「大卒でないなら簿記1級を取ってから税理士へ」と書いている。存在しない要件のために300〜500時間の回り道を指示する文章が、12週目に入る。

**それはユーザーの人生を本当に変えるか。変える。悪い方向に。**
