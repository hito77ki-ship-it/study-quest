# 稟議書：公開投稿の悩みリサーチ運用と会計士受験記事候補

**日付：** 2026年9月7日
**提案元：** AI
**種別：** 記事企画のための調査運用・新規記事候補の整理（本文・UIは変更しない）
**ステータス：** ✅ 取締役承認済み（2026年9月7日：公開投稿を使う API 不要の悩みリサーチ、記事候補化、公式情報の確認、記録作成を実施する明示指示）

> **本稟議の判断・提案は4件である。** 全記事スキャンで見つけた件数ではなく、公認会計士受験に絞った初回の公開ページ確認と既存4記事との重複確認に基づく。記事本文、図解、UIは本稟議では変更しない。

## 背景

悩みの言葉をリサーチすれば、制度ページだけでは見えにくい「読者がどこで判断を止めるか」を発見できる。一方、個人投稿や公開 Q&A は、出現頻度、一般性、正確性、将来の結果を裏付けない。誤って引用・保存・一般化すると、読者の個人情報と記事品質の両方を損なう。

そこで、公開投稿を「悩みの仮説」にだけ使い、制度・日程・選考などの事実は公開前に一次情報へ戻す運用を定める。初回記録は [会計士受験に関する悩みリサーチ：初回記録](../reports/20260907-会計士受験_悩みリサーチ初回.md) に残した。

## 判断・提案

### 1. 公開投稿を使う範囲を限定する

公開ページからは検索語、悩みの種類、記事が解くべき判断だけを匿名化して記録する。投稿本文、スクリーンショット、投稿者名・ハンドル・プロフィールを保存または記事へ転載しない。X の自動取得は、公式 API と利用規約を別途確認するまで行わない。

### 2. 健康に関する個人的な記述は企画材料にしない

進路の迷いには強いストレスを伴う公開相談も存在する。しかし、個人の健康情報を分類・保存してコンテンツ需要として扱うことはしない。医療や相談支援を扱う必要が生じたときは、資格記事の延長で書かず、一次情報と範囲を別稟議で確認する。

### 3. 会計士受験記事は、既存資産と重複しない1候補だけを次回起案する

今回の候補は「公認会計士受験と一般就活を並行するか：試験日・応募締切・自分の予定を照合する判断シート」である。断念後の応募書類整理は `cpa-akirameta-shukatsu.html`、進路・資格比較は `cpa-akirameta-shinro.html`、`cpa-akirameta-boki1.html`、`cpa-akirameta-zeirishi-boki1.html` が既に扱うため、新規記事を作らない。

候補記事の結論は「並行すべき」ではなく、試験日、応募締切、授業・仕事・生活上の制約、確保できる時間を読者自身が照合する手順に置く。選考の有利不利、必要応募数、必要学習時間、合格可能性を断定しない。

### 4. 公式情報は、企画段階と公開直前の二段階で確認する

初回は公認会計士・監査審査会が公開する令和8年試験日程を実際に確認した。記事を実装する場合は、当年の試験日程と各応募先の募集要項を公開直前に再確認する。個人記事・公開 Q&A の内容は、試験日程、採用時期、選考結果の根拠にしない。

## 実施結果と次の条件

- [公開投稿を使う悩みリサーチ運用ルール](../knowledge/20260907-公開投稿を使う悩みリサーチ運用ルール.md) を作成した。
- 会計士受験の初回記録を作成し、公開ページの観察と一次情報を分けた。
- 既存4記事との重複を確認し、候補を1件に絞った。
- API キーの取得、投稿の自動収集、SNS への送信、AdSense の再申請は行っていない。

候補記事を実装する場合は、別稟議でタイトル・想定読者・構成・一次情報・内部リンク計画を確定し、記事更新日、JSON-LD、sitemap、`index.html` の更新情報を同期する。今回のドキュメント作成だけでは、記事公開の承認とはしない。
