# JSON-LD Article構造化データに"image"プロパティが196記事中195記事で欠落している問題の修正提案

**日付：** 2026年7月27日
**提案者：** CEO ジョブズ（週次技術SEO監査タスクより）
**決定者：** 未定
**ステータス：** 取締役の承認待ち

## 背景・ファクトチェック

週次技術SEO監査の一環で、全208 HTMLファイルのJSON-LD構造化データをスクリプトで機械的に検査した。

- Article/BlogPostingタイプのJSON-LDは196記事に存在（JSON構文エラーはゼロ、既存の稟議 `20260721-低品質記事の内部リンクと構造化データ改善.md` の対応後、設置率はほぼ100%を維持している）。
- しかし**196記事中195記事（99.5%）で`image`プロパティが完全に欠落**している。唯一存在するのは`cpa-subjects.html`（独自SVG画像を指定）のみ。
- 一方、198記事に`og:image`メタタグは存在しており（大半は共通の`https://study-quest.net/screenshots/ogp_logo.png`、一部記事は専用OGP画像）、画像アセット自体は既に用意されている。つまり「og:imageの値をJSON-LDにも複製する」だけで機械的に解決できる。
- Googleの構造化データガイドライン（Article rich results）では`image`はGoogle検索でのリッチリザルト表示（トップストーリーズ・記事カード表示等）の**必須プロパティ**として明記されている。`image`欠落はJSON-LDとして無効にはならないが、リッチリザルト対象から外れる、または画像なしの貧弱な表示になるリスクがある。

## 提案内容

1. 各記事のJSON-LD（Article/BlogPosting）に、既存の`og:image`の値（専用OGP画像があればそれを、なければ`ogp_logo.png`）を`image`プロパティとして追加する。
2. 対応方法は1記事ずつ手作業ではなく、`og:image`の値を読み取ってJSON-LDに注入する一括スクリプトでの機械的な修正を推奨（195記事を人力で編集するのは非現実的かつミスの温床になるため）。
3. 修正後、Google Rich Results Testで数記事サンプリングして検証する。

## ジョブズの所見

これは派手な新機能ではないが、「検索上位表示」という最優先目標に対してほぼゼロコストで効く改善だ。素材（og:image）はすでにある。あとはコピーするだけなのに、195記事分やらずに放置している状態は、正直に言って手抜きだと評価する。甘く見ない。

ただし優先度としては、これは「今すぐサイトが死ぬ」類の緊急性はない。sitemap漏れやnoindex漏れ（別稟議参照）の方が実害が具体的にイメージしやすい。とはいえ一括スクリプトで直せる話なので、次回のメンテナンス枠で一気に片付けるべき。ユーザーの人生を変えるほどの一手ではないが、検索エンジンに正しく評価してもらうための「基礎工事」として着手する価値はある。
