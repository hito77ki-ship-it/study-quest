# 記事品質是正：保育士試験の公式制度と根拠不明な学習計画

**ステータス：実行済み（包括実行委任・低リスクの事実是正）**
**決定日：2026年9月4日**
**本稟議の指摘は 8 件。** `hoikushi.html` の制度説明を、実際に確認した一般社団法人全国保育士養成協議会の令和8年後期案内にそろえる。

## 指摘と対応

| # | 指摘 | 対応 |
|---|---|---|
| 1 | 筆記試験の合格条件が「9科目すべて60点」とだけ書かれ、教育原理・社会的養護の同一試験要件が欠ける | 公式の条件を本文・FAQに明記 |
| 2 | 実技の楽器にアコーディオンを含めている | ピアノまたはギターに訂正 |
| 3 | 言語実技の課題数・方法が現行案内と異なる | 3話から入室後に1話指定、3分間、小道具不可に訂正 |
| 4 | 「止まらず弾き続けることが採点基準」と断定している | 根拠を確認できない解説セクションごと削除 |
| 5 | 実技合格率80%以上、最適な選択組合せを断定している | 根拠がない数値・順位付けを削除し、公式案内確認へ変更 |
| 6 | 科目別・合計の勉強時間、難易度、6か月計画が根拠なく固定されている | 数値表・固定計画・図解を削除し、受験日から逆算する手順へ変更 |
| 7 | 合格率と独学合格者数を根拠なく記載している | 削除。独学は選べる学習方法であり合格保証ではないと明示 |
| 8 | 一次情報への読者向け出典がない | 本文に公式一次情報リンクと確認日を追加 |

## 実施範囲

- 対象は `hoikushi.html` と `sitemap.xml`、本稟議・実施報告のみ。
- 記事の title / h1 / description を、本文に実在する公式制度の解説へ一致させる。
- JSON-LD、本文表示、sitemap の更新日を 2026年9月4日に同期する。
- 既存の SVG 図解は、根拠のない時間・順位・合格率を含むため記事から外す。画像ファイル自体は削除しない。共通のおすすめ欄で読み込まれる記事サムネイルは、「最短スケジュール」の訴求を本文と整合する「筆記・実技を確認」へ置換する。

## 検証条件

1. `git diff --check` が通ること。
2. HTML 内の JSON-LD を構文解析できること。
3. title / h1 / og:title / description が同一の記事内容を指すこと。
4. `dateModified`、表示更新日、sitemap の `lastmod` が 2026年9月4日で一致すること。
5. 根拠のない勉強時間、合格率、実技の推奨組合せ、アコーディオン表記が残らないこと。
