# 記事会話UIを「学習メモ」へ再設計し、表情アイコンセットを追加する

**日付：** 2026年8月21日
**起案：** CEO ジョブズ（AI）
**ステータス：** 取締役承認済み（2026年8月21日・会話上の実行指示）
**本稟議の指摘は 2 件：** 記事会話における若葉の立場、会話の意味を補う表情アイコンの不足。本件は既存の全記事会話UIを対象にした表示・導線設計であり、各記事本文の事実関係を再監査した件数ではない。

## 1. 背景

現在の会話UIは、`受験生`が質問し、`若葉`が答える `student / teacher` 構造である。一方、若葉の確認済みの立場は「関西の大学3回生・日商簿記1級を勉強中・簿記3級/2級合格」であり、各資格を教える専門家ではない。プロフィールと会話の見え方が一致しないため、書き手が先生として断言しているように受け取られる。

また、同じ顔・同じ表情だけでは、質問・不安・調べて整理したこと・気づき・次の行動という会話の役割が見分けにくい。

## 2. 決定

1. `teacher` という役割・表示を廃止し、若葉の発言を **「若葉の学習メモ」** として表示する。別の「先生」キャラクターは作らない。
2. 従来の「受験生」は実在の相談者に見えないよう、表示を **「学習中の疑問」** または **「つまずきメモ」** とする。
3. 会話の意味に応じて、以下5種の同一絵柄アイコンを使い分ける。アイコン内に文字は入れない。

| 場面 | 表示 | アイコン | 役割 |
|---|---|---|---|
| 質問 | 学習中の疑問 | `icon-dialogue-question.png` | 何を知りたいかを先に言語化する |
| 不安・迷い | つまずきメモ | `icon-dialogue-worry.png` | 学習時の困りごとを可視化する |
| 確認・整理 | 若葉の学習メモ | `icon-wakaba-research.png` | 公式情報・本文・問題を調べて整理する立場 |
| 理解の着地 | 気づきメモ | `icon-wakaba-insight.png` | 覚え方や判断軸を短く残す |
| 行動提案 | 次の一歩 | `icon-wakaba-plan.png` | 次に確認・練習する行動へつなぐ |

## 3. 実装範囲

- `article-widgets.js` の会話UIの内部ロール、ラベル、`alt`、色クラス、画像参照を更新する。
- 新しいPNG 5点を `images/` に追加する。既存の `images/icon-wakaba.png` は著者プロフィール用として維持する。
- 既存会話文の文章・数値・事実主張は、この公開単位では書き換えない。UIを「学習メモ」と明示しても、裏付けのない最上級表現・成果保証・体験談は正当化されないため、本文と会話の品質監査で記事ごとに確認する。

## 4. 検証条件

1. `teacher` / `student` が会話UIの内部ロール・画面表示として残らないこと。
2. 5種の画像がすべて存在し、透過背景・44px円形表示で輪郭が欠けないこと。
3. PC・モバイル、System/Light/Darkで名前・本文・アイコンのコントラストと折返しを目視すること。
4. 既存の記事本文、JSON-LD、更新日、サイトマップをこの変更だけのために更新しないこと。

## 5. 判断理由

若葉を「正解を教える人」ではなく、「自分も学びながら公式情報と問題を整理して共有する先輩受験生」として示す方が、確認済みの実体験の範囲と整合する。読者が会話の役割を瞬時に把握でき、専門家を装う印象も避けられる。
