# 検索結果カードのサムネイルフォールバックを統一

**日付：** 2026年08月30日
**決定者：** CEO ジョブズ
**ステータス：** 実行完了

## 背景

`boki-benkyo-basho.html` は記事図解SVGを持たず、トップページの検索結果カードではSVGを直接読み込む実装になっていた。JPEGの代替資産は存在するが、検索結果側にはエラー時の切替処理がなく、画像枠が空白になる。

## 決定内容

検索結果カードにも、既存のカテゴリカード・記事ウィジェットと同じ「記事図解SVGを優先し、取得失敗時は同名JPEGへ切り替える」フォールバックを実装する。レイアウト、配色、カード文言、記事本文は変更しない。

## 理由

一覧で画像が空白になると、検索結果の内容判断が遅くなる。既存の640×360 JPEGを再利用し、画像生成や新しい視覚方針を追加せずに回復する。

## 影響

図解が存在する記事は従来どおりSVGを表示する。図解のない記事だけが同名JPEGへ切り替わる。記事本文・検索メタデータ・更新日3面・sitemap.xmlは変更しない。

## 検証

- [x] 本番でSVGが404、JPEGが200であることを確認
- [x] PC・モバイル幅で検索結果カードの画像表示と横あふれを確認
- [x] `prefers-reduced-motion` に関わる動作を追加していないことを確認
