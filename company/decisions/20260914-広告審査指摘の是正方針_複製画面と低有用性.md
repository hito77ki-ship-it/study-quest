# 稟議書：広告審査指摘の是正方針（複製画面と低有用性）

**起票日：** 2026-09-14
**起票者：** CEO ジョブズ
**ステータス：** 取締役の承認待ち
**種別：** 公開構成の判断、および記事コンテンツ改善の方針

---

## 1. 本稟議の指摘は4件

本稟議の指摘は、AdSense、Google Search Console、Bing Webmaster Toolsを実際に開いた結果と、全209記事の静的監査を合わせた**全サイト監査での4件**である。機械候補187件・124件を修正件数として扱わない。

1. `study-quest.net/apple-lp/` 以下に、Study Questと無関係な別事業LP3ページが公開状態で残っている。
2. AdSense審査は「複製された画面」と「有用性の低いコンテンツ」を理由に、サイトを広告表示不可としている。
3. Search Consoleで19ページが「検出 - インデックス未登録」だが、確認できた例は全てsitemap掲載済みである。
4. `eiken3.html`、`eiken4.html`、`eisei-kanri.html` は、未クロール・広告マーカー・独自性候補が重なるため、記事単位の一次情報確認を先行すべきである。

## 2. 承認をお願いしたいこと

### A. 別事業LPの公開オリジン隔離を判断する

`apple-lp` の3ページについて、Study Questの公開配信から外す、別ドメインまたは別ホストへ移す、または別の安全な配置にする方針を決める。

これは別事業の利用者・導線に影響しうるため、ファイル削除や公開停止を本稟議の承認前に行わない。`noindex` の維持だけでよいか、公開オリジンから隔離するかが判断点である。

### B. 記事改善は3件のファクトチェックから始める

次の3記事を対象に、掲載中の数値・制度・学習助言を公式一次情報と照合し、読者が自力で判断できる手順と、読者に見える出典を設計する稟議を別途作成する。

- `eiken3.html`
- `eiken4.html`
- `eisei-kanri.html`

この段階では本文を変更しない。公式一次情報を実際に開いてから、具体的な修正案・更新日同期・検証方法を提示する。

### C. URL再送信・再審査を行わない

Google/BingへのURL送信、IndexNow、AdSenseの「問題を修正しました」または「審査をリクエスト」は、AとBの実施・公開・検証後まで行わない。

## 3. 期待する効果と限界

別事業LPの隔離と記事の有用性向上は、AdSense指摘への合理的な対応である。しかし、審査結果を保証するものではない。Bingの216 URL検出成功とGoogleの手動対策・セキュリティ問題なしは、原因がサイトマップ送信漏れや手動ペナルティである可能性を下げる材料に留まる。

## 4. 承認後の順序

1. Aの公開構成を、影響範囲を確認した隔離cloneで実装・検証・報告する。
2. Bの3記事を一次情報でファクトチェックし、個別稟議を作る。
3. 取締役承認後に記事を実装し、JSON-LD・表示更新日・sitemap・index.html更新情報を同期する。
4. 公開状態とAdSense審査前チェックを確認する。
5. 取締役が再審査を明示指示した場合だけ、外部送信を行う。
