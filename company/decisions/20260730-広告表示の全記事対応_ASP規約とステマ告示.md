# 【稟議】広告・アフィリエイトの明示を全記事に表示する

**起案日：** 2026年7月30日
**ステータス：** ✅ 承認・実行済み
**契機：** もしもアフィリエイトのメディア登録時、ガイドラインを取締役が確認された際に発覚

---

## 1. 【重要な訂正】法令上の規制対象を私は間違えていた

私は取締役に「これは審査の問題であると同時に**景品表示法の問題**です」と報告した。**これは不正確だった。**

消費者庁の公式ページに明記されている。

> **景品表示法の対象となるのは事業者だけです。**
> 規制の対象となるのは、商品・サービスを供給する事業者(広告主)です。企業から広告・宣伝の依頼を受けたインフルエンサー等の**第三者は規制の対象とはなりません。**
> — [消費者庁「令和5年10月1日からステルスマーケティングは景品表示法違反となります。」](https://www.caa.go.jp/policies/policy/representation/fair_labeling/stealth_marketing/)（2026-07-30確認）

**ステマ告示の法的な規制対象は広告主（予備校側）であり、アフィリエイトメディア側ではない。**

では対応が不要なのか。**必要である。理由が変わるだけだ。**

| 根拠 | 内容 | 拘束力 |
|---|---|---|
| 景品表示法（ステマ告示） | 規制対象は広告主。当サイトは対象外 | **なし** |
| **もしもアフィリエイト メディア運営ガイドライン** | 「メディアの収益手段としてアフィリエイトを利用していることや広告を掲載していることをメディアに表示してください」 | **契約上必須。違反は提携解除・メディア登録削除** |
| 読者への誠実さ | 収益が発生する立場を隠さない | 自主的判断 |

**つまり「法律で決まっているから」ではなく「ASPとの契約で決まっているから」かつ「読者に対して隠すべきでないから」やる。** 理由を正確に持っておくことは重要である。理由が曖昧なままだと、対応の程度も曖昧になる。

## 3. 実行内容

### ① 全記事への表示（`article-widgets.js` に1関数追加）

```js
function injectAdDisclosure(){
  const container = document.querySelector('.container');
  if(!container) return;
  if(container.querySelector('.sq-ad-disclosure')) return;   // 二重挿入を防ぐ
  const el = document.createElement('p');
  el.className = 'sq-ad-disclosure';
  el.innerHTML = 'このページには広告（アフィリエイトリンク）が含まれます。'
    + '<a href="about.html#ad">広告・収益化について</a>';
  const bc = container.querySelector('.breadcrumb');
  if(bc) bc.insertAdjacentElement('afterend', el);
  else container.prepend(el);
}
```

**パンくずの直後、記事タイトルより上に置く。** スクロールせずに見える位置であることが「見やすい箇所」の条件だと判断した。

CSSは `--sq-*` 変数にフォールバック付きで連携させた（`CLAUDE.md` コーディング規約）。font-size 11px・枠線ありの控えめな表示で、記事本文の邪魔をしない。

**記事HTMLは1バイトも触っていない。1関数の追加で205記事すべてに入る。**

### ② `about.html` の記載を具体化

```
旧：記事内で紹介するテキスト・教材等はAmazonアソシエイトなどの
    アフィリエイトリンクを含む場合があります。

新：記事内で紹介するテキスト・教材・講座等には、Amazonアソシエイト・
    もしもアフィリエイト・アクセストレード等を通じたアフィリエイトリンクを
    含む場合があります。リンク経由で商品・サービスのお申し込みがあった場合、
    当サイトに紹介料が支払われることがあります。

    ただし、紹介料の有無が記事の評価・順位に影響することはありません。
    受講料や合格率などの数値は各運営元の公式サイトで確認し、確認できなかった
    ものは掲載していません。実際に使っていないものを「使った」とは書きません。
```

`id="ad"` を付与して、全記事の表示からアンカーリンクで飛べるようにした。

**後半の3文を入れた理由を書いておく。** もしもの規約は「表示せよ」しか求めていない。しかしこの3文は**当サイトが実際にやっていること**である。

- 「紹介料の有無が順位に影響しない」→ 本日 `boki1-yobikou.html` で、提携申請していない大原がTACより安いという事実をそのまま書いた
- 「確認できなかったものは掲載していない」→ クレアール・ネットスクールを載せなかった
- 「使っていないものを使ったと書かない」→ 若葉の実体験の範囲を `company/style-guide.md` で管理している

**やっていないことを書けば嘘になる。やっていることだから書ける。** これは読者に対する約束として機能する。

## 4. CEO所見

**この問題は、取締役がガイドラインを読んでくださるまで私は気づいていなかった。**

今日、収益導線の稟議を2本書き、33記事に導線がないことを「最大の未回収」と報告した。**リンクを増やす話ばかりしていて、増やす前に必要な表示のことを一度も考えていなかった。** 順序が逆である。

もし気づかずにアフィリエイトリンクを33記事に貼っていたら、規約違反の状態で本番に出していた。**提携解除やアカウント凍結は、収益がゼロになるだけでなく、再申請も難しくなる。** 導線を作る前に止まれたのは運が良かった。

そして法令の理解も間違っていた。「景品表示法違反になる」と言いましたが、規制対象は広告主でした。**危機感を煽る方向に間違えた**わけで、これは事実確認を怠った結果です。今日これで何度目かは数えていません。

**表示位置について1つ判断を書いておく。** 記事タイトルより上に広告表示を置くと、読者が最初に見るものが「広告が含まれます」になる。CTRの観点では不利かもしれない。だが**隠す方向に最適化した瞬間に、この表示の意味がなくなる。** 上に置く。

## 5. 取締役にお願いしたい確認

サンドボックスではレンダリングできないため、以下をご確認いただきたい。

- 任意の記事を開き、パンくずの下に「このページには広告（アフィリエイトリンク）が含まれます。」が表示されているか
- **ライト／ダーク両モード**で文字が読めるか（`--sq-muted` の色が背景に沈んでいないか）
- 「広告・収益化について」のリンクが `about.html` の該当セクションに飛ぶか
- 表示が大きすぎて記事の邪魔になっていないか（大きければ調整する）

## 6. 残課題

- **AI利用の明記について。** もしものガイドラインは「AIを利用した記事や画像の掲載を行う場合、『生成AIにより作成』など明記することを**推奨**します」としている。必須ではない。当サイトは記事執筆とSVG図解の作成にAIを使っており、**この扱いは別途判断が必要。** ただし同ガイドラインは「人の目で校正・事実確認を行っていない」「運営者の視点や感想が含まれていると判断し難い」ものをNGとしており、当サイトは若葉の一人称の体験と視点が入っているため、この点は満たしていると考える
- 「PR」表記が必要な個別ケース（特別単価や商品提供を受けた記事）は、該当が発生した時点で対応する
