# カテゴリ代表記事と戻り導線の実装

**日付：** 2026-08-10
**ステータス：** 実行完了

## 背景

AdSense合格とSEO強化に向け、記事一覧を大分類へ再編した。次に必要なのは、各カテゴリに「入口記事」を決め、個別記事から必ず入口へ戻れる導線を作ることだった。

個別記事が孤立すると、ユーザーは次に何を読めばいいか分からない。Googleにもカテゴリ内の主従関係が伝わりにくい。

## 判断

代表記事は以下とする。

| カテゴリ | 代表記事 |
|---|---|
| 簿記 | `boki.html` |
| 簿記2級 | `boki2.html` |
| 簿記1級 | `boki1.html` |
| FP | `fp.html` |
| FP3級 | `fp3.html` |
| 公認会計士 | `cpa.html` |
| 税理士 | `zeirishi.html` |
| 司法書士 | `shihoshoshi.html` |
| 法律資格 | `takken.html` |
| IT資格 | `itp.html` |
| 英語資格 | `toeic.html` |
| 大学生・社会人 | `shukatsu-shikaku.html` |
| 学習継続 | `keizoku.html` |
| 資格ガイド一覧 | `shikaku-list.html` |

補足：`boki3.html` は存在しないため、簿記3級系の記事は `boki.html` をカテゴリ入口、`boki3-progress.html` を進捗ハブとして扱う。

## 実行内容

- `article-widgets.js` に代表記事ルール `HUB_RULES` を追加した。
- 各記事の上部に「カテゴリ入口」ボックスを自動挿入する `buildHubReturn()` を追加した。
- 代表記事自身には戻り導線を出さない。
- クリック計測イベント `hub_return_click` を追加した。

## 検証

- `node --check article-widgets.js`：通過
- 代表記事ファイルの実在：全件OK
- 代表記事の `ARTICLES` 登録：全件OK

## 次の一手

代表記事側に「このカテゴリで最初に読む順番」を明示する。特に簿記・FP・英語資格は、入口記事から論点記事へ進む順番を整えると回遊がさらに強くなる。
