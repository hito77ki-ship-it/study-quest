# 稟議：`cpa-yobikou.html` に予備校の費用比較を追加する

**起案：** CEOジョブズ
**日付：** 2026年7月31日
**ステータス： **承認済み・実行完了（2026年7月31日）**
**対象：** `cpa-yobikou.html`（公認会計士・税理士の予備校 vs 独学）

---

## 発見した問題

```
cpa-yobikou.html
  本文        7,903字
  予備校名    17回言及
  金額の記載  0箇所
```

h2構成はこうなっている。

- 公認会計士試験：予備校と独学の比較
- 税理士試験：予備校と独学の比較
- 予備校と独学、どちらを選ぶべきか チェックリスト
- まとめ／よくある質問／関連記事

**「予備校と独学、どちらを選ぶべきか」を7,903字論じておいて、予備校の費用が1円も書かれていない。** 独学と予備校を分ける最大の要素は費用である。それが無いまま「どちらを選ぶべきか」を語っているので、**比較として成立していない。**

これは `boki1-yobikou.html` で本日修正したのと同じ穴が、会計士側にも空いていたということである。

---

## なぜ新規記事ではなくこの記事なのか

新規記事（簿記2級の講座比較など）も候補だったが、**GSCの数字が新規記事を否定している。**

```
未登録：159
  検出 - インデックス未登録        142
  クロール済み - インデックス未登録   16
```

**142ページがインデックスされていない状態で1本足しても、143になるだけである。** インデックス作成レポートの最終更新日は7/10から3週間止まっている。

既にインデックスされている既存記事を厚くする方が、確実に早い。

## 追加する内容の案

1. **h2「公認会計士の予備校はいくらかかるか」** — 4校の受講料表。初学者向けと受験経験者向けを分ける
2. **tip-box：費用を下げる制度** — 教育ローン・奨学生制度・合格返金制度・有資格者免除。**条件も併記する**（boki1-yobikouで祝賀金の条件を書いた前例に倣う）
3. **warn-box：若葉の実感** — 「予備校に入れば受かるわけではない」。会計士試験を1年半やって断念した立場からの正直な注記
4. 税理士側にも同様の費用表（各校の科目別受講料）

## ジョブズの所見

**この穴は、金額を書かなかったことより「比較と名乗ったのに比較していなかった」ことの方が重い。**

読者が「予備校か独学か」で迷う理由の大半は費用である。80万円か0円かという差を伏せたまま、学習効率やサポート体制の話を7,903字続けても、読者の意思決定には届かない。**titleが約束した内容が本文に無い**という、7月29日にチェックリスト化したのと同じ構造の問題である。

同時に、正直に書いておく。**私はこの記事の存在を知りながら、今日まで中身を確認していなかった。** boki1-yobikouの費用比較を追加したとき、「他の予備校記事はどうなっているか」を確かめていれば、その場で見つかっていた。**1件直したら同種を全部走査する、というルールをまだ体に入れられていない。**
