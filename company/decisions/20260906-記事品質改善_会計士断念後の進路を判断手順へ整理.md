# 稟議書：会計士断念後の進路記事を、将来の断定から判断手順へ整理

**起案日：** 2026年9月6日
**起案者：** CEO ジョブズ
**ステータス：** ✅ 取締役承認済み（2026年9月6日：継続作業の明示指示）
**重要度：** 高（AdSenseの有用性・独自性、進路判断の誤認防止）
**対象：** `cpa-akirameta-shinro.html`、関連SVG 2点、`index.html`、`sitemap.xml`

> ## 本稟議の指摘は 7 件である。
>
> 1〜3は根拠のない将来・評価の断定、4〜5は制度情報と選択肢の説明不足、6は図解内の同型断定、7はメタデータと更新導線の同期である。今回の監査対象は1記事と図解2点であり、サイト全体の件数ではない。

## 監査結果

1. title / h1 / description / JSON-LD が「後悔しにくい選び方」を約束している。しかし、進路選択の将来の後悔を判定・保証する根拠はない。
2. 本文・FAQ・会話に「勉強量と努力できる才能は絶対に消えない」「就職活動のどこかで必ず牙になる」「経理・会計職で説明しやすい」等がある。個人の経験・応募先・採用基準に左右され、一般論として断定できない。
3. 「簿記1級や税理士が向く」等、読者の適性を分類しているが、判断材料と検証方法が本文にない。
4. 税理士試験は科目合格制だが、会計科目（簿記論・財務諸表論）と税法科目では受験資格が異なる。この選択条件を示さずに「税理士」を一つの選択肢としている。
5. 簿記1級は4科目・各90分、合格基準70％かつ各科目40％以上であり、合格者には税理士試験の受験資格が与えられる。従来記事には、次に検討するための公式条件がない。
6. PC・モバイル図解に「努力は消えません」「強みに変えて活動する」「そのまま活かせる」「自分のペースを作れる」とある。本文と同じ断定を画像として固定している。さらに白い背景矩形があり、テーマ切替に対応しない。
7. 実質的な記事・図解更新となるため、Article JSON-LD、本文表示、sitemap、index.html更新情報を同日付で同期する必要がある。

就職・転職での有利不利、採用評価、経験が将来役立つ程度を一律に示す一次情報は確認できない。したがって、これらを新たな一般論で補わず、求人票と自分の記録を照合する手順にする。

## 実施内容

- title / h1 / og:title / description / Article JSON-LD の主題を「後悔しにくい」から「4つの選択肢と確認すること」に統一する。
- 会話、本文、FAQ、CTA、まとめから成果・評価・将来の断定を削除し、「公式条件」「応募先の条件」「自分の記録」を確認する問いに置き換える。
- 簿記1級・税理士の各節に、上記一次情報への読者から見える出典リンクを置く。
- 図解を「選択を決めるフロー」から「4つの確認先」に変更する。透過背景・中間色の線と文字で作り、進路の優劣は示さない。
- `dateModified`、本文更新日、sitemap `lastmod`、index更新情報を `2026-09-06` に同期する。

## CEO所見

会計士を断念した人に必要なのは、きれいな励ましや「この先も必ず活きる」という約束ではない。今の選択を、制度・求人・自分の体調と記録で確認できる足場である。前2件の関連記事と同じ基準へ揃えることで、感情を否定せず、しかし進路や採用結果を断定しない記事にする。
