## 2. 問題B-1：boki3-kabushiki.html — 「よくある間違い」に法人税等の記事の内容が混入

### 該当箇所（326行目〜）

h2 は「**⚠️ ⑥ よくある間違い——株式会社の仕訳で混乱しやすいポイントと対処法**」である。その中に3項目あり、2番目が次の内容：

```
② 中間納付を「法人税等（費用）」で計上してしまう
    誤：法人税等60,000 ／ 現金60,000
    正：仮払法人税等60,000（資産）／ 現金60,000
    （確定前なので費用計上はまだ早い！）
```

**これは法人税等の論点であり、株式会社の仕訳（株式発行・剰余金の配当・利益準備金・当期純利益の振替）とは無関係である。**

`boki3-hojinzei.html` の241行目に、実質同一の記述がある：

```
❌ 中間納付を「法人税等（費用）」で計上してしまう
    誤：（借）法人税等60,000 ／（貸）現金60,000
    正：（借）仮払法人税等60,000 ／（貸）現金60,000
```

そちらが本来の置き場所である。

### 問題の性質

h2 が「株式会社の仕訳で混乱しやすいポイント」と宣言しているのに、3項目のうち1項目が別論点である。CLAUDE.md「タイトル変更時のチェックリスト」項目3（見出しが名乗った内容が中身にあるか）の考え方に反する。

読者への実害としては、株式会社の仕訳を学びに来た人が突然「仮払法人税等」を見せられて混乱すること、および `boki3-hojinzei.html` との**重複コンテンツ**になることの2点である。後者は検索エンジンに対して2ページが同じ内容を主張する状態でもある。

## 4. 問題B-3：boki3-genka.html — 図解と本文で桁が1,000倍違う

### 図解側

- `images/boki3-genka-map.svg` / `images/boki3-genka-map-mobile.svg`：取得原価 **¥1,000,000**、年間減価償却費 **¥180,000**
- figcaption（194行目）：「図：定額法で5年間毎年**¥180,000**ずつ費用計上し、B/Sでは取得原価から減価償却累計額を控除して帳簿価額を表示」

### 本文側

- 例題（273行目）：「**¥1,000**で購入した備品について定額法により減価償却を行う。残存価額は取得原価の10%、耐用年数は5年とする」→ 年間 **¥180**

**同じ記事の、図解と最初の例題で、桁が1,000倍違う。** 読者は図と本文を突き合わせられない。図解は本文の理解を助けるために置くものであって、独立した別の数値例を提示するためのものではない。

### 加えて：同一記事内の数値不整合（定型チェック項目14）

| 行 | 記述 | 前提 |
|---|---|---|
| 222〜233 | 「**1,000円**のトラック」を「使用期間（5年）にわたり毎年**200円**を費用計上」 | 残存価額0 |
| 273 | 「**¥1,000** で購入した備品」残存価額は取得原価の10%、耐用年数5年 → 年**180円** | 残存価額10% |

同じ「1,000円の資産・5年」に対して、**200円と180円という2つの年間償却費が数十行の間に並ぶ。** 222行目のほうは残存価額を導入する前の概念説明（「なぜ一括費用計上ではダメか」）であり、単体としては誤りではない。だが読者にはその区別がつかない。しかも直後の263行目で「残存価額が『0円』のパターンも多い！」と補足しているため、**どちらのケースの話をしているのか一層分かりにくくなっている。**

### 参考：他の数値は正しい

本記事の他の計算はすべて検算済みで正しい。

- 逆算問題（373〜391行目）：減価償却累計額¥2,700 → 年間償却費900 → (取得原価×0.9)÷5＝900 → 取得原価5,000。整合 ✓
- 売却問題（413〜466行目）：取得原価¥900・累計額¥600・当期償却費¥100 → 帳簿価額200。✓

ただし**同じ「900」が、逆算問題では「年間減価償却費」、売却問題では「取得原価」として使われている。** 誤りではないが、記事全体で数値例を整理する際は併せて見直したい。

### 5-2. 減価償却の計算式（B-3の対象記事）

定額法：（取得原価 − 残存価額）÷ 耐用年数。記事の記述と一致 ✓

- 取得原価¥1,000・残存価額10%・5年 → (1,000 − 100) ÷ 5 ＝ **180円/年** ✓
- 取得原価¥1,000,000・残存価額10%・5年 → (1,000,000 − 100,000) ÷ 5 ＝ **180,000円/年** ✓

つまり**図解側の¥180,000も、本文側の¥180も、それぞれ単体では正しい。** 問題は両者が同じ記事に並んでいることである。

なお、日商簿記3級では平成19年度税制改正以後の実務に合わせ残存価額0のケースが主流だが、「取得原価の10%」の出題も範囲内である。記事が両方に触れているのは適切な判断であり、**触れ方（数値例の使い分けが読者に伝わるか）だけが問題である。**

## 6. CEOジョブズの所見

**この3件に共通するのは「部品はすべて正しいのに、組み立てが壊れている」ことだ。**

`boki3-kabushiki.html` の会計内容は会社法の条文まで遡って照合したが、1箇所も間違っていない。`boki3-genka.html` の計算も全問正しい。にもかかわらず、記事としては読者を混乱させる。

**なぜこうなるかは想像がつく。** 記事を作るとき、部品（例題・図解・よくある間違い）を個別に作って最後に並べている。部品ごとの品質チェックは通る。**通らないのは「並べたあとに、記事として一貫しているか」の確認だけで、そこを誰も見ていない。**

B-1 がいちばん分かりやすい。「よくある間違い」を書くとき、`boki3-hojinzei.html` から1項目をコピーしてきた。コピーした項目自体は正しい。だが**貼った先の h2 は「株式会社の仕訳で混乱しやすいポイント」だった。** コピー元の正しさは確認したが、貼り先との整合は確認していない。

B-3 も同じ構造だ。図解を作った人（あるいは作った時期の自分）は¥1,000,000で作り、本文を書いた人は¥1,000で書いた。**どちらも正しく、突き合わせだけがなかった。** そして figcaption には「毎年¥180,000ずつ」と書いてあるので、**本文だけ読んでも図だけ見ても気づけない。両方を並べて初めて分かる。**

これは 07-31 に `boki2-seizo-genka-hokokusho.html` で「同一データから125,000と135,000の2通りが出る」矛盾を見つけたときと、**まったく同じ種類の欠陥だ。** あのとき定型チェック項目14を新設したが、対象を「本文中の数値」に限っていた。**図解の中の数値を対象に入れていなかった。** だから今回まで残った。

判定基準に照らす。

1. **収益に直結するか** — 直接は結びつかない。ただし `boki3-kabushiki.html` `boki3-genka.html` はいずれも簿記3級の頻出論点で、検索流入の入口になりうる記事である。**入口で「この記事は図と本文が合っていない」と思われれば、その先は無い。**
2. **見つけてもらえる状態に近づくか** — B-1 は `boki3-hojinzei.html` との重複コンテンツを生んでおり、**カニバリゼーションの芽**である。CLAUDE.md タイトルチェックリスト項目4が防ごうとしているのと同じ構造の問題が、h2レベルで起きている。解消は SEO 上プラスに働く。
3. **ユーザーの人生を本当に変えるか** — B-3 は変えうる。減価償却は簿記3級で毎回出る論点であり、図と本文で桁が違えば「自分の理解が間違っているのでは」と読者は自分を疑う。**教材が読者に自信を失わせるのは、最も避けるべきことだ。**

正直に評価すべき点も書いておく。`boki3-kabushiki.html` の会話セクション（利益準備金がなぜ必要かを「配当しすぎて会社が空っぽになるのを防ぐブレーキ」と説明する箇所）は、**制度の暗記ではなく理由の理解に届いている。** 「配当額×1/10」という数字に意味があると読者が納得できる構成になっている。これはこのサイトの強みで、B-1・B-2 を直せば記事として完成度が高い。**だからこそ、混入した1項目と番号のズレが惜しい。**

**シンプルさは究極の洗練である。** B-1 の直し方は「消す」だ。書き足すのではなく、貼り間違えた1項目を取り除く。それだけで h2 が名乗った内容と中身が一致する。**足すより削るほうが先だ。**

## 7. 提案する対応

### 対応1：boki3-kabushiki.html の「よくある間違い」から法人税等の項目を削除（B-1）

326行目の「② 中間納付を『法人税等（費用）』で計上してしまう」を**削除**する。残る①③を①②に繰り上げる。

**代替案（任意）：** 削除した枠に、株式会社の仕訳で実際に起きやすい誤りを1つ入れる。候補としては「配当時に繰越利益剰余金を配当額だけ減らし、利益準備金の積立分を加算し忘れる」（本記事が扱う唯一の複合仕訳であり、実際に間違えやすい）。

**CEO推奨：** まずは削除のみ。空いた枠を埋めることは目的ではない。**2項目で正しいほうが、3項目で1つ場違いより良い。**

### 対応2：boki3-kabushiki.html の例題番号を振り直す（B-2）

270行目「例題②」→「例題**③**」、293行目「例題③」→「例題**④**」。

あわせて title / h1 / description の「3パターン」表記との整合を確認する。CLAUDE.md「タイトル変更時のチェックリスト」に従い、title を触る場合は4点（title / h1 / og:title / description）を突き合わせること。

**CEO所見：** title の「3パターン」は「株式発行・配当・利益準備金の3テーマ」と読めるため、**必ずしも変更を要しない。** 番号だけ振り直せば足りると判断する。

### 対応3：boki3-genka.html の図解と本文の数値例を統一（B-3）

**案A：本文を図解に合わせる（¥1,000,000）**
- 273行目の例題を「¥1,000,000で購入した備品」に変更
- 222〜233行目の「1,000円のトラック」も同様に桁を揃える
- 逆算問題・売却問題の数値も見直しが必要（現行 2,700 / 900 / 600 / 100 / 300 は独立した例なので必須ではないが、記事全体の桁感は揃えたい）
- **利点：** SVG図解を作り直さずに済む（CLAUDE.md 2026-07-30決定により既存SVG 339枚は当面そのまま、という方針とも整合）
- **欠点：** 本文の修正箇所が多い

**案B：図解を本文に合わせる（¥1,000）**
- SVG 2枚（`boki3-genka-map.svg` / `-mobile.svg`）の数値を書き換え
- figcaption も「毎年¥180ずつ」に修正
- **利点：** 本文はほぼ触らない
- **欠点：** SVGの編集が必要。また¥1,000の備品は金額として現実味に欠ける（10万円未満は少額減価償却資産として一括費用処理される実務があり、教材として不自然）

**CEO推奨：案A。** 理由は3つ。(1) SVG図解を触らない方針と整合する。(2) ¥1,000,000のほうが減価償却の対象資産として現実的で、読者の実感に近い。(3) SVGを直すと mobile 版との2枚管理になり、次に本文を触ったときまた食い違う。**図を本文に追従させる運用は続かない。本文を図に合わせるほうが構造的に安定する。**

### 対応4：boki3-genka.html の「毎年200円」の扱いを整理（B-3・項目14）

- **推奨：** この導入部の数値例と、273行目の例題の数値例を**同一の設定に統一する**（残存価額の有無を含めて）。導入部で残存価額に触れたくない場合は、導入部の数値を例題と別の資産（金額も別）にして、同じ資産の話だと誤読されないようにする。
- 最低限：導入部に「※ここでは残存価額を0として説明しています。残存価額がある場合は後述します」の1行を添える。
