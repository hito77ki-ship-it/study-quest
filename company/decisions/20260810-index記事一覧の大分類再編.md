# index記事一覧の大分類再編

**日付：** 2026-08-10
**ステータス：** 実行完了

## 背景

AdSense合格とSEO強化に向け、`index.html` の記事一覧が細かいカテゴリに分散していた。特に「法律・会計系」の中に、簿記・FP・公認会計士・税理士・宅建・行政書士などが混在しており、読者にも検索エンジンにもサイトの専門領域が伝わりにくかった。

## 判断

記事一覧を以下の8分類に寄せる。

1. 簿記
2. FP
3. 会計士・税理士
4. 法律資格
5. IT資格
6. 英語資格
7. 大学生・社会人
8. 学習継続

## 実行内容

- `cat-boki3` を `cat-boki` に変更し、簿記全体の入口にした。
- 旧「法律・会計系」を分解し、`FP`、`会計士・税理士`、`法律資格` を独立させた。
- `IT・技術系` を `IT資格`、`語学・教養系` を `英語資格` に変更した。
- `医療・福祉系` を、就活・社会人・実務資格を含む `大学生・社会人` に寄せた。
- `学習継続` セクションを新設し、継続術・勉強時間・アプリ活用・挫折対策をまとめた。
- サイドバーのカテゴリリンクを8分類に更新した。
- 検索モーダルのカテゴリフィルターを8分類に揃えた。

## 検証

- サイドバーのフラグメントリンク切れ：0
- 検索フィルターに出る分類：`学習継続 / 簿記 / FP / 会計士・税理士 / 法律資格 / IT資格 / 大学生・社会人 / 英語資格`

## 次の一手

各分類の中で重複カードを減らし、カテゴリハブ記事へ流す。特に `大学生・社会人 追加ガイド` はまだ広すぎるため、将来的に「資格ガイド一覧」ハブへ寄せる。
