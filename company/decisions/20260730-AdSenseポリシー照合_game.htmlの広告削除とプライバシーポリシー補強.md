## 1. ① `game.html` にAdSenseコードが入っていた（削除済み）

### 実測

```
game.html   AdSenseスクリプト:1  noindex:1  本文398字
```

### 該当するポリシー（3つに同時に触れていた）

**(a) 広告枠の価値**
> パブリッシャーのコンテンツを含まない画面における Google が配信する広告の扱い
> 次のような画面には、Google が配信する広告を配置できません。
> ・パブリッシャーのコンテンツが含まれていない、**または有用性の低いコンテンツを含んでいる**
> ・アラート、**ナビゲーション、その他の操作を目的として使用されている**

**(b) 広告のプレースメント（AdSenseポリシー初心者向けガイド）**
> **コンテンツ広告は、インタースティシャル ページ、ゲームプレイ画面、ストリーミング動画専用のサイトには掲載しないでください。** 動画ストリーミングまたはゲームプレイ画面で、オーバーレイ、インストリーム、インタースティシャル プレースメントを使用して収益化する場合は、動画向け AdSense または YouTube パートナー プログラムをご利用ください。

**(c) 広告とページコントローラの間隔**
> 広告とページ コントローラの間には十分な間隔を取ってください。たとえば、ゲームを含むサイトでは、ゲームのコントローラに近づきすぎないように広告を配置してください。

`game.html` は**本文398字のゲーム画面で、noindex 付き**である。「有用性の低いコンテンツ」「操作を目的とした画面」「ゲームプレイ画面」の3条件をすべて満たしていた。

**AdSenseスクリプトを削除した。** 検証：`<div>` 190/190、`<script>` 1/1 でバランス一致、AdSense参照 0件。

### なぜ危険だったか

AdSenseは現在**審査中**である。ポリシーセンターの説明にはこうある。

> なお、挙げられている URL はあくまで一例です。**同じ違反が他のページに残らないようサイト全体を確認してください。**
> 1 つのサイトについて問題の指摘を受けた場合は、他のページやサイトも確認のうえ、お客様のサイトのネットワーク全体がすべての AdSense ポリシーに準拠するようにしてください。

**1ページの違反がサイト全体の評価に波及する構造である。** 205記事が健全でも、`game.html` 1枚で審査に影響しうる。

## 2. ② プライバシーポリシーに必須項目の抜けがあった（補強済み）

### 該当するポリシー

> **プライバシーの開示**
> Google のプロダクトおよびサービスを利用することで、データの収集、共有、使用について明確に開示するプライバシー ポリシーを掲載し、それに準拠すること。これには、**使用されている技術（例: Cookie、ウェブビーコン、IP アドレスまたはその他の識別子）**に関する情報も含まれます。
> ウェブサイトに広告を掲載することによって、第三者がユーザーのブラウザに Cookie を保存したり、**ウェブビーコンまたは IP アドレス**を使用したりして情報を収集する可能性があることについて、プライバシー ポリシーで明示すること。
> Google によるデータの使用に関する開示義務を履行するには、**「Google のサービスを使用するサイトやアプリから収集した情報の Google による使用」ページへのリンクを目立たせて表示**することもできます。

### 照合結果

| 項目 | Before | After |
|---|---|---|
| Cookie | ✅ 7回 | ✅ |
| 第三者 | ✅ 5回 | ✅ |
| IPアドレス | △ 2回（データ収集の表の中のみ。広告文脈になし） | ✅ 4回 |
| **ウェブビーコン** | ❌ **0回** | ✅ 3回 |
| **その他の識別子** | ❌ 0回 | ✅ 1回 |
| **partner-sites へのリンク** | ❌ **0件** | ✅ 1件 |
| パーソナライズド広告の説明 | ❌ 0回 | ✅ 5回 |

**既存のプライバシーポリシーは想定より良く書けていた。** Google 広告設定・aboutads.info・Google の広告に関するポリシーへのリンクは既にあった。抜けていたのは以下である。

1. **ウェブビーコン**という語（ポリシーが名指ししている技術）
2. **Googleが「開示義務を履行できる」と明示しているリンク**（`policies.google.com/technologies/partner-sites`）— 最も確実な担保が抜けていた
3. パーソナライズド／非パーソナライズド広告の区別

### 追加した内容

```
本サービスに広告を掲載することにより、Google を含む第三者がユーザーのブラウザに
Cookie を保存したり、ウェブビーコン（クリアGIF等の埋め込み画像）、IPアドレス、
その他の識別子を使用して情報を収集する場合があります。収集される情報には、
閲覧したページ、閲覧日時、端末やブラウザの種類、おおよその所在地などが
含まれることがあります。
```

```
また、Google が本サービスの利用にあたって取得する情報の取り扱いについては、
「Google のサービスを使用するサイトやアプリから収集した情報の Google による使用」
をご参照ください。
```

さらにパーソナライズド広告と非パーソナライズド広告の違い、CMP未導入地域（EEA・英国・スイス）では非パーソナライズド広告になることを明記した。**これは事実であり、隠すべきものではない。**

## 4. 判断を仰ぎたい：`app.html` の扱い

```
app.html   AdSenseスクリプト:1  <ins adsbygoogle>:0  A8バナー:13  noindex:1  本文5,782字
```

**本文5,782字あるので「有用性の低いコンテンツ」には当たらない**と考える。しかし2点気になる。

1. **AdSenseスクリプトを読み込んでいるが `<ins>` 広告枠が0個。** LPと同じ構造で、222KBのライブラリを読み込んで何も表示していない。表示速度の純損失である
2. **app.html は学習記録アプリで、タイマー・ボタン・タブが密集している。** ポリシーは「広告とページコントローラの間には十分な間隔を取る」「ナビゲーション用機能であると直感的に認識されるような配置」を禁じている。**将来ここに広告枠を置く場合は配置に細心の注意が必要**

`app.html` の変更は `CLAUDE.md` により規模を問わず稟議が必要なため、**今回は触っていない。** 以下2案を提示する。

- **案A：AdSenseスクリプトを app.html から削除する。** `<ins>` が0個なので表示上は何も変わらず、222KBの読み込みが消える
- **案B：現状維持。** 審査結果が出るまで構成を変えない

**CEOとしては案Aを推す。** ただし審査中に構成を変えることのリスク（Googleが再クロールしたときに差分をどう見るか）が読めないため、断定はしない。
