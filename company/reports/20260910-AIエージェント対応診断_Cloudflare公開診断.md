# AIエージェント対応診断：Cloudflare公開診断の記録

**実施日：** 2026年9月10日 18:01 JST
**対象：** `https://study-quest.net/`
**方法：** [Cloudflare「Is Your Site Agent-Ready?」](https://isitagentready.com/)で公開URLを読み取り診断した。診断ページ自身が、推奨内容はAI生成で誤り得るため判断して扱うよう注意している。点数をKPIにせず、Study Questの目的に関係する項目だけを確認した。

## 結論

総合スコアは20/100だったが、AdSense合格や資格学習記事の有用性を測る指標ではない。低得点の大半は、API、OAuth、MCP、エージェントスキル発見、機械間決済など、AIエージェントに機能を提供するサービス向けの項目である。Study Questは公開記事とブラウザ完結の学習アプリを提供するサイトであり、今回これらを実装しない。

## 診断結果と判断

| 診断項目 | 結果 | Study Questでの判断 |
| --- | --- | --- |
| `robots.txt` | 合格。HTTP 200、`User-agent`とsitemap指定を確認 | 維持する。`/admin.html`以外を一律に遮断していない。 |
| `sitemap.xml` | 合格。HTTP 200、XML構造を確認 | 維持する。記事更新時の更新日同期を継続する。 |
| AIボット規則 | ワイルドカード規則が適用される。個別AIボット指定はなし | 現在の許可方針を維持する。訓練・検索・入力利用の扱いを変更する必要が生じた場合だけ、公式仕様と運営方針を確認して稟議化する。 |
| Markdown交渉 | 未対応 | ホスティング側の設定が必要なため、AdSense・読者価値への効果を確認できるまで実装しない。 |
| Content Signals | 未記載 | 新しい仕様のため、点数目的では追加しない。利用方針を決める必要がある場合に別途検討する。 |
| Linkヘッダー・DNS-AID | 未設定 | APIやエージェント提供をしていない現状では対象外。 |
| API Catalog、OAuth、MCP、WebMCP、Agent Skills、ARD | 未設定 | Study Questの公開記事・ローカル保存型アプリには不要。機能を装った空の発見情報は公開しない。 |
| 機械間決済 | 対象外 | 現在の収益方針・AdSense合格の作業とは無関係のため実装しない。 |

## 現在の優先順位

1. 記事の一次情報リンク、具体的な判断手順、誇張表現の是正を進める。
2. `robots.txt`、`sitemap.xml`、`llms.txt`を公開情報の案内として維持する。
3. AIエージェント向けの新しい仕様は、読者に必要な公開機能または実測できる利用価値が生じた場合だけ検討する。

診断結果を理由に、記事本文、DNS、ホスティング、robots.txt、外部API、AdSense設定は変更していない。AdSense再申請や外部送信も行わない。
