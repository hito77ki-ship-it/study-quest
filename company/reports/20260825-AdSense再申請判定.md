# AdSense再申請判定

- 判定日：2026年8月25日
- 対象：`codex/pending-facts-20260825` の公開候補

## 結論

**現時点では再申請しない。**

理由は、今回の是正がまだ `main` と本番へ反映されていないためである。公開後に本番で確認できれば、**再申請してよい（条件付きGO）**と判断する。Googleの審査結果は保証できない。

## 再申請前に完了した是正

- 制度・受験料・持ち物・合格率の一次情報に基づく是正と、出典リンクの追加。
- JSON-LD、画面表示、`sitemap.xml` の更新日3面同期。
- 142記事の一律な反応要求CTAを、記事内容を次の学習で確認する案内へ置換（残存0件）。
- 合格を保証するように読める表現を11記事で是正。残る「必ず合格」は税理士試験の必修科目という制度説明だけ。
- 本文抽出後3,000文字未満の2記事から広告コードを削除（残存0件）。
- 新規の独自記事「簿記の勉強場所とメニュー割り当て」を、一次情報・FAQ・関連導線つきで追加。
- コンテンツ品質ゲートは、構造・ローカルリンク・更新日・テーマ・指標候補すべて0件。

Googleは、広告を載せる画面に独自の有用な内容を求め、他サイトの内容を付加価値なく複製した画面への広告掲載を認めていない。今回の是正は、この点と「広告より内容が主役であること」を優先した。出典：[Google Publisher Policies](https://support.google.com/adsense/answer/10502938)、[replicated content policy](https://support.google.com/publisherpolicies/answer/11190248)。

## 申請前の必須確認

1. このブランチの統合PRを `main` にマージする。
2. GitHub Pagesのデプロイ完了後、`study-quest.net` で少なくとも以下をハードリロードして確認する。
   - `boki-vs-fp.html`：一次情報リンクと更新日
   - `boki-benkyo-basho.html`：新規記事・FAQ・関連導線
   - `kakutei-shinkoku-okure-bassoku.html`：広告のない短い記事
3. AdSenseのポリシーセンターに新しい未解決通知がないことを確認する。
4. 上記が確認できた当日に再申請する。

Googleは変更後にポリシーセンターからレビューをリクエストできるとしている。広告コードを外したページは、ポリシーセンターから自動的に消えるまで7〜10日かかる場合がある。出典：[Google AdSense Help](https://support.google.com/adsense/answer/10008391)。

## 稟議の棚卸し

`承認待ち` 表記の稟議は多数残るが、外部施策（SNS・Unity）、古い企画、後続のPRで内容が置き換わった記録も含む。これらを文書の表記だけで一括実行すると、現行修正の巻き戻しや外部アカウントへの無断操作になる。そのため今回の公開候補では、現在有効で、サイト内だけで完結し、再申請に直結する品質残件のみを実装した。

## 判定の限界

静的監査は、ページ構造・リンク・更新日・定型表現・広告コードの候補を確認するものだが、Googleの独自性・有用性評価そのものを代替しない。本番表示とAdSense管理画面の確認後に再申請しても、審査の通過を約束するものではない。
