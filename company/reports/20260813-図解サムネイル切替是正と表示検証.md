# 図解サムネイル切替是正と表示検証

**実施日：** 2026年8月13日
**実施者：** CEO ジョブズ
**状態：** 実装・ローカル表示検証完了／本番反映はブランチ反映後の通常デプロイ待ち

## 事実訂正

先行報告では、201記事のカードを「内容が一目で伝わる図解サムネイルへ統一済み」とした。しかし、実際の表示は `images/article-thumbnails/*.jpg` の机・本・電卓を主題にした写真調画像が優先されており、記事固有の判断を伝えるものではなかった。取締役からの画面指摘を正とし、この報告で訂正する。

## 是正内容

- `ARTICLES` 台帳の201記事から、640×360のSVG図解を201件生成
- 比較記事は `VS`、日程・立て直し記事は `START → GOAL`、会計は元帳、法律は天秤、ITはコード、英語は `A B C`、資格選びは上昇グラフとして表現
- 記事タイトル由来の短いメッセージを画像内に置き、一覧だけで「何を解決する記事か」を読めるようにした
- トップ一覧、関連記事、新着、検索結果、端末内おすすめ、記事タイトル直下のビジュアルをすべて図解SVG優先へ変更
- 旧JPGはネットワーク失敗時だけのフォールバックとし、通常表示では使わない

## 検証結果

| 確認項目 | 結果 |
|---|---:|
| 台帳記事数 | 201 |
| SVG生成数 | 201 |
| manifestとの対応漏れ | 0 |
| SVG構造不備（`svg` / `title` / 640×360） | 0 |
| 検索 `IELTS` の図解カード | 4件読込済み |
| IELTS記事のおすすめカード | 図解3件／写真0件 |
| 390px幅の関連記事 | 横スクロール0／640×360比率を保持 |

スマホ幅で画面外の画像は既存どおり遅延読込のため、その瞬間には `naturalWidth=0` になる。壊れた画像とは判定せず、生成ファイルの完全性と実際に表示領域へ入った画像の読込を分けて確認した。

## 再発防止

`scripts/audits/run-diagram-thumbnail-audit.mjs` を追加した。台帳・201件のSVG・表示実装（トップ、共通カード、記事ヒーロー、おすすめ）の対応を検査し、欠落・壊れたSVG・実装の後退があれば異常終了する。
