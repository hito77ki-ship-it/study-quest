# AdSense独自性対策 第5段階

## 実施日

2026年8月10日

## 対象

直近のSearch Consoleで表示回数があり、クリックが発生していなかった重点記事5本。

## 実施内容

| 記事 | 本文へ追加した独自パーツ |
| --- | --- |
| `boki2-ochita.html` | 不合格原因を「知識不足・解法の迷い・時間切れ」に分ける再受験判断シート |
| `boki2-roumuhi.html` | 8時間の作業を直接労務費・間接労務費へ分ける計算例 |
| `boki3-seisanhyo.html` | 決算整理仕訳・修正記入・P/L/B/S・差額検算の4行チェック |
| `boki3-shohi.html` | 仕入・売上・決算の消費税処理を確認する判断フロー |
| `sharoshi-vs-gyosei.html` | 合格率ではなく、1年後の仕事から逆算する資格選択表 |

## 独自性の考え方

- 既存の一般論を言い換えるだけでなく、読者が自分の状況を分類して次の行動を選べるようにした。
- 同じ「比較表」でも、記事ごとに判断軸を変えた。
- 簿記記事では、数値・作業時間・検算手順を開示した。
- 社労士・行政書士の記事では、資格取得後の仕事内容と学習継続性を分けて考える構成にした。
- 新しい制度・試験日・料金などの変動情報は追加せず、既存の事実誤りを広げないようにした。

## 検証

- 5ファイルすべてで本文セクションと4行以上の表を確認。
- `node --check article-widgets.js` 成功。
- 直接計算を検算した。労務費は直接7,500円、間接4,500円、合計12,000円。消費税は仮受22,000円−仮払12,000円＝未払10,000円。
- 既存の未コミット変更がある2ファイルは、今回の追加部分だけを選択的に公開対象とする。

## 次の確認

1. 本番反映後、5ページの本文表示とモバイル表の横幅を目視確認する。
2. Search Consoleでクリック、CTR、平均掲載順位の変化を次回週次記録と比較する。
3. 数値例と判断表が有効だった記事型だけを、表示回数のある次の5本へ展開する。

## CEO所見

表示回数があるのにクリックされない記事は、検索結果でまだ上位でないだけでなく、読者が「このページを読む理由」を本文内で見つけられていない可能性がある。独自の判断表と再現可能な例題を積み重ね、一般的な資格情報の寄せ集めではなく、Study Questの学習判断ページとして育てる。
