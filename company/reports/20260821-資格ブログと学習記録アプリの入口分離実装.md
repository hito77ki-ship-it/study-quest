# 資格ブログと学習記録アプリの入口分離 実装レポート

**作成日：** 2026年8月21日
**担当：** CEO ジョブズ
**対象ブランチ：** `codex/blog-app-separation`（`origin/main` の `1e16a18` から作成）

## 実施内容

稟議 `20260821-資格ブログと学習記録アプリの入口分離.md` に基づき、同一ドメイン内の役割を以下の3つに分離した。

| URL | 役割 | 主な行動 |
|---|---|---|
| `/` | 資格ブログの入口 | 資格・勉強法の記事を探す |
| `/app-guide.html` | 学習記録アプリの紹介 | 向く場面と使い方を確認する |
| `/app.html` | 実際の学習記録アプリ | 記録を始める |

- `index.html` のtitle、description、OG、JSON-LDを資格・勉強法の学習ガイドに合わせた。
- トップの主CTAを「資格・勉強法の記事を探す」に変更し、アプリの入口は「アプリについて」として区別した。
- 記事一覧の後ろにあった旧アプリ詳細説明群をトップの公開面から外した。更新情報、記事一覧、アプリ紹介への控えめな導線は維持した。
- `app-guide.html` を新設し、「記事で決める → 今日やることを決める → アプリで記録する」の流れ、向く場面、アプリ本体・資格ガイドへの入口を追加した。
- `shikaku-list.html` と `article-widgets.js` のアプリ導線を、実アプリの直接起動ではなく `app-guide.html` の説明ページへ変更した。
- `app_guide_click` と `app_launch_click` を追加し、紹介ページへの遷移と紹介ページから実アプリを開く遷移を分けて観測できるようにした。
- `sitemap.xml`、資格一覧の表示更新日、JSON-LDの更新日を同期した。

## 観測上の注意

トップページ全体を390px幅で計測すると、既存の `.articles-feature-links` に起因する126pxの横はみ出しは残っている。これは本実装で新たに発生したものではなく、承認待ちの稟議 `20260821-トップページ_モバイル記事導線の横スクロール.md` が対象とする既知の不具合である。本公開単位には混ぜず、同稟議の承認後に別コミットで是正する。

## 公開後の観測

公開直後のクリック数では成功・失敗を決めない。少なくとも14日後に、同じ期間・同じURL単位で `app_guide_click` と `app_launch_click` を確認する。記事・配置別の分解ができない場合、サイト全体のイベント数を本施策の効果として扱わない。
