## 2. `boki3-credit.html` — 記事が最も強調している箇所で仕訳の貸借が逆

### 直した内容

```
修正前： 売上 10,000 ／ クレジット売掛金 9,800 ＋ 支払手数料 200
修正後： クレジット売掛金 9,700 ＋ 支払手数料 300 ／ 売上 10,000
```

### 問題は2つ重なっていた

**① 貸借の逆転**
本サイトは全記事で「A ／ B」を「借方A ／ 貸方B」の意味で使っている。修正前の記載は「借方：売上／貸方：クレジット売掛金・支払手数料」を意味し、**3科目すべてが逆**だった。

**② 同一記事内での数値不一致**
本記事の例題は一貫して「商品10,000円・手数料率3%＝300円 → クレジット売掛金9,700円」（記事内12箇所）。**この `warn-box` だけが手数料200円・9,800円**で、読者はどちらが正しいか判断できなかった。

修正後、旧数値（9,800／手数料200）の残存は**0件**。

### 重大度

**「【最大のひっかけ】」と見出しを付けた枠の中で、仕訳が逆だった。** 記事がいちばん読ませたい箇所であり、そこを信じた読者は逆に覚える。

## 3. `boki2-seizo-genka-hokokusho.html` — 同じ例題データで答えが2つあった

### 直した内容

セクション⑤「仕掛品ボックス」とセクション⑥「バトンリレー」が、**まったく同じ数値セットで異なる答えを出していた。**

| 項目 | ⑤（正） | ⑥（誤・修正前） | ⑥（修正後） |
|---|---|---|---|
| 当期総製造費用 | 150,000 | 150,000 | 150,000 |
| 期首仕掛品 | 20,000 | 20,000 | 20,000 |
| 期末仕掛品 | (30,000) | (30,000) | (30,000) |
| 他勘定振替 | (5,000) | (5,000) | (5,000) |
| **異常仕損費** | **(10,000)** | **記載なし** | **(10,000)** ← 追加 |
| **当期製品製造原価** | **125,000** | **135,000** | **125,000** |

⑥の下流にある製品ボックスも連動して修正した。

```
期首製品 10,000 ＋ 当期製品製造原価 125,000 － 期末製品 15,000 ＝ 売上原価 120,000
（修正前は 130,000）
```

### 検算

```
借方合計 150,000 ＋ 20,000 ＝ 170,000
170,000 － 30,000 － 5,000 － 10,000 ＝ 125,000  ✅ ⑤と一致
10,000 ＋ 125,000 － 15,000 ＝ 120,000          ✅
```

⑥は単体では貸借が合っていた（30,000＋5,000＋135,000＝170,000）ため、**その図だけを見ても誤りに気づけない構造だった。** ⑤と突き合わせて初めて出る。

### あわせて直した：CRの項目番号 Ⅲ の欠落

Ⅰ→Ⅱ→**Ⅳ** と飛んでおり、直前のひな形が「Ⅰ〜Ⅳの合計」と説明しているため、読者には脱字に見えていた。

**番号は振り直していない。** 「Ⅰ直接材料費／Ⅱ直接労務費／Ⅲ直接経費／Ⅳ製造間接費」が製造原価報告書の標準形であり、**Ⅳを Ⅲ に繰り上げるほうが誤りになる。** 代わりに Ⅲ の行を「—（本問では発生なし。外注加工賃など）」として明示した（2箇所）。

### 触っていない箇所

同ファイルの総合例題（別データセット）は元から正しい。

```
50,000 ＋ 40,000 ＋ 0 ＋ 30,000 ＝ 120,000
120,000 ＋ 15,000 ＝ 135,000
135,000 － 20,000 － 3,000 ＋ 2,000 ＝ 114,000  ✅
```

ここに残る `135,000` は正しい値なので変更していない。**一括置換をかけていたら、この正しい数字まで壊していた。**

## 4. `boki2-shohin-baibai.html` — 棚卸資産の評価基準が旧表現

### 直した内容


**同じ記事の表とFAQでは正味売却価額を正しく使っており、記事内で用語が割れていた。**
