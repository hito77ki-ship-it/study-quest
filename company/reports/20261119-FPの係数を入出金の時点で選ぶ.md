# FP3級の入出金の演習と老齢基礎年金の表示

## 公開前に確かめた計算

2年後に同じ備品代180,810円を用意する二つの案を作った。年利は計算用に5％と仮定し、年初からあった残高に利息を付けたあと、年末の入出金を行う。税・手数料は含めない。式と年ごとの残高を別々に計算して、次の3通りを確かめた。

| 案と入出金 | 1年目末の残高 | 2年目末の残高 |
| --- | ---: | ---: |
| A　今日164,000円だけ入れる | 172,200円 | 180,810円 |
| B　残高0円から、各年末に88,200円ずつ入れる | 88,200円 | 180,810円 |
| C　今日164,000円を用意し、各年末に88,200円ずつ受け取る | 84,000円 | 0円 |

Bの2回目は支払い直前の入金で、まだ利息が付かない。Cの2年目は84,000円に4,200円の利息が付き、88,200円を受け取ると残高が尽きる。従来の例題では、問題で指定した0.0913を300万円に掛け、1年あたり約27.4万円という概算が得られることも確認した。[記事内の演習](https://study-quest.net/fp3-lifeplanning.html#cashflow-timeline)

## 年金額と適用条件

令和8年度に第1号被保険者などが納める国民年金の定額保険料は月額17,920円。老齢基礎年金の満額は、1956年4月1日以前生まれなら月額70,408円・年額844,900円、同年4月2日以後生まれなら月額70,608円・年額847,300円である。冊子5ページの本文と注記を読み、要点・本文・早見表・開閉式FAQ・検索向けFAQの各金額と条件を照合した。公的年金の2階建てと企業年金などの私的な上乗せについても表記を整理した。[定額保険料](https://www.nenkin.go.jp/service/kokunen/hokenryo/hokenryo.html)・[老齢年金ガイドの冊子5ページ](https://www.nenkin.go.jp/service/pamphlet/kyufu.files/LK03.pdf#page=6)・[厚生労働省の制度解説](https://www.mhlw.go.jp/stf/nenkin_shikumi_002.html)

実際の運用利回り、個人の年金受給額、試験での得点や学習効果は確認対象外。公開版の操作結果は配信後に確認する。
