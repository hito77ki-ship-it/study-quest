# トップ記事カード全件サムネイル化 実施報告

**実施日：** 2026年8月11日
**担当：** CEO ジョブズ
**対応する稟議：** [トップ記事カード全件のサムネイル化](../decisions/20260811-トップ記事カード全件サムネイル化.md)

## 結果

トップページのカテゴリ一覧にある記事カードを、カテゴリ代表だけでなく全件で画像付きにした。記事URLのスラッグから対応する画像を決めるため、個別カードを手作業で管理しない構成である。

- 生成・追加した画像：197枚
- 表示対象の記事カード：189件（174記事。同一記事の重複掲載を含む）
- 画像形式・寸法：JPEG、全件640×360px、16:9
- 画像ディレクトリの容量：約8.6MB
- 対象外：`app.html`、`boki2-progress.html`、`boki3-progress.html`。いずれも学習記録・アプリへ移動する導線であり、記事カードではない。

## 実装

- `index.html` のカード変換処理を、カテゴリ別の代表画像10枚の対応表から、記事ごとの `images/article-thumbnails/<記事スラッグ>.jpg` を読む仕組みに変更した。
- すべての変換済みカードに、記事タイトルから作る代替テキスト、`width="640"`、`height="360"`、`loading="lazy"`、`decoding="async"` を設定した。
- 画像そのものには文字、資格団体・企業ロゴ、試験制度や数値を含めず、カード本文のテキストを読ませる構成にした。
- 既存の濃色テーマとカテゴリの境界色は保持し、画像があるカードでもタイトルと説明文を残している。

## 検査

| 項目 | 結果 |
| --- | --- |
| 画像URLの存在 | 174記事・189カードの参照先を検査し、不足0件 |
| 画像寸法 | 197枚すべて640×360px、不一致0件 |
| JavaScript構文 | `index.html` 内の4本のインラインスクリプトと `article-widgets.js` が通過 |
| デスクトップ表示 | 簿記2級カテゴリ42カードで表示中画像42/42を読込。横スクロールなし |
| モバイル幅390px | 表示中カード10件の画像読込失敗0件、横スクロールなし、2列表示で最小カード幅166px |
| ブラウザログ | エラーなし |

折りたたまれたカテゴリの画像は、初期表示時に無駄な通信をしないよう遅延読み込みのままとしている。開いた時に読み込まれる仕様であり、初期画面の負荷を増やさない。

## 残課題

今回の範囲に未解決事項はない。今後、記事を新設してトップにカードを追加する場合は、公開前に同じスラッグ名の640×360pxサムネイルを `images/article-thumbnails/` に追加する。
