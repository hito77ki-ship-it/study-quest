# 記事サムネイル：クリック訴求型インフォグラフィック実装記録

- 実施日：2026年8月20日
- 対象：`article-widgets.js` の `ARTICLES` に登録された全201記事
- 根拠稟議：`company/decisions/20260820-記事サムネイル_クリック訴求型インフォグラフィックへ再設計.md`

## 実施内容

従来の「机・本・文具」の汎用的な写真調カードを、記事を開く前に内容を判断できるサムネイルへ再設計した。

- 上段：記事ごとの短い検索意図を、白文字・濃紺アウトラインの大見出しで表示
- 下段：内容に合わせた図解（比較、ロードマップ、会計、法律、IT、英語、キャリア、つまずき解決）を表示
- 文字を画像生成に任せず、SVG内で日本語を合成。誤字・文字化けを避けた
- 背景図解は8系統のAI生成イラストを共通の視覚言語として利用し、タイトル・ラベル・訴求は201記事ごとに固有化した
- すべて640×360px、16:9。SVG内で背景を `preserveAspectRatio="xMidYMid meet"` として表示し、元絵を切り取らない

## 検証結果

| 検証項目 | 結果 |
|---|---:|
| 記事数 / サムネイルSVG数 | 201 / 201 |
| 欠落・破損・マニフェスト不一致 | 0 |
| 使用する8背景素材の欠落 | 0 |
| 見出し末尾の省略記号 | 0 |
| SVG構文・画像参照の監査エラー | 0 |
| PC実画面（一覧・記事内関連記事） | 確認済み |

記事内の `ielts.html` では、関連記事のTOEIC・英検2級・資格比較の3カードについて、見出し・図解・カードリンクが一体で読めることを目視確認した。

## 判定

「画像が付いている」だけではなく、一覧・関連記事・検索結果・おすすめ記事のどこに出ても、記事の問いと読む価値を即座に伝えるカードへ更新できた。なお、背景図解を8系列で統一しているのは、201枚を無秩序な絵柄にせず、Study Questの認知を積み上げるためである。各記事の主張を読ませる見出しは個別に変わる。
