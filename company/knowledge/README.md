# メディア運営知識

Study Questで蓄積した、他事業にも適用できるメディア運営の共通知識を管理する。

## このフォルダの目的

- 事業固有のコンテンツやブランドを混ぜず、再利用できる原則だけを残す
- 新しい企画・記事・LPを始める前に、品質とリスクの確認漏れを減らす
- 実行結果を知識へ戻し、同じ失敗を別事業で繰り返さない

## 読み方

1. [再利用知識インデックス](INDEX.md) から、作業に必要な一件を選ぶ
2. 事業側の `AGENTS.md`、`company/compliance/`、`company/decisions/` を優先して確認する
3. 共通知識と事業固有ルールが衝突した場合は、事業固有ルールを優先する

知識庫全体を常時読むのではなく、[再利用知識の取得・昇格プロトコル](20260820-再利用知識の昇格と取得プロトコル.md)に従って必要な一件だけを取得する。

## 更新ルール

- 成果が確認できた原則、失敗から得た再発防止策、規約・運用上の共通注意だけを追加する
- Study Quest固有のAdSense判断、資格制度、アプリ仕様はここへ移さない
- FANZA固有の成人向け表現、作品情報、広告規約、掲載可否判断はここへ移さない
- 重要な変更は各事業の `company/decisions/` に残し、実行結果は `company/reports/` に記録する
