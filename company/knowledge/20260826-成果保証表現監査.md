# 成果保証・最上級表現の監査

## 目的

記事を自動変更せず、合格・得点・理解など読者の結果を断定する表現と、根拠の確認が必要な最上級表現を抽出する。機械検査は文脈を完全には判断できないため、候補を直ちにポリシー違反や事実誤りと断定しない。

## 実行

```bash
node scripts/audits/run-claim-language-audit.mjs
node scripts/audits/run-claim-language-audit.mjs --paths boki3-next-exam.html --no-write
```

レポートは `company/reports/automation/YYYYMMDD-claim-language-audit.md` に保存される。

## 除外基準

- 問題文の確認など、手順の注意
- 受験資格などの公式事実
- 成果保証を否定する文
- 会計処理・契約上の「保証」など、学習成果と無関係の語

## 変更権限

この監査は検出と記録だけを行う。記事の書き換えはしない。無根拠の成果保証を削る、最上級表現に根拠を付ける、説明構成を変える場合は、`CLAUDE.md` の例外と稟議フローに従う。
