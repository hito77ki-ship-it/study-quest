# AdSenseポリシー品質ゲート

## 目的

AdSenseの再審査前に、広告を出さないと決めたページへ広告コードが戻っていないことと、運営者・問い合わせ・プライバシー・利用規約の信頼ページが読者から到達できることを機械的に確認する。

Googleは、審査を広告コードのあるURLだけでなくサイト全体に対して行うと案内している。また、自動生成または独自性がほとんどないページに広告コードを置かないこと、読者に付加価値のある独自コンテンツと分かりやすい操作性を求めている。

- https://support.google.com/adsense/answer/81904?hl=ja
- https://support.google.com/publisherpolicies/answer/11190248?hl=ja

## 実行

```bash
node scripts/audits/run-adsense-policy-gate.mjs
node scripts/audits/run-adsense-policy-gate.mjs --strict --no-write
```

レポートは `company/reports/automation/YYYYMMDD-adsense-policy-gate.md` に保存する。

## 機械的に止める条件

1. 非収益化指定ページにGoogle広告コードがある。
2. 運営者情報・お問い合わせ・プライバシーポリシー・利用規約のいずれかで、title、description、canonical、sitemap掲載、トップページからの導線が欠ける。

非収益化指定には、`about.html`、`contact.html`、`privacy.html`、`terms.html`、`app.html`、`game.html` と、既存稟議で広告を除去した26本の狭い論点記事を含める。

## 自動断定しない候補

- 3,000字未満で広告コードがある記事
- 定型的な「いいね」CTAを残す記事

3,000字はGoogleが定めた合格ラインではなく、Study Quest内で低スコープ記事の広告配置を見直すために使う運用上の目安である。定型CTAも、直ちにポリシー違反とは断定しない。いずれも、読者価値・一次情報・既存稟議を確認してから編集する。

## 変更権限

このゲートは検出と記録のみで、記事本文・広告コード・公開ページを自動変更しない。検出された記事のリライト、広告配置方針、収益化導線の変更は `CLAUDE.md` の稟議フローに従う。
