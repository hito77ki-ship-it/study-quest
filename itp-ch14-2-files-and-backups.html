ITパスポート 14-2 ファイル管理とバックアップ

フォルダの木をたどり、ファイルの場所を表す

ファイルをまとめるディレクトリは、画面上ではフォルダと呼ばれることがあります。木の起点がルート、現在作業の基準にしている場所がカレントディレクトリです。図の例では、絶対パスは /イベント/広報/案内.pdf、当日を起点にした相対パスは ../広報/案内.pdf です。区切り記号やルートの表記はOSによって異なります。

「.」は現在のディレクトリ、「..」は一つ上を表します。拡張子の .pdf は形式を知る手掛かりで、名前を変えても中身は変換されません。HDDでファイルが離れた場所に分かれて置かれる断片化は、フォルダでの論理的な場所とは別の話です。

共有では、読める人と書ける人を決める

読み取り、書込み、実行などの権限はOSやファイルシステムに応じて設定します。共有先に誤って編集権限を付けると、意図しない変更が起き得ます。担当グループごとに権限を管理し、担当が変わったときに見直すと更新しやすくなります。

フル・差分・増分は、何と比べて変更を保存するか

日曜にフルを取り、毎晩更新する例
方式保存する範囲水曜時点へ戻すとき
フル対象を毎回すべて保存水曜のフル
差分直前のフルからの変更日曜のフル＋水曜の差分
増分直前のフルまたは増分からの変更日曜のフル＋月・火・水の増分を順に

日曜のフルを100MBとし、月に3MB、火に5MB、水に4MBの別々のデータが変更されたと仮定します。水曜に作る差分は3＋5＋4＝12MB、水曜に作る増分は4MBです。容量は変更の重複、圧縮、ツールの動作によって変わります。

上書きや消失から戻せるよう、世代を残す

元と同じ端末だけにコピーを置くと、端末の故障で両方を失うことがあります。保存先を分け、必要な期間分の世代を保ち、復元できることを確かめます。同期で削除が別の端末にも反映される場合があるので、以前の状態を取り戻せる仕組みを確認します。

リストアはバックアップからデータを戻す作業です。アーカイブは、読み返す頻度が低い記録などを長期保管する考え方です。復旧に使うバックアップと、長期参照のためのアーカイブでは目的や保管期間が異なります。

例題8問と解説

Study Quest編集部の自作問題です。先に答えを考えてから、各問の「解答と解説」を開いてください。

第1問　同じフォルダの基準

カレントが /イベント/当日 のとき、「..」はどこを指しますか。

  1. /
  2. /イベント
  3. /イベント/当日
  4. /イベント/広報
第1問の解答と解説

イ　/イベント

「..」はカレントの親を指します。ここでは一つ上の /イベント です。

第2問　相対パスを読む

図と同じ構成で、/イベント/当日 から案内.pdfへ移る相対パスはどれですか。

  1. 広報/案内.pdf
  2. 当日/案内.pdf
  3. ../広報/案内.pdf
  4. ../../広報/案内.pdf
第2問の解答と解説

ウ　../広報/案内.pdf

当日から一つ上のイベントへ戻り、そこから広報へ入ります。

第3問　共有権限を選ぶ

参加者は案内を読めればよく、編集は担当者が行います。参加者に与える権限はどれですか。

  1. 閲覧
  2. 編集と削除
  3. 管理者
  4. ファイルの所有権
第3問の解答と解説

ア　閲覧

案内を読むだけなら閲覧権限で目的を満たせます。

第4問　拡張子と形式

案内.txt の名前だけを案内.pdfに変えたとき、ファイルの中身はどうなりますか。

  1. 自動でPDFの形式になる
  2. 必ず暗号化される
  3. 画像へ変換される
  4. 元のテキストデータのまま
第4問の解答と解説

エ　元のテキストデータのまま

拡張子は形式の手掛かりです。ファイルの中身をPDFに変換するには、対応する保存や出力の処理が必要です。

第5問　差分から復元する

日曜のフル以降、月・火・水に差分を取得しました。水曜の状態を復元するのに必要なものはどれですか。

  1. 水曜の差分だけ
  2. 日曜のフルと水曜の差分
  3. 月・火・水の差分だけ
  4. 日曜のフルと月曜の差分
第5問の解答と解説

イ　日曜のフルと水曜の差分

水曜の差分には、日曜のフル以降の変更が入っています。日曜のフルに水曜の差分を適用します。

第6問　増分が欠けた場合

日曜のフル以降、月・火・水の増分を取得しました。火曜の増分だけ使えない場合、残っている一連のコピーで確実に戻せる最新の時点はどれですか。

  1. 水曜
  2. 火曜
  3. 月曜
  4. 木曜
第6問の解答と解説

ウ　月曜

日曜のフルと月曜の増分は揃っています。水曜の増分は火曜までの状態を基準にするので、火曜の変更が欠けたままでは完全な復元を確認できません。

第7問　水曜に保存する量

月に3MB、火に5MB、水に4MBの別々のデータが変更されました。日曜フルから水曜に取る差分は何MBですか。

  1. 4MB
  2. 8MB
  3. 9MB
  4. 12MB
第7問の解答と解説

エ　12MB

差分は日曜以降の変更を保存します。異なるデータの変更なので3＋5＋4＝12MBです。

第8問　正常だった版を選ぶ

木曜の誤編集が同期先にも反映されました。水曜の状態を取り戻す準備はどれですか。

  1. 水曜時点のバックアップ世代を残す
  2. 今の版だけを同期し直す
  3. ファイルの拡張子を変える
  4. 同じ誤編集を別の端末で繰り返す
第8問の解答と解説

ア　水曜時点のバックアップ世代を残す

以前の版を残しておけば、同期された最新の状態とは別に、水曜版を復元できます。
